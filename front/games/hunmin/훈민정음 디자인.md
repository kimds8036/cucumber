# 말풍선 카니발 — 디자인 프롬프트 (비주얼 전용)

로직·상태관리·데이터 흐름은 제외하고, 순수 스타일 스펙만 정리했습니다.

## 1. 컨셉 한 줄
카카오톡 오픈채팅 감성의 파스텔 톤 + 둥근 손글씨체. 채팅과 말풍선이 게임의 주인공이 되는, 친근하고 가벼운 톤.

## 2. 컬러 팔레트
| 용도 | 색상 |
|---|---|
| 배경 (상단) | `#FFF6EE` |
| 배경 (하단, 그라데이션) | `#FFEFDD` |
| 카드/버블 배경 | `#FFFFFF` |
| 기본 보더 (플레이어 카드) | `#FFD9B0` |
| 강조 보더 (발언 중) | `#FF8FA3` |
| 아바타 배경 | `#FFE1B8` |
| 포인트 컬러 (말풍선, 점수 텍스트) | `#FF8FA3` |
| 본문 텍스트 | `#5A4632` |
| 보조 텍스트 (라운드 표시 등) | `#C99A6C` |

배경은 상→하 세로 그라데이션(#FFF6EE → #FFEFDD)만 사용하고, 그 외 요소는 전부 플랫 컬러. 톤은 채도 낮은 파스텔로 통일 — 원색은 쓰지 않음.

## 3. 타이포그래피
- 폰트: **Jua** (둥글고 통통한 손글씨 계열 한글 웹폰트)
- 중앙 초성 표시: 58px, 자간 0.15em
- 플레이어 닉네임: 12.5px
- 점수 텍스트: 11px, 포인트 컬러(#FF8FA3)
- 라운드 표시: 12px, 알약(pill) 배지 안에 배치
- 타이머 안내 텍스트: 13px

## 4. 레이아웃 구조
가로형(랜드스케이프) 3단 그리드: **왼쪽 플레이어 컬럼(150px) / 중앙 게임 정보 / 오른쪽 플레이어 컬럼(150px)**
- 좌우 컬럼: 각각 3명씩 세로로 쌓기, 카드 간 간격 10px, 세로 중앙 정렬
- 프레임 전체 모서리: 22px 라운드
- 내부 패딩: 22px

## 5. 컴포넌트 스타일

### 5-1. 플레이어 카드
- 배경 흰색, 보더 2px `#FFD9B0`, radius 18px
- 내부 패딩: 9px 12px, 가로 정렬(아바타 + 닉네임/점수)
- 발언 중 상태: 보더 컬러만 `#FF8FA3`로 전환 (그림자·글로우 없이 색상 전환만)
- 아바타: 36px 원형, 배경 `#FFE1B8`, 안에 이모지 1개 (🙋 😎 🐣 🐯 🐼 🦊 등 동물/캐릭터 이모지로 랜덤 배정 — 실제 프로필 사진 대신 사용)

### 5-2. 말풍선 (채팅 답변)
- 배경 `#FF8FA3`, 텍스트 흰색, radius `14px 14px 14px 3px` (왼쪽 아래만 뾰족하게 — 말풍선 꼬리 역할)
- 위치: 해당 플레이어 카드의 아바타 오른쪽 옆, 카드 위쪽으로 살짝 걸치게(top: -14px)
- 패딩: 6px 12px, 폰트 11.5px
- 표시 애니메이션(비주얼 묘사만): 톡 튀어나오듯 스케일 0.8→1.05→1.0 팝인, 사라질 때는 위로 살짝 뜨면서 페이드아웃

### 5-3. 중앙 초성 디스플레이
- 흰색 박스, 보더 3px `#FFD9B0`, radius 20px, 패딩 6px 26px
- 안에 초성 텍스트만 크게(58px)

### 5-4. 라운드 표시
- 배경 `#FFE1B8`, radius 12px(알약형), 패딩 3px 12px, 텍스트 `#C99A6C`

### 5-5. 타이머 (dot 소진형)
- 7개의 점(8px 원)을 가로로 나열, 간격 4px
- 남은 시간: 점 색상 `#FF8FA3`(on) / 소진된 시간: `#FFD9B0`(off, 흐린 톤)
- 점 옆에 "n초 남음" 텍스트 병기(13px, `#C99A6C`)

## 6. 여백/톤 원칙
- 그림자·블러 없음, 전부 플랫 + 보더로 위계 표현
- 라운드 값을 넉넉하게 써서(카드 18px, 버블 14px, 프레임 22px) 전체적으로 말랑말랑한 인상 유지
- 컬러는 위 팔레트 7개 안에서만 조합, 추가 색 도입 금지
