# 스터디룸 (타이머 교실) — 디자인 및 구상

> 제품명: **스터디룸**. 타이머와 연동된 교실 좌석·캐릭터 연출.  
> 이 문서는 **합의된 요구사항** 정리본이다. (랩 검증 → 본 연동 구현으로 전환)

---

## 0. 한 줄 요약

**타이머를 켠 사람만 스터디룸 4×4 좌석에 앉아 공부한다.**  
본인은 이미 앉아 있는 상태로 보이고, 다른 유저는 우측 아래에서 들어와 앉고 / 끝나면 우측 아래로 나간다.  
방당 최대 **16명**, 꽉 차면 **다른 방으로 안내**해 계속 수용한다.

## 1. 진입 · 네비게이션 UX

| 항목 | 결정 |
|------|------|
| 메인 헤더 walk 아이콘 | **제거** (타이머 애니 랩으로 가던 버튼 삭제) |
| 스터디룸 진입 | **타이머 화면**에서, 타이머 **다운로드 아이콘 좌측**에 **「스터디룸 입장」** 버튼 |
| 랩용 우측 상단 버튼 | **「배경 바꾸기」「앉기」삭제** (데모용) |
| 상시 배회 NPC 4명 | **삭제** (걸어 다니는 데모 캐릭터 없음) |

### 1.1 스터디룸 화면 레이아웃 (풀블리드)

| 항목 | 결정 |
|------|------|
| SubHeader / 상단 헤더 바 | **없음** (제목 「스터디룸」텍스트 헤더도 쓰지 않음) |
| 하단 여백·푸터·SafeArea 하단 패딩 | **없음** — 화면 아래로 여백 없이 |
| 교실 배경 | **화면 전체 꽉 참** (`flex:1` + `cover` / edge-to-edge). 상태바·제스처 영역까지 가능하면 배경이 침범 |
| 뒤로가기 | **좌측 상단 플로팅**만 존재. 헤더에 붙지 않고 배경 위에 떠 있음 (반투명 원형 버튼 등). `zIndex` 최상위권 |
| Safe area | 뒤로가기 버튼 위치만 top inset을 고려해 상태바에 안 가리게. 배경·좌석 그리드는 풀스크린 기준 |

스케치:

```
┌─────────────────────────┐
│ [←]  (플로팅)            │  ← 헤더 바 없음
│                         │
│     (교실 배경 풀블리드)   │
│      4×4 좌석·캐릭터      │
│                         │
│                         │  ← 하단 여백/버튼 바 없음
└─────────────────────────┘
```

## 2. 타이머 ↔ 착석 연동 (핵심)

### 2.1 본인 (나)

| 상황 | 연출 |
|------|------|
| 타이머 **실행** (`isRunning = true`) | 빈 좌석 중 **랜덤**에 착석. 착석 스프라이트 = `boy_study` / `girl_study` (성별) |
| 스터디룸 **입장 시점**에 이미 타이머 중 | **이미 앉아 있는 상태**로 보임 (입장·보행 모션 **없음**) |
| 타이머 **종료** | 좌석에서 사라짐. **본인 캐릭터의 퇴장(걸어 나가기) 모션은 보지 않음** |
| 본인 입장(걸어 들어오기) | **보지 않음** (다른 사람 시점과 비대칭) |

→ 사용자는 자기 캐릭터의 **들어오기 / 나가기 걷기**를 화면에서 볼 수 없다.  
→ 스터디룸에 들어오면 타이머 상태와 동기화되어, 공부 중이면 **즉시 착석 UI**.

### 2.2 다른 사용자

| 상황 | 연출 |
|------|------|
| 상대가 타이머 **시작** | **우측 아래**에서 걸어 들어와 → 배정된 빈 좌석에 착석 |
| 상대가 타이머 **종료** | 자리에서 일어나 → **우측 아래**로 걸어 나감 |
| 이미 앉아 있는 상대 | 스터디룸 입장 시 **앉아 있는 모습**으로 보임 (과거 입장 모션 재생 안 함) |

이동 경로: 스프라이트는 상하좌우만 있으므로 **축 정렬(L자 등)** 이동.  
출입 스폰/디스폰 포인트 = 화면 **우측 하단** (문·복도 쪽 가정).

### 2.3 착석 시 UI (좌석 라벨)

착석한 캐릭터마다:

| 위치 | 내용 |
|------|------|
| **머리 위** | **타이머 경과 시간** (앱 타이머와 **동일 연동** — 로컬 데모 시계 아님) |
| **캐릭터/책상 아래**(기존에 시간이 있던 자리) | **유저 아이디** |

아이디 표시 규칙:

- 최대 **9자**까지 표시
- 그보다 길면 **앞 9자 + `..`** (예: `abcdefghij` → `abcdefghi..`)
- 배경 칩 없음 — **텍스트만**, 그림자로 가독성 확보
- 타이머·아이디 모두 **한 줄** (영역 확장 + 작은 글씨)

시간 표시:

- 포맷은 타이머 화면과 맞출 것 (예: `mm:ss` / `hh:mm:ss`)
- 값이 **실제 타이머 세션 경과**와 동기

## 3. 룸 · 좌석 · 정원

### 3.1 좌석

- 빈 자리: `chair_desk.png` **4×4 = 16** 그리드
- 착석: 해당 칸의 빈 책걸상 숨김 → `boy_study` / `girl_study`로 교체
- 타이머 ON 시 **빈 좌석 중 랜덤** 배정 (충돌 없이 1인 1좌)

### 3.2 정원 · 멀티 룸 · 같은 방 연동

- **방당 최대 16명** (좌석 수 = 정원)
- 16명 꽉 차면: 사용자에게 **다른 스터디룸으로 안내**
- 방은 **계속 추가·할당** 가능해야 함 → “항상 앉을 곳이 생기도록” 스케일

**같은 스터디룸에 입장한 사용자끼리는 연동된다.** (의도 = Yes)

같은 `roomId`를 공유하는 참가자끼리:

| 공유되는 것 | 설명 |
|-------------|------|
| 좌석 배치 | 누가 몇 번 칸에 앉았는지 |
| 착석/퇴실 | 타이머 시작·종료에 따른 입장·퇴장 연출 (타인은 모션 보임) |
| 머리 위 시간 | 각 유저의 **본인 타이머 경과** (상대 타이머 값도 동기되어 표시) |
| 아이디 | 좌석 아래 표시 |

구현 메모: 룸 ID, 좌석 인덱스, 참가자 userId, 타이머 세션 시작 시각(또는 elapsed)을 **서버/실시간(소켓 등)** 으로 같은 방 전원에게 브로드캐스트.

다른 방에 있는 유저는 **서로 보이지 않음** (룸 단위 격리).

### 3.3 배경 — 시간대 자동 전환 (기기 로컬 시각)

랩의 「배경 바꾸기」버튼은 제품에서 **삭제**.  
스터디룸 배경은 **현재 시각**에 따라 아래 에셋으로 자동 선택한다.

| 파일 | 시간대 (로컬) | 비고 |
|------|----------------|------|
| `classroom1.png` | **06:00 – 17:00** | 아침 6시 ~ 오후 5시 |
| `classroom2.png` | **17:00 – 22:00** | 오후 5시 ~ 밤 10시 |
| `classroom3.png` | **22:00 – 06:00** | 밤 10시 ~ 아침 6시 |

경계 규칙 (구현 시):

- 구간은 **시작 시각 이상 ~ 끝 시각 미만** (`[start, end)`) 으로 통일.
- 예: `06:00` → classroom1, `17:00` → classroom2, `22:00` → classroom3, `00:00` → classroom3.
- 시각이 바뀌면(구간 변경) 배경만 교체. 좌석·캐릭터 상태는 유지.

```
06  classroom1  17  classroom2  22  classroom3  (…자정…)  06
```

## 5. 기기 · 레이아웃

### 5.1 패드

- 당분간 **폰 세로 우선**. 패드는 추후.

### 5.2 기종별 화면 크기

- 좌석·캐릭터는 **정규화 좌표 + 짧은 변 기준 스케일**
- 배경 `cover` 시에도 **4×4 그리드는 잘리지 않는 중앙 영역**에 배치
- Safe area: 헤더 아래 스테이지만 좌표계

## 6. 구현 체크리스트 (우선순위)

1. ~~걷기·착석·빈 책상·다중 배경 에셋 / 랩 검증~~
2. 메인 헤더 walk → **제거**
3. 타이머 화면 **「스터디룸 입장」** (다운로드 아이콘 좌측)
4. 스터디룸 화면: **헤더·하단 여백 제거**, 배경 풀블리드, **좌상단 플로팅 뒤로가기만**
5. 타이머 `isRunning` / 경과시간 **연동 착석** (본인: 즉시 착석, 입장·퇴장 모션 숨김)
6. 머리 위 **타이머 시간**(한 줄) + 아래 **아이디(9자+`..`, 배경 없음)**
7. 타 유저: 우하단 입장·퇴장 걷기 + **같은 룸 실시간 동기**
8. **16명 만석 → 다른 룸 안내**, 룸 확장
9. 배경 **로컬 시각 구간** 자동 전환 (§3.3)

## 7. 이해한 내용 (재확인)

- 스터디룸은 **타이머와 한몸**이다. 데모용으로 막 돌아다니는 4명은 없다.
- **앉기/배경 버튼은 없다.** 앉는 트리거는 **타이머 실행**. 배경은 **시간대 자동**.
- **나는** 들어오고 나가는 걸 못 보고, 들어와 보면 이미 앉아 있거나(타이머 중) 없다.
- **남이** 타이머를 켜면 우측 아래에서 걸어와 앉고, 끄면 우측 아래로 나간다.
- 시간 = **진짜 타이머**, 아이디는 **자리 아래**(텍스트만·9자), 시간은 **머리 위**(한 줄).
- **16명 방**이 차면 **다음 방**으로 보내서, 전체적으로는 계속 받을 수 있게 한다.
- **같은 스터디룸 안 사용자끼리는 연동** (좌석·입퇴장·표시 정보 공유). 다른 방은 격리.
- 스터디룸 UI는 **헤더/하단 여백 없이 배경 풀스크린**, 조작은 **좌상단 플로팅 뒤로가기**뿐.

이 문서가 위 해석과 다르면 알려 주면 수정한다.
