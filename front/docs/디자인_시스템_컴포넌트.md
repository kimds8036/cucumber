## 1. 버튼

### 쓰임

| 종류 | 언제 쓰나 | 구현 |
|------|-----------|------|
| **Primary CTA** | 화면 하단 주 액션 1개 (가입·로그인·시작하기) | `SignupPrimaryFooter`, Login pill |
| **Popup** | 모달 안 확인/취소 | `AlertHost` 버튼 |
| **Header icon** | 메인 상단 검색·알림 | `MainHeader` `iconButton` |
| **Text / link** | 보조 이동 | `primary` / `primaryDark` 글 |
| **Destructive** | 삭제·거절 | `alert` 면 또는 `alertDark` 글 |

### 모양 · 크기 **[기존]**

| 종류 | 높이 | 모서리 | 글 | 면 |
|------|------|--------|-----|-----|
| Primary CTA | **52** | pill (26) | Bold `xxl` · `textWhite` | `primary` |
| Popup | **42** | **10** | Bold 14 · 흰/보조 | primary / cancel / alert |
| Header icon | min **40** | 원형 | 아이콘만 | `green` + `primaryLight50` 보더 |

### 상태

| 상태 | 기준 |
|------|------|
| 기본 | 위 표 |
| 눌림 | `activeOpacity` **0.7** (`tokens.interaction`) — AlertHost 일부는 아직 0.85 **[기존 혼재]** |
| 불가 | CTA: `disabled` 면 + `textSecondary` 글 · 또는 `primaryLight50` |
| 로딩 | 버튼 안 `ActivityIndicator` (`textWhite`) · `SignupPrimaryFooter` |

### 사용 기준

- 한 화면에 Primary CTA는 **1개**
- 팝업 버튼 2개 이하면 **가로**, 3개 이상이면 **세로** (`AlertHost`)
- cancel = `textLight5` 면 · destructive = `alert` 면

## 2. 카드

### 쓰임

| 종류 | 언제 쓰나 | 구현 |
|------|-----------|------|
| **Feed** | 게시글 목록·스크랩 | `Boardpostcard` 등 |
| **Surface** | 설정·마이 섹션 묶음 | `surface` 또는 보더만 |
| **Profile** | 마이 요약 | `Profilecard` |
| **Popup card** | 중앙 모달 본체 | `AppPopupModal` 안 View |

### 모양 · 크기 **[기존]**

| 종류 | 배경 | radius | 그림자 | 안쪽 여백 |
|------|------|--------|--------|-----------|
| Feed | `background` | ~**18** | `shadow.md`급 | 화면별 |
| Surface | `surface` `#F7F7F7` | `md`~`lg` | 약하거나 없음 | **[시작값]** 16 / 밀집 12 |
| Popup | `background` | **18** | 딤만 | 가로 18 · 세로 25 |
| Lock 로딩 카드 | `background` | **16** | 딤 0.45 | 세로 28 · 가로 32 |

### 사용 기준

- 히어로에 카드 스택 남용 금지
- 클릭 가능한 피드 카드 vs 장식용 Surface는 역할 분리
- 게임·스터디룸 전용 카드는 이 기준과 분리

## 3. 입력 칸

### 쓰임

| 종류 | 언제 쓰나 | 구현 |
|------|-----------|------|
| **Underline** | 로그인·가입·프로필 아이디 | Login, SignStep2, SignProfileUsername, GrowingUnderline |
| **Search** | 검색 | `SearchSubHeader` |
| **Boxed** | 일부 폼(비밀번호 등) | 설정·기존 폼만 |

### 모양 · 상태 **[기존]**

| 종류 | 기본 | 포커스 | 오류 |
|------|------|--------|------|
| Underline | 밑줄 · Regular `xl`+ · `textPrimary` | GrowingUnderline 채움 | Regular `lg` 피드백 문구 (`alert`/`primaryDark`) |
| Search | SubHeader 슬롯 + TextInput | X 슬롯 높이 고정(점프 방지) | — |
| Boxed | radius `md` · `border` | 기본 커서 | 화면별 |

### 사용 기준

- **신규 계정·아이디 입력 = Underline 우선** **[시작값]**
- 검색 3화면은 모두 `SearchSubHeader` 공유
- 글로우·두꺼운 포커스 링 지양
- Android 메타·한 줄: `includeFontPadding: false` 관례

## 4. 칩

### 쓰임

| 종류 | 언제 쓰나 | 예 |
|------|-----------|-----|
| **필터 / 선택** | 게시판·정렬·해시태그 | `boardChip`, 해시태그 칩 |
| **상태** | 문의·숨김글 상태 | `StatusChip` |
| **카운트 / 배지형** | 친구 수 등 | `friendCountChip` |

### 모양 **[기존]** (게시판 칩 예시)

| 상태 | 면 | 보더 | 글 |
|------|-----|------|-----|
| 선택·강조 | `primaryLight10` | `primaryLight30` | `primaryDark` · `md` |
| 비활성(일반 필터 관례) | 흰 / 투명 | `textLight10` | `textSecondary` |
| 활성 채움형 | `primary` | — | `textWhite` |

모서리: 대략 **20** (pill에 가까운 칩) · 해시태그·드롭다운은 화면별.

### 사용 기준

- 같은 필터 줄의 칩은 radius·패딩을 맞춤
- 상태 칩(승인/거절)은 `alert` / `primary` 계열로 의미 구분 — 필터 칩과 혼용 금지

## 5. 하단 탭

### 쓰임

메인 5탭 셸. `MainFooter` + `MainShellContext`.

| 키 | 라벨 |
|----|------|
| board | 홈(게시판) |
| message | 메시지 |
| school | 우리 학교 |
| timer | 타이머 |
| mypage | 마이페이지 |

### 모양 · 크기 **[기존]**

| 항목 | 값 |
|------|-----|
| 바 높이 | **65** |
| 탭 min 높이 | **50** |
| 배경 | `background` |
| 상단 선 | `textLight5` · 0.5 |
| 라벨 | Bold `md`(10) |

### 상태

| 상태 | 아이콘·라벨 |
|------|-------------|
| 기본 | `textSecondary` |
| 선택 | `primary` + 상단 **삼각 인디케이터** |
| 눌림 | `activeOpacity` **0.7** |

### 사용 기준

- 메인 탭 이외 화면에 동일 하단바를 복제하지 않음
- 아이콘 라이브러리(Octicons/FA/Material/Ionicons)는 기존 탭 유지 — 억지 통일 금지

## 6. 헤더 / 푸터

### 헤더

| 컴포넌트 | 쓰임 | 거터 · 제목 |
|----------|------|-------------|
| `MainHeader` | 메인 탭 상단 | 가로 **20** · 큰 탭 타이틀 (`heading+6`) |
| `SubHeader` | 하위 화면 | 폭 **7%** · Bold `xxl` 가운데 |
| `SearchSubHeader` | 검색 | SubHeader와 동일 거터·뒤로(아이콘 **20**) |

**MainHeader 아이콘 버튼:** min 40 원형 · `green` 면 · 알림 뱃지 `alert` 점.

### 푸터

| 컴포넌트 | 쓰임 |
|----------|------|
| `MainFooter` | 하단 5탭 (§5) |
| `SignupPrimaryFooter` | 가입·프로필 아이디 하단 CTA · 거터 **7%** · 상하 여백 **8** |

### 사용 기준

- 하위 화면 = `SubHeader` + 흰 배경
- 가입 CTA 거터는 SubHeader와 **동일 7%**
- SafeArea bottom은 셸/화면이 담당 (`SignupPrimaryFooter`에 inset 넣지 않음)

## 7. 토글

### 쓰임

설정 on/off (알림 등). **공통 Toggle 컴포넌트는 없음** — `Switch`를 화면에서 직접 사용.

대표: `notificationsettings.jsx`

### 모양 · 상태 **[기존]**

| 상태 | track | thumb |
|------|-------|-------|
| Off | `border` (`#E0E0E0`) | `textWhite` |
| On | `primary` (`#A6DA95`) | `textWhite` |
| Disabled | Switch `disabled` + 행 `notifRowDisabled` | — |

눌림(행): `activeOpacity` **0.7**.

### 사용 기준 **[시작값]**

- 신규 설정도 동일 `trackColor` / `thumbColor` 사용
- 칩·탭으로 on/off를 표현하는 화면은 Switch와 역할을 섞지 않음
- 공통 `<AppSwitch>` 추출은 미도입 — 필요 시 위 색만 맞추면 됨

## 8. 토스트 메시지

### 쓰임

짧은 피드백·푸시 미리보기. 탭하면 관련 화면으로 이동 가능.

| 계층 | 역할 |
|------|------|
| `useToast` / `ToastContext` | `showToast` API |
| `ToastHost` | 전역 호스트 · 탭 네비게이션 |
| `GlobalToast` | 시각 UI |

### 모양 · 모션 **[기존]**

| 항목 | 값 |
|------|-----|
| 위치 | 상단 · `topOffset` 기본 **60** · 좌우 **16** |
| 면 | `background` · radius **16** |
| 패딩 | 가로 16 · 세로 14 |
| 그림자 | opacity 0.12 · elevation 8 |
| 제목 | Bold `xl` · `textPrimary` |
| 본문 | Regular `lg` (제목 있을 때) / Bold `xl` (제목 없을 때) |
| 등장 | ~320ms · 위에서 슬라이드 |
| 퇴장 | ~180ms |
| 눌림 | `activeOpacity` 0.92 |

### 사용 기준

- 오류·확인이 중요하면 토스트 대신 **오류 안내 팝업** (`appAlert`)
- 한 번에 하나 · Host가 큐/교체 처리
- raw hex 로딩바 색(`#4CAF50`)은 주석 처리됨 — 재사용 시 `primary`로 **[시작값]**

## 9. 로딩 화면

### 쓰임 · 종류

| 종류 | 언제 | 구현 |
|------|------|------|
| **Skeleton** | 리스트·카드 자리 표시 | `Skeleton`, 화면별 SkeletonRow |
| **Lock 모달** | 제출 중 전체 차단 | `SubmittingLockModal` |
| **인라인 Indicator** | 버튼·작은 영역 | `ActivityIndicator` · `primary` 또는 흰 |
| **오버레이** | 본인인증 등 | `SignupIdentityVerifyingOverlay` 등 |

### Skeleton **[기존]**

- 면: `textLight10`
- opacity 루프: **0.5 ↔ 0.9** · 각 650ms
- 기본 radius **8** (`radius.sm`)

### SubmittingLockModal **[기존]**

- 딤: `rgba(39,42,38,0.45)`
- 카드: 흰 · radius **16** · Indicator `primary` · Bold 16 메시지
- 뒤로가기 차단 (`onRequestClose` no-op)

### 사용 기준

- 첫 로드·새로고침 = Skeleton 우선
- API 제출·이중 탭 방지 = Lock 모달
- 버튼 안 로딩과 Lock을 동시에 쓰지 않도록 화면에서 선택

## 10. 빈 화면

### 쓰임

리스트에 항목이 없을 때 (`ListEmptyComponent` 등).

**공통 Empty 컴포넌트 없음** — 화면별 `Text` + 짧은 카피.

### 모양 관례 **[기존]**

| 항목 | 값 |
|------|-----|
| 글 | Regular `xl` 전후 |
| 색 | `textSecondary` 또는 `textLight40` |
| 정렬 | 가운데 |
| 카피 예 | 「아직 게시글이 없습니다.」 · 친구/알림/급식도 화면별 |

### 사용 기준 **[시작값]**

- 설명은 **한두 문장**, 장문·일러스트 남발 금지
- 액션이 필요하면 빈 화면 아래 Primary/ Text 링크 1개
- 오류(실패)와 빈 화면(성공·0건)을 같은 카피로 쓰지 않음
- 추후 공통 `<EmptyState title description action />` 도입 여지는 있음(미도입)

## 11. 오류 안내 팝업

### 쓰임

확인이 필요한 안내·오류·파괴적 확인.

| 계층 | 역할 |
|------|------|
| `appAlert` / `Alert.alert` 래핑 | 호출 API |
| `AlertHost` | 전역 큐 · 표시 |
| `AppPopupModal` | 딤 + 흰 카드 셸 |

### 모양 **[기존]**

| 항목 | 값 |
|------|-----|
| 딤 | `rgba(0,0,0,0.3)` |
| 카드 폭 | **86%** · max 420 |
| radius | **18** |
| 패딩 | 가로 18 · 세로 25 |
| 제목 | 18 · Bold · `textPrimary` · 가운데 |
| 본문 | 14 · `textSecondary` · lineHeight 22 |
| 노트 | 12 · `textLight40` (옵션) |
| 버튼 | 높이 **42** · radius **10** · gap 8 |
| 페이드 | dismiss **320ms** |

### 버튼 스타일

| `style` | 면 | 글 |
|---------|-----|-----|
| (기본) | `primary` | 흰 |
| `cancel` | `textLight5` | `textSecondary` |
| `destructive` | `alert` | 흰 |

- 배경 탭으로 닫기: AlertHost는 **끔** (`dismissOnBackdrop={false}`)
- 큐: 닫힌 뒤 다음 alert

### 사용 기준

- 필드 옆 짧은 오류 = 입력 칸 피드백 (팝업 X)
- 전역 실패·확인 = `appAlert`
- 네이티브 `Alert.alert` 직접 UI 분기 금지 — Host 경로 유지
