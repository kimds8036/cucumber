# 뽀모도로 엔진 연동

작성: 2026-09-27  
상태: **엔진만 완료. 화면은 팀원 작업 후 이 문서로 붙인다.**

기존 공부 타이머(카운트업·세션 기록)와 **상태를 섞지 않는다.**  
엔진은 UI/알림/서버 저장 없이 동작한다.

## 2. 화면에서 바로 붙이는 최소 코드

```jsx
import { usePomodoro } from '../../hooks/usePomodoro';

function PomodoroScreen() {
  const p = usePomodoro({
    onEvent: (view, events) => {
      for (const e of events) {
        if (e.type === 'phase_complete') {
          // 집중/휴식 끝 알림, 사운드
        }
        if (e.type === 'cycle_complete') {
          // 집중 4회 완료(긴 휴식 직전)
        }
      }
    },
  });

  const running = p.status === 'running';
  const paused = p.status === 'paused';

  return (
    <>
      {/* p.phase: 'focus' | 'short_break' | 'long_break' */}
      {/* p.remainingSec, p.durationSec, p.progress (0~1) */}
      {/* p.focusCountInCycle / p.longBreakEvery  예: 2/4 */}

      <Button
        title={running ? '일시정지' : paused ? '계속' : '시작'}
        onPress={() => {
          if (running) p.pause();
          else if (paused) p.resume();
          else p.start();
        }}
      />
      <Button title="건너뛰기" onPress={() => p.skip()} />
      <Button title="초기화" onPress={() => p.reset()} />
    </>
  );
}
```

`remainingSec`은 초 단위 남은 시간이다. `mm:ss`로 쓰려면:

```js
const mm = String(Math.floor(p.remainingSec / 60)).padStart(2, '0');
const ss = String(p.remainingSec % 60).padStart(2, '0');
`${mm}:${ss}`
```

## 3. 훅이 주는 값 · 액션

### 표시용

| 필드 | 타입 | 설명 |
|------|------|------|
| `status` | `'idle' \| 'running' \| 'paused'` | 재생 상태 |
| `phase` | `'focus' \| 'short_break' \| 'long_break'` | 현재 페이즈 |
| `remainingSec` | number | 남은 초 (올림) |
| `durationSec` | number | 현재 페이즈 전체 초 |
| `progress` | 0~1 | 진행률. 링/바에 그대로 |
| `focusCountInCycle` | number | 이번 사이클에서 완료한 집중 횟수 |
| `completedFocusTotal` | number | 앱 켜진 동안 완료한 집중 총합 |
| `longBreakEvery` | number | 기본 4. N회마다 긴 휴식 |
| `nextPhase` | phase | 지금 페이즈가 끝나면 갈 곳 |
| `config` | object | 아래 설정 |

### 액션

| 함수 | 동작 |
|------|------|
| `start()` | idle에서 시작 |
| `pause()` | running → paused. 남은 시간 유지 |
| `resume()` | paused → running |
| `skip()` | **완료로 치지 않고** 다음 페이즈. 집중 skip은 횟수 +0 |
| `reset(config?)` | 처음부터. 설정은 유지하거나 인자로 교체 |
| `setConfig({ ... })` | 시간/사이클 변경. idle이면 현재 페이즈 길이도 갱신 |
| `tick()` | 훅이 250ms마다 호출. 화면에서 부를 필요 없음 |

## 4. 기본 규칙 (바꿀 때 여기부터)

기본값 (`DEFAULT_POMODORO_CONFIG`):

- 집중 25분, 짧은 휴식 5분, 긴 휴식 15분
- 집중 **4회 완료**마다 긴 휴식
- `autoStartNext: false` — 페이즈가 끝나도 **자동 시작하지 않음**. 화면이 알림 보여 준 뒤 `start()` 호출

설정 바꾸기:

```js
p.setConfig({
  focusSec: 25 * 60,
  shortBreakSec: 5 * 60,
  longBreakSec: 15 * 60,
  longBreakEvery: 4,
  autoStartNext: false,
});
```

`autoStartNext: true`면 페이즈 종료 즉시 다음이 running이 된다. 알림을 먼저 띄울 거면 false 유지.

## 5. 이벤트

`onEvent(view, events)`의 `events`는 배열이다.

| type | 언제 | 필드 |
|------|------|------|
| `phase_complete` | 시간이 0이 되어 페이즈가 끝남 | `phase`, `atMs` |
| `cycle_complete` | 집중 N회 완료, 긴 휴식으로 넘어갈 때 | `completedFocusTotal`, `atMs` |
| `phase_skip` | 사용자가 skip | `phase`, `atMs` |
| `reset` | 초기화 | `atMs` |

집중 skip은 `phase_complete`가 아니다. 횟수에 안 넣는다.

## 6. 기존 타이머와 관계

| | 공부 타이머 | 뽀모도로 |
|--|-------------|----------|
| 훅/스토어 | `useTimerDay` / `timerRuntimeStore` | `usePomodoro` / `pomodoroRuntimeStore` |
| 시간 | 카운트업, 세션 `startedAtMs` | 카운트다운, `endsAtMs` |
| 저장 | 서버 day 스냅샷 | **아직 없음** (아래 7) |

한 화면에서 둘 다 켜지 말 것. 모드 전환 시 한쪽을 `pause`/`reset` 한다.

남은 시간은 `setInterval`로 1초씩 깎지 않는다. `endsAtMs - now`라서 백그라운드에 있다 돌아와도 맞다. 훅의 250ms 틱은 화면 갱신 + 0초 감지용이다.

## 7. 화면 붙인 뒤에 하면 되는 것

엔진에 없는 것. 화면 나온 뒤 따로 구현한다.

1. **알림** — `phase_complete`에서 로컬 알림. 기존 `timerRunNotification.js`와 identifier를 분리할 것.
2. **설정 저장** — `pomodoroSerialize()` / `pomodoroHydrate(raw)`가 이미 있다. AsyncStorage 또는 서버에 raw만 넣으면 된다. hydrate 시 running은 paused로 복원된다.
3. **공부 세션 연동** — 집중 running일 때만 기존 `startTimer`를 켤지 여부는 제품 결정. 엔진은 세션 API를 호출하지 않는다.
4. **테스트** — 엔진은 `front`에서  
   `node --test utils/pomodoroEngine.test.js`

## 8. 훅 없이 스토어만 쓸 때

위젯·알림 핸들러처럼 React 밖이면:

```js
import {
  getPomodoroView,
  subscribePomodoro,
  pomodoroStart,
  pomodoroPause,
  pomodoroResume,
  pomodoroSkip,
  pomodoroReset,
  pomodoroTick,
  pomodoroSerialize,
  pomodoroHydrate,
} from '../utils/pomodoroRuntimeStore';
```

`subscribePomodoro((view, events) => { ... })`  
running일 때는 어디선가 `pomodoroTick()`을 주기적으로 호출해야 페이즈가 끝난다. 화면 훅을 쓰면 자동이다.
