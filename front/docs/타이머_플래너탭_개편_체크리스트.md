# 타이머 투두·타임테이블 탭 개편 체크리스트

> 대상: 타이머 탭 시간 카드 아래의 투두리스트·타임테이블 영역. 지금은 `front/view/src/timer/TimerLiveViews.jsx`의 `segment === 'body'` 부분(226~386줄)이 둘을 가로로 나란히 그린다.  
> 스타일: `front/styles/timer.js`의 `todoTimetableRow`, `todoColumn`(폭 50~60%), `timetableColumn`(폭 35% 이상), `todoHeader`, `todoTitle`, `timetableTitle` 등.  
> 참고 디자인: 위쪽에 `투두리스트 · 타임테이블 · 공부 잔디 · 위클리` 메뉴가 가로로 있고, 선택한 메뉴에 밑줄이 그어진다. 그 아래에 선택한 메뉴의 내용이 화면 폭 가득 보인다.

목표는 투두리스트와 타임테이블을 가로 나란히 배치하는 대신, 메뉴 탭으로 하나씩 골라 보게 바꾸는 것이다. 투두리스트와 타임테이블의 기능(과목 추가, 할 일 추가·체크·삭제, 과목별 시작·정지, 접기·펼치기, 10분 단위 공부 기록)은 그대로 둔다.

---

## 0. 작업 순서

- [x] 1단계: 메뉴 탭 컴포넌트를 만든다 (투두리스트, 타임테이블, 공부 잔디, 위클리)
- [x] 2단계: 투두리스트·타임테이블 가로 배치를 없애고, 선택한 메뉴의 내용만 보이게 한다
- [x] 3단계: 투두리스트와 타임테이블이 화면 폭 가득(좌우 거터 0.04 유지) 보이게 스타일을 바꾼다
- [x] 4단계: 공부 잔디·위클리 메뉴를 추가한다 (내용은 나중에 개발)
- [x] 5단계: 로딩 스켈레톤, 사용 가이드, 쓰지 않는 스타일을 정리한다

- (c) 메뉴에 이미 이름이 있으니 두 제목 모두 없애고 `과목 추가` 버튼만 남긴다
