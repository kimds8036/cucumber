# 하루 알림 계획

작성일: 2026-10-20  
시각은 모두 한국 시간(Asia/Seoul).

하루에 사용자 푸시는 한 번만 보낸다. 관리자가 고른 것만 나간다. 고르지 않은 날은 보내지 않는다.

## 언제 고르나

- 평일(월~금): 18시에 디스코드로 “오늘 알림을 골라 주세요”.
- 주말(토·일): 14시에 같은 알림.
- 그 시각 전에 관리자가 이미 그날 알림을 보냈으면 디스코드 알림은 보내지 않는다.
- 18시·14시는 사용자 푸시 시각이 아니다. 관리자에게 “지금 골라라”고 부르는 시각이다. 고른 뒤 관리자가 보내는 시각에 사용자에게 간다.
- 디스코드 이후에도 끝까지 고르지 않으면 그날 사용자 알림은 없다. 인기글 자동 발송은 하지 않는다.

디스코드는 지금 있는 웹훅(`discordWebhook.service.js`)에 하루 알림용 채널을 하나 붙여 보낸다.

## 관리자 화면에서 고르는 것

하루 한 장. 이미 보냈으면 그날은 다시 보낼 수 없고, 보냈다는 표시만 남긴다.

1. **대상 게시판.** 전체 게시판 또는 학생 게시판.
2. **게시글.** 그 게시판의 오늘 인기글이 있으면 목록에서 하나 고른다. 인기글이 없어도 글을 직접 고를 수 있다.
3. **알림 종류.** 고른 글에 붙일 문장 종류다.
   - 오늘의 인기 게시글. 인기글을 골랐을 때의 기본 뉘앙스.
   - 학생 게시판에 올라온 ‘○○’ 게시글. ○○는 그 글의 분류에서 고른다. 예: 고민.
4. **공지.** 게시 중인 공지를 사용자 알림으로 보낼지 고른다. 기본은 보내지 않음. 공지를 고르면 그날의 한 번을 공지로 쓴다.
5. **스터디룸.** 올릴 만한 글이 저조하고, 타이머·스터디룸 이용자가 기준 이상일 때만 후보로 보여 준다. 문장 뉘앙스는 “스터디룸이 활발해요, 참여해 보세요”. 관리자가 이 후보를 골랐을 때만 보낸다.

보내는 내용은 관리자가 고른 글(또는 공지, 또는 스터디룸)과 고른 종류 문장이다.

## 학생증을 하지 않은 사용자

알림 자체는 받는다.

- 전체 게시판 글, 인증 없이 열리는 공지·스터디룸: 누르면 그 화면으로 간다.
- 학생 게시판 글, 학생 게시판 문장: 누르면 글 대신 학생증 인증으로 간다.

## 하지 않는 것

- 마감이 지나서 인기글이나 스터디룸을 자동으로 보내지 않는다.
- 하루에 두 번 보내지 않는다. 먼저 보냈으면 그날이 끝이다.
- 디스코드 시각에 사용자 폰으로 바로 나가지 않는다.
