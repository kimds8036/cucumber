Git 추적본: `front/docs/릴리스_노트.md`

## 1.5.14 (versionCode 23) — 2026-08-01

### 스토어용 (짧게) — 복사용

```
• 마이페이지에서 학적(학교·학년·반) 정보가 더 바로 반영되도록 개선
• 게시글 답글 작성 중 다른 답글을 눌러도 입력 내용이 유지되도록 수정
• 다크모드 전환을 비활성화해 화면 표시를 안정화
• 전반적인 안정성 개선
```

### 상세 (팀·내부)

| 구분 | 내용 |
|------|------|
| 마이페이지 | 탭 포커스마다 `/auth/me` 재조회로 관리자·DB 학적 변경 반영 |
| 게시판 | 다른 「답글」 전환 시 `setBottomComment('')` 하지 않음 — 입력 유지 |
| UI | 다크모드 버튼 비활성화 (`userInterfaceStyle: light` 유지) |
| 관리자 | 사용자 학적(학교·학년·반) 변경 API·패널 (앱 버전과 무관, Railway 반영) |

**배포:** AAB → Play → (필요 시) `MIN_ANDROID_VERSION=1.5.14` / `MIN_IOS_VERSION`  
**주의:** Production `MIN_*`는 스토어 반영 **이후**에만 상향
