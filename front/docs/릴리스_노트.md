## 1.5.0 (versionCode 9) — 2026-07-14

### 스토어용 (짧게) — 복사용

```
• 회원가입: KG 이니시스 본인인증·보호자 인증·재학증명서 가입 개선
• 이용약관·개인정보처리방침 등 법적 문서 앱 내 최신 표시
• 개인우편: 자동 반송 안내 및 재발송 경험 개선
• 타이머·시간표·등교 배너 안정성 개선
• 학생증 검수 대기·거절 화면에서 로그아웃·문의 지원
• 보안·오류 처리 강화 및 전반적인 사용성 개선
```

### 상세 (팀·내부)

| 구분 | 내용 |
|------|------|
| 회원가입 | 이니시스 간편인증 `01`, 보호자 경로, 재학증명서 signup·관리자 검수, 성인 테스트 모드 원복, SKIP은 `__DEV__`만 |
| 법적 문서 | `legal_documents` DB + 관리자 편집, 커뮤니티 가이드·청소년보호·오픈소스 통합 |
| 개인우편 | 반송 대기 기본 3시간, cron 30분 주기 |
| 타이머 | 날짜 전환 스켈레톤, 미래일 이동 차단, 캡처 워터마크 |
| 검수 UX | PENDING/REJECTED 로그아웃, 거절 시 문의하기 |
| 보안 | Access JWT 기본 15m + refresh, validation 2b, multer MIME·용량, Login 검수 기본값 PENDING |
| 관리자 | 수동 학생 계정 생성, 약관 저장 audit 수정 |

**배포:** AAB → Play → production DB migrate → `MIN_ANDROID_VERSION=1.5.0` → `git push origin production`
