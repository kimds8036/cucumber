### 상세 (팀·내부)

| 구분 | 내용 |
|------|------|
| 회원가입 | 이니시스 간편인증 `01`, 보호자 경로, 재학증명서 signup·관리자 검수, 성인 테스트 모드 원복, SKIP은 `__DEV__`만 |

| 보안 | Access JWT 기본 15m + refresh, validation 2b, multer MIME·용량, Login 검수 기본값 PENDING |
| 관리자 | 수동 학생 계정 생성, 약관 저장 audit 수정 |

```

```

### 상세 (팀·내부)

| 구분 | 내용 |
|------|------|
| 회원가입 | 4단계(약관→본인확인→계정→학생증), 학교 검색 UI, 아이디·비밀번호 규칙 실시간 안내 |
| 학생증 검수 | PENDING 게이트, 재제출 화면, 관리자 학생증 탭 SQL 수정 |
| 강제 업데이트 | App-Version 헤더·426 미들웨어(방법 A) + ForceUpdateGate(방법 B) |
| 관리자 | OTP 2FA, 환경 드롭다운, admin HTML Railway 배포 경로 정리 |
| 백엔드 | `requireMinAppVersion`, 마이그레이션 041 (`signup_student_id_submissions`) |

**배포:** AAB 업로드 → 출시 → Railway `npm run migrate` (041) → `MIN_ANDROID_VERSION=1.4.0` → `production` push. 앱·백엔드 동시 배포 권장.
