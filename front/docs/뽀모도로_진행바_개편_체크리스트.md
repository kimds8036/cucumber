# 뽀모도로 진행바 개편 체크리스트

> 대상: 타이머 탭 시간 카드의 뽀모도로 화면. `front/view/src/timer/TimerCard.jsx`의 `showPomodoro` 부분.  
> 스타일: `front/styles/timer.js`의 `createTimerStyles` (`pomoSeg*`, `pomoLabel*`, `timerTimeBreak`, `timerBtnBreak`).  
> 엔진 값: `usePomodoro()`가 주는 `phase`, `status`, `progress`, `focusCountInCycle`, `focusSkipped`, `longBreakEvery`, `nextPhase` (`front/utils/pomodoroEngine.js`의 `toView`).

목표는 사이클 점을 없애고, 한 사이클 전체를 진행바 하나로 보여 주는 것이다. 단계 표시는 진행바 아래로 내린다. 시작·일시정지, 건너뛰기, 초기화 동작은 바꾸지 않는다.

## 1. 진행바 칸 계산

긴 휴식 주기가 n이면 진행바를 n칸으로 나눈다. 앞의 n-1칸은 "집중 + 짧은 휴식" 한 쌍이고, 칸 안은 설정한 시간 비율(예: 25분 : 5분)로 나눈다. 마지막 칸은 집중만 있고, 다른 칸의 집중 부분만큼의 너비다. 긴 휴식은 이 진행바에 넣지 않는다.

예: 주기 4 → `[집중|짧은휴식] [집중|짧은휴식] [집중|짧은휴식] [집중]`

마지막 집중이 끝나 긴 휴식이 시작되면, n칸 진행바를 숨기고 같은 자리에 긴 휴식 진행바 한 줄을 보여 준다 (2-1 참고).

- [x] `TimerCard.jsx`에 칸 상태 계산 함수 `buildPomoSegments`를 둔다
- [x] 지금 몇 번째 칸인지 계산한다
  - 집중 중: `focusCountInCycle`번째 칸(0부터)의 집중 부분
  - 짧은 휴식 중(집중을 마친 뒤): `focusCountInCycle - 1`번째 칸의 휴식 부분 (집중을 마치면 엔진이 횟수를 1 올린다)
  - 짧은 휴식 중(집중을 건너뛴 뒤): `focusCountInCycle`번째 칸. 집중 부분은 비우고 휴식 부분만 차오른다 (Q1 답 (나))
  - 긴 휴식 중: 칸 계산을 하지 않고 긴 휴식 진행바를 쓴다
- [x] 엔진에 `focusSkipped` 값을 추가했다. 집중을 건너뛰면 `true`, 단계를 정상으로 마치거나 휴식을 건너뛰면 `false`. 앱을 다시 열어도 유지된다 (`serializeState` / `hydrateState`). 엔진 테스트 추가, 12개 통과
- [x] 마지막 칸은 휴식 부분 없이 집중만 그린다
- [x] 각 부분의 상태: 끝남(가득) / 진행 중(`progress`만큼) / 아직(빈칸)
- [ ] 마지막 집중을 건너뛴 경우 → **질문 Q8**

## 2. n칸 진행바

- [x] 기존 `pomoProgressTrack` / `pomoProgressFill` 한 줄짜리 진행바를 없앴다
- [x] 칸을 가로로 n개 놓고 칸 사이 간격 4, 칸 안 집중과 휴식 사이 간격 2를 둔다
- [x] 칸 너비 비율: 일반 칸은 `집중분 + 짧은휴식분`, 마지막 칸은 `집중분`. 칸 안은 `집중분 : 짧은휴식분`
- [x] 색: 끝남·진행 중 채움은 `primary`, 빈 트랙은 `textLight1`. 짧은 휴식·긴 휴식 중에는 채운 부분 전체가 `alert`
- [x] 진행 중인 부분은 `progress`(0~1)만큼 너비를 채운다
- [ ] 설정에서 긴 휴식 주기를 바꾸면(2~8회) 칸 수가 바로 바뀌는지 기기에서 확인한다

### 2-1. 긴 휴식 진행바

- [x] `phase === 'long_break'`일 때 n칸 진행바를 숨기고 같은 자리에 긴 휴식 진행바 한 줄을 보여 준다
- [x] 긴 휴식 진행바는 `progress`만큼 `alert` 색으로 채운다
- [x] 긴 휴식이 끝나거나 건너뛰면 다시 빈 n칸 진행바로 돌아간다 (엔진이 `focusCountInCycle`을 0으로 되돌림)

**Q1. 집중을 건너뛰면 그 칸을 어떻게 보여 줄까요?**  
엔진은 건너뛴 집중을 횟수에 세지 않습니다. 그래서 첫 집중을 건너뛰면 짧은 휴식인데 "끝난 집중"이 0개인 상태가 됩니다. 아래 중 하나를 골라 주세요.
- (가) 건너뛴 집중도 끝난 것처럼 칸을 채운다 (화면 기준으로 자연스러움)
- (나) 엔진 횟수 그대로 따른다 (건너뛴 칸은 비어 있고, 휴식 부분만 차오름)
답: (나) 엔진 횟수 그대로 따른다 (건너뛴 칸은 비어 있고, 휴식 부분만 차오름)

- 휴식 부분도 같은 초록 계열로 할지, 지금처럼 살구색 계열로 구분할지 알려 주세요.
답: 끝난 부분은 primary, 진행 중도 primary, 빈 트랙은 textLight1, 짧은휴식과 긴 휴식이 시작되면 지금처럼 시간과 진행바, 시작 버튼이 alert 색상으로 변경/짧은 휴식과 긴휴식일 때만 alert 색상으로 진행바가 칠해지고 집중이 시작되면 진행바는 모두 primary

**Q8. 마지막 집중을 건너뛰면 어떻게 보여 줄까요?**  
엔진은 건너뛴 집중을 횟수에 세지 않아서, 마지막 집중을 건너뛰면 긴 휴식이 아니라 짧은 휴식으로 넘어갑니다. 그런데 마지막 칸에는 휴식 부분이 없어서, 이 짧은 휴식 동안에는 진행바에 차오르는 부분이 없습니다. 지금은 이렇게 구현해 두었습니다 (문구 줄에는 "5분 휴식"이 나옵니다).
- (가) 지금처럼 둔다 (진행바 변화 없음)
- (나) 이 경우에만 긴 휴식처럼 진행바 자리에 짧은 휴식 진행바 한 줄을 보여 준다
