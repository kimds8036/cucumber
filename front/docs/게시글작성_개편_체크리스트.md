# 게시글 작성 개편 체크리스트

> 대상: `front/view/src/boardWrite.jsx`.  
> 게시판 선택: `front/components/common/SortChips.jsx`. 정렬 드롭다운은 넘기지 않는다.  
> 학생증: `useAuth().studentVerificationStatus`. 목록과 같이 `APPROVED`가 아니면 미인증이다.  
> 등록 API의 `boardType`은 지금과 같다. 전체 `national`, 학생 `student`, 학교 `school`과 `schoolId`.  
> 투표는 화면만 둔다. `FormData`에 넣지 않는다.

상단 `글쓰기` 헤더와 완료 버튼, 하단 안내 `비방/욕설 게시글은 커뮤니티 가이드에 따라 삭제될 수 있어요`는 유지한다.

---

## 0. 작업 순서

- [x] 1단계: 게시판 드롭다운을 전체/학생/학교 칩으로 바꾼다
- [x] 2단계: 미인증이면 전체만 선택되고, 학생/학교는 알림만 띄운다
- [x] 3단계: 칩 아래에 게시판별 안내 문구를 둔다
- [x] 4단계: 본문 입력과 하단 위치·사진·투표 버튼을 둔다
- [x] 5단계: 투표 상자를 본문 아래에 연다. 서버에는 보내지 않는다
- [x] 6단계: 해시태그 입력은 지금 기능 그대로 본문 아래로 옮긴다
- [x] 7단계: 추천 해시태그는 더미로만 보여 준다

---



## 1. 게시판 칩

지금 상단 툴바의 `전체게시판 / 학생게시판 / 학교게시판` 드롭다운을 뺀다.

- [x] `SortChips`에 정렬값 `sortValue`는 넘기지 않는다. 오른쪽 최신순 메뉴가 나오지 않는다
- [x] 칩은 `전체` `national`, `학생` `student`, `학교` `school`
- [x] 선택 칩은 지금 `SortChips` 그대로다. 면 `colors.textLight3`, 글자 `colors.white`, `fonts.bold`, `normalize(fontSizes.xl)`. 안 고른 칩은 흰 면, 테두리 `colors.textLight1`, 글자 `colors.textLight4`
- [x] 완료 시 매핑은 유지한다. `national`은 `boardType=national`. `student`는 `boardType=student`. `school`은 `/api/schools/me`로 `schoolId`를 붙여 `boardType=school`
- [x] 들어올 때 `route.params.boardContext`가 `student` 또는 `school`이면 그 칩을 고른다. 없으면 `전체`

---



## 2. 학생증 없을 때

- [x] `studentVerificationStatus !== 'APPROVED'`이면 `전체`만 선택된 상태로 둔다. 검수 중(`PENDING`)도 같다. 진입 파라미터가 학생/학교여도 `전체`로 시작한다
- [x] `학생` 또는 `학교`를 누르면 `Alert` 제목 `알림`, 내용 `학생증 인증을 해주세요`. 선택은 `전체`에서 바뀌지 않는다
- [x] `APPROVED`이면 세 칩 모두 선택할 수 있다

---



## 3. 안내 문구

칩 바로 아래에 한 줄. 선택한 칩만 보여 준다.


| 칩   | 문구                 |
| --- | ------------------ |
| 전체  | 모든 사람들이 볼 수 있어요    |
| 학생  | 학생들만 볼 수 있어요       |
| 학교  | 우리 학교 학생들만 볼 수 있어요 |


- [x] 글자는 `fonts.regular`, `normalize(fontSizes.lg)`, `colors.textLight4`
- [x] 좌우 여백은 칩과 같이 `width * 0.04`

---



## 4. 본문과 하단 버튼

해시태그 툴바 아이콘과 게시판 드롭다운은 뺀다. 위치·사진 동작은 지금 함수를 그대로 쓴다.

- [x] 안내 문구 아래에 본문 `TextInput`. placeholder `내용을 입력해 주세요`
- [x] 입력 상자 하단에 버튼 세 개. 위치, 사진, 투표
- [x] 위치는 `handleToggleLocation`. 켜지면 `location-sharp`과 `colors.primary`, 끄면 `location-outline`과 `colors.textLight4`. 등록 시 좌표를 붙이는 조건도 그대로다
- [x] 사진은 `handlePickPostImages`. 최대 5장. 고른 미리보기와 삭제는 본문 상자 안, 글 입력과 하단 버튼 사이에 둔다
- [x] 투표가 닫혀 있으면 누르면 본문 상자 바로 아래에 투표 상자를 연다
- [x] 투표가 열려 있을 때 다시 누르면 `삭제할까요?` 알림을 띄운다. `삭제`는 상자를 닫고 입력값을 지운다. `취소`는 상자를 유지한다

---



## 5. 투표 상자

참고 화면의 제목 칸과 `1일 후 마감`은 넣지 않는다. 서버 전송도 하지 않는다.

- [x] 면은 `colors.primaryLight2`, 모서리 `normalize(12)`
- [x] 항목은 처음에 `항목 1`, `항목 2` 두 개. 각각 입력칸. 개수는 최소 2개, 최대 10개
- [x] 항목이 3개 이상일 때만 각 항목을 지울 수 있다. 2개일 때는 삭제하지 않는다
- [x] `+ 항목 추가`는 점선 칸. 누르면 `항목 3`부터 늘어난다. 10개면 추가하지 않는다
- [x] `복수 선택`은 켜고 끄는 칩. 기본은 꺼짐
- [x] 완료를 눌러도 투표 값은 `FormData`에 넣지 않는다

---



## 6. 해시태그 입력

본문(투표 상자가 열려 있으면 그 아래) 다음에 둔다. 로직은 유지한다.

- [x] `#` 접두와 입력칸 placeholder `해시태그 입력(선택)`, 오른쪽 `n/5`
- [x] 최대 5개. 이미 있으면 무시. 띄어쓰기·엔터로 추가
- [x] 입력 중 `/api/posts/tags/search` 추천은 유지한다
- [x] 고른 태그는 `#이름` 칩과 삭제 버튼으로 보여 준다. 등록 시 `tags[]`로 보낸다

---



## 7. 추천 해시태그

입력 추천과 별도다. 추천 시스템은 나중에 붙인다.

- [x] 제목 `추천 해시태그`
- [x] 더미는 `#중간고사`, `#수행평가`, `#급식` 세 개. 칩 면은 `colors.primaryLight2`, 글자는 `colors.primaryDark`
- [x] 칩을 누르면 6단계와 같이 선택 목록에 넣는다. 5개 제한도 같다
