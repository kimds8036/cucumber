# 게시글 상세 댓글 체크리스트

> 대상: `front/view/src/board/BoardCommentTree.jsx`, `front/view/src/boardDetail.jsx`.  
> 스타일: `front/styles/board.style.js`의 `comment*`.  
> 참고 화면의 최신순, 프로필 아이콘, 작성자 칩은 넣지 않는다. 대댓글은 그 화면을 따르지 않고 댓글과 같은 배치에 왼쪽 화살표만 둔다.

게시글 본문, 광고 배너, 하단 입력은 이번 범위가 아니다.

---

## 0. 작업 순서

- [x] 1단계: 댓글 바깥 여백을 빼고, 좌우 `width * 0.04` 거터만 남긴다
- [x] 2단계: `댓글` + 개수 헤더와 위쪽 `colors.textLight1` 경계선을 넣는다
- [x] 3단계: 댓글을 본문 헤더처럼 배치하고, 마지막을 뺀 아래에 경계선을 넣는다
- [x] 4단계: 대댓글은 댓글과 같은 배치로 두고, 왼쪽 화살표는 유지한다
- [x] 5단계: 고정 댓글은 목록 맨 위에 `colors.primaryLight2` 배경과 `normalize(15)` 모서리를 준다

---

## 1. 바깥 여백

댓글은 목록 아이템에서 이미 `paddingHorizontal: width * 0.04`를 쓴다. 그 안쪽에 말풍선·블록 여백이 더 있다.

| 스타일           | 지금                                       | 변경                                                                         |
| ---------------- | ------------------------------------------ | ---------------------------------------------------------------------------- |
| 목록 아이템 좌우 | `width * 0.04`                             | 유지. 게시글 본문 `contentSection`과 같다                                    |
| `commentBubble`  | 상하 `normalize(10)`, 좌우 `normalize(14)` | 제거                                                                         |
| `commentBlock`   | 좌우 `width * 0.01`, 상하 `normalize(4)`   | 제거                                                                         |
| `commentItem`    | `marginBottom: normalize(6)`               | 제거. 간격은 아래 경계선이 대신한다                                          |
| `commentSection` | 상하 `normalize(10)`, 좌우 `width * 0.04`  | 목록에는 적용하지 않는다. 스켈레톤의 추가 `paddingTop: normalize(10)`도 뺀다 |

- [x] 위 표의 바깥 여백만 제거한다
- [x] 작성자·본문·푸터 사이 간격은 유지한다. 작성자 행 `marginBottom: normalize(6)`, 본문 `marginBottom: normalize(6)`, 푸터 왼쪽 `gap: normalize(12)`

---

## 2. 댓글 헤더

광고 배너 아래, 첫 댓글 위에 한 줄을 둔다. 댓글이 없어도 헤더는 보인다.

- [x] 왼쪽 문구는 `댓글`과 개수다. 개수는 화면에 있는 댓글과 대댓글을 모두 센다. `post.comments`는 대댓글 작성 때도 1이 오르므로 같은 값이어야 한다
- [x] 글자는 `fonts.bold`, `normalize(fontSizes.xl)`, `colors.text`. `댓글`과 숫자 사이는 `normalize(4)`
- [x] 좌우 여백은 `width * 0.04`. 위아래는 `normalize(12)`
- [x] 위쪽 경계선은 `borderTopWidth: 1`, `borderTopColor: colors.textLight1`

---

## 3. 댓글 한 줄

위는 게시글 본문 헤더와 같다. `익명`은 bold, `익명`과 시간 사이의 `•`는 없다.

- [x] 이름(`익명 N` 또는 `작성자`)은 bold다. `익명`은 `fonts.bold`, `normalize(fontSizes.lg)`, `colors.textLight4`. `작성자`는 지금처럼 `detailAuthor`(`fonts.bold`, `colors.alert`)
- [x] 장착 뱃지는 유지한다. `marginLeft: normalize(3)`, 크기 `normalize(13)`
- [x] `detailDot`(`•`)을 댓글 헤더에서 뺀다. 시간 앞은 `marginLeft: normalize(6)`
- [x] 가운데는 댓글 본문. 글자 크기 `normalize(fontSizes.xl)`, `fonts.regular`, `colors.text`, `lineHeight: normalize(20)`
- [x] 왼쪽 아래는 좋아요, 대댓글 수, `댓글 달기` 순이다
  - 좋아요: 하트 `normalize(13)`, `colors.alert`, 숫자 `detailStatText`. 간격 `normalize(4)`
  - 대댓글 수: `chatbubble-outline` `normalize(15)`, `colors.primary`, 숫자는 그 댓글 아래 대댓글 전체 개수
  - `댓글 달기`: 지금 버튼. `normalize(fontSizes.xl)`, `fonts.regular`, `colors.textLight4`
- [x] 오른쪽 아래는 메뉴. `dots-three-vertical` `normalize(14)`, `colors.textLight4`
- [x] 아래 경계선은 `borderBottomWidth: 1`, `borderBottomColor: colors.textLight1`. 목록에서 가장 마지막 댓글·대댓글에는 넣지 않는다
- [x] 답글 입력 중인 배경 `colors.primaryLight3`는 유지한다

---

## 4. 대댓글

배치와 글자, 푸터, 경계선은 3단계와 같다. 참고 화면의 말풍선·오른쪽 하트는 쓰지 않는다.

- [x] 왼쪽 화살표 `return-down-forward`를 유지한다. 크기 `normalize(16)`, 색 `colors.textLight4`, 오른쪽 간격 `normalize(6)`, 위 간격 `normalize(7)`
- [x] 대댓글 줄의 `marginLeft: normalize(12)`와 가로 `flex: 1`은 유지한다
- [x] 본문 앞 `@부모 이름`은 유지한다. `fonts.bold`, `colors.primary`

---

## 5. 고정 댓글

고정 댓글은 이미 같은 단계 안에서 위로 정렬된다. 그 순서는 바꾸지 않는다.

- [x] `isPinned`인 댓글·대댓글 배경은 `colors.primaryLight2`
- [x] 모서리는 `borderRadius: normalize(15)`
- [x] 핀 아이콘은 유지한다
- [x] 아래에 다른 댓글이 있어도 경계선은 두지 않는다
