# 디자인 개편 계획

작성: 2026-09-25  
브랜치: `feat/design-overhaul`  
상태: **1차 반영 · 2차(메시지·학교·타이머·프로필 사진) 반영 중** (2026-09-25)

확정:
- 인기 칸 **1장**, 기존 `sort=popular` API
- 목록 **거리 칩 유지**
- 바텀바 라벨도 검정, **위 삼각형 삭제**
- 광고 없을 때 팁 없음 — **빈 슬롯만 확보** (에셋은 나중에)

관련: `현재_메인탭_화면_분석.md` (현행 기능 맵)

---

## 1. 한 줄

홈 게시판의 **전체/학생은 필터 줄로**, **최신·인기·거리는 우측 드롭다운**으로 옮기고, 헤더·글 카드·바텀바를 더 담백하게 바꾼다. 기능은 유지한다.

---

## 2. 목표 화면 (게시판 홈, 위 → 아래)

```
[ 게시판                              검색  벨 ]     ← 헤더. 아이콘만, 원 없음
[              광고 배너 자리              ]     ← 헤더와 필터 사이
[ 전체 ] [ 학생 ]              [ 최신순 ▾ ]     ← 피드 + 정렬
[ 인기 ] 오늘의 인기 글 1장(고정)               ← 목록 최상단
[ 본문 … ]
[ ♥ n   💬 n   🔖 n                 시간 ]     ← 카드 푸터
…
[            (플로팅 바텀바)            ]
```

탭바는 화면 하단에서 떠 있다. 글쓰기 FAB는 바 위에 둔다.

---

## 3. 변경 항목

### 3.1 헤더 아이콘

**현재:** 검색·벨이 연두 원 + 테두리 (`frame.style` `iconButton`, `colors.green`).

**변경:**
- 원형 배경·테두리 삭제
- 아이콘 색 **검정 계열** (`textPrimary`)으로 통일
- 벨 미읽음 **빨간 점**은 유지
- 등교 칩은 이번 범위 밖 (조건부 표시 그대로)

**파일:** `view/frame/mainHeader.jsx`, `styles/frame.style.js`  
**영향:** 다섯 탭 모두 같은 헤더를 씀.

---

### 3.2 게시판 헤더 타이틀

**현재:** 보드 탭만 「전체 ↔ 학생」 스왑. 상수 타이틀은 `전체 게시판`.

**변경:**
- 스왑 UI·팁 말풍선 제거
- 좌측 고정 텍스트 **「게시판」**
- `MAIN_TAB_TITLES.board` → `'게시판'`

전체/학생 **상태와 인증 게이트는 헤더가 아니라 아래 칩**이 담당.

**파일:** `mainHeader.jsx`, `MainShellContext.jsx`

---

### 3.3 필터 줄 (칩 + 드롭다운)

**현재:** 본문 상단 칩 3개 — 최신 / 인기 / 근처. 전체·학생은 헤더.

**변경:**

| 자리 | 컨트롤 | 하는 일 |
|------|--------|---------|
| 좌 | 칩 **전체** / **학생** | `boardFeedMode` `national` \| `student`. 학생+미인증 → 기존 CTA |
| 우 | 드롭다운 | **최신순 / 인기순 / 거리순** (`latest` / `popular` / `nearby`) |

- 기본값: 전체 + 최신순
- 거리순 = 지금 「근처」와 동일 (좌표·권한 필요, 거부 시 안내)
- 학생 칩을 눌러도 인증 실패하면 전체를 다시 고른 것처럼 동작 (현행과 같음)

**파일:** `view/src/boardAll.jsx`, `styles/board.style.js`  
드롭다운은 새 작은 컴포넌트로 빼도 됨.

---

### 3.4 광고 배너 자리

**위치:** 헤더 **아래**, 전체/학생·정렬 줄 **위**. 리스트 안이 아님.

**현재:** 리스트 헤더에 `TopAdBanner` → 광고 없으면 팁.

**변경:**
- 그 슬롯을 **필터 위로 이동**
- 높이는 확보만. 광고 API 전엔 팁 또는 빈 플레이스홀더
- 리스트 안 기존 팁 배너는 빼서 자리가 겹치지 않게

**파일:** `boardAll.jsx`, `components/ads/TopAdBanner.jsx` (또는 동일 슬롯 재사용)

---

### 3.5 하루 인기 글 (목록 고정)

**위치:** 필터 아래, **일반 목록의 맨 위**. 스크롤과 같이 움직임(헤더 고정 아님).

**표시:**
- 카드 좌측 상단 라벨 **「인기」**
- 오늘(또는 최근 24시간) 인기 글 **1장**
- 아래 목록과 같은 새 카드 구조
- 탭하면 기존처럼 `BoardDetail`
- 없거나 실패하면 슬롯 숨김

**데이터 (구현 시 선택):**
1. 기존 `GET /api/posts?sort=popular` + 클라이언트에서 오늘만 — 빠름, 부정확할 수 있음
2. API에 `period=day` 또는 `GET /api/posts/daily-popular` — 정확, 백엔드 필요

피드가 **학생**이면 인기도 학생 보드 기준으로. 전체면 전체 기준.

필터가 인기순이어도 이 고정 칸은 따로 둔다. 같은 글이 목록에 또 나오면 **목록에서 한 번만** 빼는 편이 낫다.

---

### 3.6 게시글 카드 구조

**현재 (위 → 아래):**
- 익명(+배지) · 시간 · (위치) / 거리 칩
- 본문 3줄 + (있으면) 우측 썸네일
- 태그
- 좋아요·댓글·스크랩 (0이면 숨김)

**변경:**
- **익명(작성자) 줄 삭제.** 장착 배지도 목록에서는 빼는 쪽
- 본문·태그·썸네일은 유지
- 카드 하단 한 줄: **좋아요 | 댓글 | 스크랩** (좌, 가로) …… **시간** (우 끝)
- 카운트 0이어도 아이콘은 보여 주는 쪽으로 (빈 카드가 되지 않게)
- 목록에서 좋아요/스크랩은 여전히 **누르지 않음**. 카드 전체 → 상세
- 거리 칩·위치 문구는 이번 요청에 없음 → **일단 유지**, 자리만 본문 쪽(시간 옆이 아니라 본문 위/우)으로 조정 가능

상세 화면(`BoardDetail`)의 익명·시간은 **이번 범위 밖**.

**파일:** `components/Boardpostcard.jsx`, `styles/board.style.js`

---

### 3.7 바텀바 플로팅

**현재:** 화면 맨 아래 전폭, 위쪽 초록 삼각형, 활성 아이콘 `primary` 초록.

**변경:**
- 바를 하단에서 **띄움** (좌우·아래 여백, 둥근 알약/바, 얕은 그림자)
- 활성: **초록 제거**, 아이콘·라벨 **검정 계열**
- 비활성: 지금처럼 회색(`textSecondary`) 유지 제안
- 위쪽 초록 삼각형은 플로팅과 안 맞음 → **제거** 제안
- 메시지 로고 SVG도 활성일 때 검정으로

**파일:** `view/frame/mainFooter.jsx`, `styles/frame.style.js`, `view/src/MainScreen.jsx` (하단 inset·FAB 간격)

FAB(+)가 바에 가리지 않게 올린다. 다른 탭 본문도 하단 패딩을 맞춤.

## 6. 구현 순서 제안

1. 헤더 아이콘 플랫 + 타이틀 「게시판」 (스왑 삭제)  
2. 필터 줄: 전체/학생 칩 + 정렬 드롭다운  
3. 광고 슬롯을 헤더~필터 사이로  
4. 글 카드 푸터(통계 가로 + 시간 우측), 익명 제거  
5. 일일 인기 1장 + 「인기」 라벨  
6. 바텀바 플로팅 + 활성 검정, FAB·본문 패딩  

1→2는 헤더/필터가 겹치므로 같이 가는 편이 안전하다.

## 7. 확정 사항

1. 인기 칸: 기존 `GET /api/posts?sort=popular` 1장. 전체/학생 보드 각각.  
   기준은 학교 보드가 아니라 **전체·학생 피드** — KST 최근 3일 좋아요+댓글+스크랩 합 **6회 이상**, 참여 많은 순.  
   조건 맞는 글이 없으면 칸을 숨긴다.  
2. 거리 칩 유지  
3. 바텀바 아이콘·라벨 모두 검정 계열, 삼각형 없음  
4. 광고 슬롯은 높이만 확보. 팁 배너는 넣지 않음

## 11. 우리 학교

**현재:** 학교 카드 → 급식 → **공부 잔디밭** → 학교 게시판/우편함 바로가기 → 실시간 인기

**목표 위 → 아래**

```
[ 우리 학교                      검색  벨 ]
[ 학교 카드 ]
[ 급식 ]
[           광고 배너 자리           ]     ← 급식과 학교 게시판 사이
```

## 12. 타이머

가장 큰 화면 개편. 날짜 ◀▶ 는 없애고, 본문은 **오늘** 기준으로 돌린다.

### 12.1 목표 위 → 아래

```
[ 타이머                         검색  벨 ]
[ 친구 추가 · 친구 스토리 바 ]
[           광고 배너 자리           ]     ← 친구 바와 타이머 카드 사이
[          큰 시간  05:35:16         ]
[ 시작/일시정지          ⚙ 설정      ]     ← 날짜 줄 삭제. 우측 상단 톱니
[ 스터디룸 ] [ 연속 공부일 n ] [ 위클리 n% ]

[ ▌ ]  ← 좌측 세로 책갈피 4탭          [ 탭 내용 ]
  1 투두
  2 타임라인
  3 잔디(개인·한달)
  4 위클리
```

레이아웃 확정: **카드 안 우측 상단 톱니** + **카드 아래(또는 카드 안 하단) 스터디룸·연속일·위클리% 3칸**.  
「톱니 통계」는 기능 이름이 아님. 톱니(설정)와 숫자 3칸을 어디에 둘지 묻던 말이었다.

### 12.2 삭제 · 이동

| 현재 | 처리 |
|------|------|
| 날짜 ◀▶ · 달력 | 타이머 카드에서 **삭제**. 투두는 **투두 탭에서 날짜를 바꿔** 과거/오늘 확인 |
| 날짜 줄의 다운로드 | **공부 타임라인** 헤더로 이동 (톱니 아님) |
| 날짜 줄의 스터디룸 입장 | 통계 칸 「스터디룸」으로 이동. **타이머 ON일 때만** 입장 (현행 게이트 유지) |
| 우측 「공부 기록」 2열 | 탭 2 「공부 타임라인」으로 이동 |

친구 추가 모달·쿡·DM은 그대로. 광고는 **스토리 바 아래, 타이머 카드 위**.

### 12.3 톱니바퀴 (타이머 우측 상단)

탭하면 시트 또는 설정 화면.

| 항목 | 의미 | 구현 메모 |
|------|------|-----------|
| 뽀모도로 모드 | 집중/휴식 사이클 | **신규**. 1차는 토글+시간 프리셋 UI, 실제 사이클은 이어서 |
| 허용 앱 설정 | 타이머 중 쓸 수 있는 앱 | **신규**. 안드로이드 사용정보/오버레이 권한 필요. iOS는 제한적 → 안내만 둘 수 있음 |

플래너 다운로드는 톱니가 아니라 **공부 타임라인**에 둔다.

### 12.4 통계 3칸 (타이머 세션)

| 칸 | 동작 |
|----|------|
| 스터디룸 | 실행 중이면 `TimerAniLab`. 꺼져 있으면 비활성 |
| 연속 공부일 | `study_sessions` 있는 날을 KST로 이어 센 숫자. 표시만 (탭 동작 없음 또는 잔디 탭으로) |
| 위클리 달성율 | **위클리 탭 체크리스트** 이번 주 완료/전체 %. 타이머 카드 **우측 하단**에도 같은 숫자 |

### 12.5 좌측 세로 책갈피 4탭

본문 왼쪽 끝에 세로로 붙은 탭. 한 번에 하나만 연다.

| # | 이름 | 내용 |
|---|------|------|
| 1 | 투두리스트 | 지금 좌측 투두 + **날짜 전환**(과거 투두 확인). 타이머 카드의 ◀▶는 없음 |
| 2 | 공부 타임라인 | 지금 우측 「공부 기록」 10분 슬롯. 이름만 변경 |
| 3 | 공부잔디 | **개인**, **한달**. 학교 잔디와 분리. 타이머 쓴 날 색 |
| 4 | 위클리 | 세로 **월→일**. 요일마다 할 일 체크리스트 추가/체크/삭제 |

위클리 달성율 = `체크된 개수 / 이번 주 체크박스 전체 개수`. 항목이 0개면 0% 또는 숨김. 빈 요일도 분모에 안 넣고, **만들어진 칸만** 센다.

위클리 데이터는 지금 없음 → 새 테이블 또는 유저 JSON. 제안:

```
user_weekly_tasks
  user_id, week_start (KST 월요일), weekday (0-6),
  title, is_done, sort_order
```

개인 잔디: `study_sessions`를 그달 `day_key`로 묶어 기존 `StudyGrassMap` 재사용.

**파일:** `timer/TimerContent.jsx`, `timer/TimerLiveViews.jsx`, `timer/useTimerDay.js`, `styles/timer.js`, (신규) weekly API·잔디 집계

**범위가 커서 구현은** 레이아웃·탭 골격 → 위클리 API → 뽀모도로/허용앱 순으로 쪼갠다.

## 13. 마이페이지 — 프로필 사진 1장

광고는 없음. 이 기능만.

| 항목 | 내용 |
|------|------|
| 설정 | 마이페이지 프로필 카드 아바타 탭 → 앨범 1장. 바꾸기/삭제 |
| 저장 | `users`에 사진 URL (Cloudinary 등). 기존 `color_id` 새싹은 **사진 없을 때** 폴백 |
| 게시판 | **안 보임**. 익명 유지 |
| 타이머 | 친구 스토리·쿡 시트에서 상대 사진 |
| 쪽지 | **익명 쪽지 = 새싹**. DM(친구)만 사진 |
| 개인 우편 | **익명 수신 = 새싹**. 상대를 아는 방만 사진 |

상세 채팅·우편 말풍선 옆 아바타도 같은 규칙.

**파일:** `Profilecard.jsx`, `mypage.jsx`, `FriendStoryBar` / `timerFriendModals`, `Message.jsx`, (백) users 컬럼 + 업로드 API

게시글·댓글·학교 인기글에는 넣지 않는다.

## 15. 2차 구현 순서 제안

1. 메시지 칩 + 광고 슬롯 (게시판과 동일 패턴, 작음)  
2. 학교: 잔디 제거 + 급식~바로가기 광고 슬롯  
3. 타이머: 날짜 삭제, 광고, 톱니 자리, 통계 3칸, 좌측 4탭 골격 (1·2탭은 기존 UI 이식)  
4. 개인 잔디(한달)  
5. 위클리 체크리스트 + 달성율  
6. 프로필 사진 업로드 + 타이머/DM/아는 우편에만 노출  
7. 뽀모도로 · 허용 앱 (별도, 네이티브 권한)

## 16. 2차 확정 (2026-09-25)

1. 타이머 카드 날짜 ◀▶는 없앰. **과거 투두는 투두 탭에서** 날짜 바꿔 확인  
2. 플래너 다운로드는 **공부 타임라인** (톱니 아님)  
3. 「톱니 통계」는 오해. 톱니=설정, 통계=스터디룸·연속일·위클리% 3칸. 카드 상단 톱니 + 그 아래 3칸  
4. 위클리 달성율 분모 = **이번 주 체크박스 전체 개수**  
5. 익명은 **전부 새싹** (쪽지·우편·게시판)  
6. 홈 위젯은 급식·시간표용이지 **학교 잔디를 안 씀**. 학교 화면 잔디는 그냥 빼도 위젯과 무관. API는 다른 학교 화면(`otherschool`)이 쓰면 그건 유지  

위클리 할 일은 요일별 자유 체크리스트 (투두 과목과 연결하지 않음).
