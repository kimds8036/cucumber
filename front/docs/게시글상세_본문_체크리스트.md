# 게시글 상세 본문 체크리스트

> 대상: `front/view/src/board/BoardPostContent.jsx`.  
> 스타일: `front/styles/board.style.js`의 `detail*` .  
> 위치 뱃지: `front/components/DistanceBadge.jsx`. 목록 카드는 `front/components/Boardpostcard.jsx`.  
> 사진 모서리 기준: 상세에서 2장 이상일 때 `PostImageSlider`에 넘기는 `borderRadius={normalize(10)}`.

댓글, 광고 배너, 하단 입력, 서브헤더는 이번 범위가 아니다.

---

## 0. 작업 순서

- [x] 1단계: `익명`을 bold로 바꾸고, `익명`과 시간 사이의 `•`를 뺀다
- [x] 2단계: 오른쪽 거리 뱃지를 목록 카드와 같은 수치로 맞춘다
- [x] 3단계: 세로가 가로보다 긴 사진만 정사각형으로 잘라 보여 준다. 누르면 전체 이미지는 그대로다
- [x] 4단계: 사진 모서리를 `normalize(10)`으로 맞춘다

---

## 1. 작성자와 시간

지금 왼쪽은 `익명` · 장착 뱃지 · `•` · 시간이다. `익명`은 `detailAuthorAnonymous`이고 `fonts.regular`다.

- [x] `detailAuthorAnonymous`의 `fontFamily`를 `fonts.bold`로 바꾼다. 크기 `normalize(fontSizes.lg)`, 색 `colors.textLight4`는 유지한다
- [x] `detailDot`(`•`)을 본문 헤더에서 뺀다
- [x] 장착 뱃지는 그대로 둔다. 시간과 붙지 않게 시간 앞에 `marginLeft: normalize(6)`을 둔다. 빼는 구분점의 좌우 간격과 같다

---

## 2. 위치 뱃지

상세는 `DistanceBadge`를 쓰지만 `chipStyle`을 넘기지 않는다. 목록 카드는 `wrapStyle={styles.distanceBadgeWrap}`, `chipStyle={styles.distanceBadgeChip}`을 넘긴다. 상세도 이 두 스타일을 그대로 넘긴다.

화면에 그려지는 칩 수치는 `DistanceBadge`가 다시 지정한다. 아래가 목록 카드에 보이는 값이다.

| 항목 | 수치 |
| --- | --- |
| 아이콘 | `location-on`, `normalize(10)` |
| 거리 숫자 | `normalize(10)`, `fonts.regular` |
| 단위 `km` | `normalize(10)`, `fonts.regular` |
| 아이콘·글자 간격 | `normalize(1)` |
| 좌우 안쪽 여백 | `normalize(7)` |
| 상하 안쪽 여백 | `normalize(2)` |
| 모서리 | `normalize(10)` |
| 왼쪽 바깥 간격 | `normalize(8)` (`distanceBadgeWrap.marginLeft`) |
| 위치 있음 | 면 `colors.primaryLight3`, 글·아이콘 `colors.primaryDark` |
| 위치 없음·계산 중 | 면 `colors.scrap`, 글·아이콘 `colors.scrapDark` |

- [x] 상세 `DistanceBadge`에 목록과 같은 `distanceBadgeWrap`, `distanceBadgeChip`을 넘긴다
- [x] 뱃지 표시 조건은 유지한다. 위치 권한이 있을 때만 보이고, 좌표가 없으면 주황, 계산 중이면 점 로딩이다

---

## 3. 사진 자르기

1장은 지금 가로 100%에 원본 비율로 그린다. 비율을 모르면 높이는 `normalize(260)`이다. 2장 이상은 이미 정사각 타일이다.

- [x] 가로 ≥ 세로는 지금처럼 원본 비율로 보여 준다
- [x] 세로 > 가로일 때만 정사각형으로 자른다. 가로는 본문 너비 100%, 높이는 그 가로와 같다. `resizeMode`는 `cover`
- [x] 누르면 지금처럼 `ImageViewer`에서 잘리지 않은 사진을 보여 준다
- [x] 2장 이상 캐러셀의 타일 크기 `Math.min(너비의 70%, normalize(200) * 1.15)`는 바꾸지 않는다

---

## 4. 사진 모서리

2장 이상 캐러셀은 `BoardPostContent`에서 `borderRadius={normalize(10)}`을 넘긴다. `PostImageSlider`가 각 사진에 그 값을 넣는다. 1장에는 모서리가 없다.

- [x] 1장 사진에도 `borderRadius: normalize(10)`을 넣는다. 정사각형으로 자른 경우도 같다
- [x] 2장 이상도 `normalize(10)`을 유지한다
- [x] 잘린 모서리가 사각으로 비치지 않게, 사진을 감싼 쪽에 `overflow: 'hidden'`과 같은 `normalize(10)`을 둔다
