# 색상 개편 체크리스트

> 범위: `front/styles/colors.js` 토큰을 먼저 교체한 뒤, 스타일 파일의 `colors.*` 키를 같은 매핑으로 바꾼다.  
> 1단계(`colors` 객체 교체)까지 반영했다. 스타일 키는 아직 그대로다.  
> 키 표기는 기존 파일과 같이 camelCase (`primaryDark`, `primaryLight6`, `textLight1`).

---

## 0. 작업 순서

- [x] 1단계: `colors.js`의 `colors` 객체만 아래 구조로 교체
- [x] 2단계: 스타일 파일의 삭제·이름변경 키를 매핑표대로 교체
- [x] 3단계: 스타일 파일 밖에 남은 `colors.*` 참조를 같은 매핑으로 교체 (키를 지우면 화면이 깨지므로 필수)
- [ ] 유지 확인: `green`, `greenDark`, 로고 컬러, `TIMETABLE_SUBJECT_COLORS`, `PROFILE_COLORS`, `fonts`, `fontSizes`

## 2. 삭제 키 → 지정 대체

언급되지 않은 키는 삭제한다. 투명색은 흰 배경 위에 합성한 뒤, 새 팔레트에서 채널 차이가 가장 작은 색으로 지정했다.

이름만 바뀌는 키:

| 기존 | 대체 | 이유 |
|------|------|------|
| `background` `#fff` | `white` | `#FFFFFF` 통일 |
| `textWhite` `#fff` | `white` | 동일. `white`로 합침 |
| `shadow` `#000000` | `text` | `#000000` 통일 |

primary 투명 단계 → 새 솔리드 단계 (흰 배경 합성값이 새 hex와 거의 일치):

| 기존 | 합성 근사 | 대체 |
|------|-----------|------|
| `primaryLight70` | `#C0E5B5` | `primaryLight6` |
| `primaryLight50` | `#D2ECCA` | `primaryLight5` |
| `primaryLight30` | `#E4F4DF` | `primaryLight4` |
| `primaryLight20` | `#EDF8EA` | `primaryLight3` |
| `primaryLight10` | `#F6FBF4` | `primaryLight2` |
| `primaryLight5` | `#FBFDFA` | `primaryLight1` |

주의: `primaryLight5`는 키 이름이 그대로라 값만 바꾸면 안 된다. 기존 5% 투명은 `primaryLight1`로 옮긴다.

## 5. 바꾸면 눈에 띄는 차이

- [x] 본문색 `textPrimary` `#272A26`는 `text` `#000000`가 된다. 기존 `shadow`도 같은 `text`로 합쳐진다.
- [ ] `textLight5`(5% 회색)와 `surface`(거의 흰색 카드)가 둘 다 `textLight1` `#E3E3E3`로 모인다. 구분선·카드 배경이 이전보다 진해진다.
- [ ] 딤 레이어(`overlay*`)가 반투명 검정에서 불투명 회색이 된다. 뒤 내용이 비치지 않는다.
- [ ] 캐시 거리 칩이 반투명 주황+짙은 갈색에서 `scrap` / `scrapDark` 불투명이 된다.
