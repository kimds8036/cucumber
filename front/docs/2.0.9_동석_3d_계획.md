# 2.0.9 동석 3D 계획

작성일: 2026-10-30  
브랜치: `2.0.9-동석-3d` (`2.0.9-동석`에서 분기)  
이 브랜치에서만 실험한다. `develop`, `production`, 스토어 빌드에는 올리지 않는다.

교실 스프라이트 방을, 고정 카메라로 보는 자연 속 공부 장소로 바꾼다. 완성본 정원은 8명이다.

## 지금 동석

화면은 `front/view/src/TimerAniLab.jsx`다. 시간대별 교실 그림 위에 남녀 스프라이트를 올리고, 자리는 4열×4행 16석이다. 배치 계산은 `front/utils/studyRoomLayout.js`, 배경은 `front/utils/studyRoomClassroomBg.js`다. 3D 라이브러리는 없다.

서버는 이미 그림 없이 짧은 메시지만 보낸다.

- 입장 `study_room:join`, 퇴장 `study_room:leave`
- 타이머 상태 `study_room_timer_status`
- 자리 의미는 공부 중(`study`)과 쉬는 중(`break`)

한 방 정원은 서버와 클라이언트가 모두 16이다 (`STUDY_ROOM_CAPACITY`).

## 그대로 두는 것

- 언어는 앱과 같은 JavaScript다.
- 입장·퇴장·공부/쉼 메시지는 지금 소켓을 쓴다. 3D용 서버를 새로 만들지 않는다.
- 프로필 팁, 뽀모도로 팁, 타이머 UI는 React Native 오버레이로 둔다. 3D 장면 안에 글자를 넣지 않는다.

## 완성본에서 보이는 것

보이는 무대와 인형만 바꾼다. 계산은 각자 폰이 한다.

장면은 디오라마다. 카메라는 고정하고, 화면의 위·가운데·아래는 멀리·중간·가까이 거리다.

| 화면 | 거리 | 내용 | 사람 |
|---|---|---|---|
| 위 | 멀리 | 나무, 절벽, 물길, 장식 | 가지 않음. 배경 |
| 가운데 | 중간 | 열린 건물(정자), 정원, 테이블, 가로등 | 여기 앉음 |
| 아래 | 가까이 | 계단, 다리, 산책로 | 입장할 때 이 길로 들어옴 |

분위기는 혼합이다. 정자 안과 야외가 한 장면에 같이 있다. 학교 교실 책상은 쓰지 않는다.

## 자리 8개

정원 8명. 자리 종류는 두 가지다.

**같이 앉는 테이블 1개, 4명.** 정자 안에 둔다. 한 테이블을 마주 보거나 둘러 앉는다. 슬롯은 4개로, 각 사람의 위치만 다르다.

**혼자 앉는 자리 4개.** 정원과 산책로에 흩어 둔다. 생김새는 자리마다 다르게 한다.

1. 벤치
2. 소파
3. 나무 아래 1인 의자
4. 물가 쪽 평상

빈 슬롯 하나에 한 명이다. 지금처럼 빈 자리 중 하나를 고른다. 테이블 4칸과 개인 자리 4칸은 같은 정원 안의 슬롯이고, 어느 쪽이 우선인지는 두지 않는다.

이 브랜치에서 서버 정원과 `STUDY_ROOM_CAPACITY`도 8로 맞춘다. `2.0.9-동석`의 16석 방은 이 브랜치를 합치기 전까지 유지된다.

## 상태

- 공부 중: 그 슬롯에 앉아 있다.
- 쉬는 중: 같은 슬롯에서 일어선다. 다른 장소로 걷지 않는다.
- 입장: 가까이 산책로 쪽에 나타났다가 자기 슬롯으로 간다.
- 퇴장: 슬롯에서 사라진 뒤 장면에서 빠진다.

캐릭터는 한 종류를 8번 쓰고, 색만 바꾼다.

## 도구

| 역할 | 도구 |
|---|---|
| 화면 코드 | React Three Fiber (three.js) |
| 모델 | Kenney, Poly Pizza. 라이선스는 CC0, 또는 앱 배포가 허용된 것만 |
| 배치·수정 | Blender. 무료 |
| 결과 파일 | 장면 하나를 `.glb`로 묶어 폰이 한 번만 읽게 한다 |
| 브라우저 확인 | 작은 웹 페이지로 먼저 만든다 |
| 앱에 넣기 | `react-native-webview`로 그 페이지를 띄운다 |

Sketchfab은 상업 이용이 막힌 모델이 많다. 받을 때마다 라이선스를 확인한다.

Unity, Godot, C#은 쓰지 않는다. Expo 앱 안에 넣기 어렵고, 자리 앉히기에는 과하다.

## 진행

매일 고치는 작업은 브라우저에서 한다. 장면이 브라우저에 처음 보이면 WebView로 폰에 한 번 올려 크기와 끊김만 보고, 수정은 다시 브라우저에서 한다. 앱에 붙이는 일, 8명 연동, 걸음은 뒤 차수다. 2차부터는 앞 차수가 끝나면 같은 형식으로 이 문서에 덧붙인다.

| 차수 | 끝나면 이런 상태 |
|---|---|
| 1차 | 브라우저에 사람 없는 무대가 보인다 |
| 2차 | 자리 8칸에 색만 다른 사람이 앉거나 일어선다 |
| 3차 | 입장하면 나타나고 퇴장하면 사라진다 |
| 4차 | 앱 WebView에서 지금 동석 소켓으로 8명이 움직인다 |
| 5차 | 걸음, 시간대 하늘. 폰이 버거우면 앱이 3D를 직접 그린다 |

## 1차 — 브라우저에 빈 무대

사람, 소켓, 앱 화면은 이 차수에 없다. 끝나는 모습은 브라우저를 새로고침하면 정자와 야외 가구가 한 화면에 있는 것이다.

### 준비

- Blender
- ❤️Kenney 또는 Poly Pizza에서 받은 모델. 라이선스는 CC0, 또는 앱 배포가 허용된 것만❤️
- 브라우저용 페이지. 위치는 `front/study-room-3d/`

받는 파일은 `.fbx`, `.obj`, `.gltf`여도 된다. Blender에서 배치한 뒤 웹이 읽는 파일은 `.glb` 하나만 둔다.

| 파일 | 위치 | 역할 |
|---|---|---|
| `.blend`, 받은 원본 | `front/study-room-3d/blender/` | 작업 원본. 웹과 앱은 읽지 않는다 |
| `room.glb` | `front/study-room-3d/public/room.glb` | 웹 페이지가 그리는 무대 |

`room.glb` 안에 넣을 것: 땅, 나무, 절벽, 물길, 정자, 가로등, 4인용 테이블, 벤치, 소파, 나무 아래 의자, 물가 평상, 계단, 다리, 산책로. 무늬(`.png`, `.jpg`)는 파일 안에 같이 넣는다. 사람은 넣지 않는다. 다음 차수에서 `character.glb`로 따로 앉힌다.

### 만드는 순서

1. 종이 한 장에 카메라가 보는 구도를 그린다. 정자 테이블, 벤치, 소파, 나무 의자, 평상 위치만 정한다.
2. 모델을 Blender에서 그 구도대로 놓고 `room.glb`로 내보낸다.
3. `front/study-room-3d/`에 React Three Fiber 페이지를 만든다. 페이지는 `room.glb`를 읽고, 조명과 고정 카메라를 둔다.
4. 브라우저에서 어색하면 Blender에서 고친 뒤 같은 이름으로 다시 내보내고 새로고침한다.

둘러보기용 카메라 조작은 두어도 된다. 나중에 앱에 쓸 기본 각도는 하나 정해 둔다.

### 끝

- 브라우저에서 정자, 4인용 테이블, 벤치, 소파, 의자, 평상, 나무, 물이 한 화면에 보인다.
- 앱 `TimerAniLab`과 서버 정원 16은 그대로다.
