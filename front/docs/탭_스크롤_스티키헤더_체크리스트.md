# 탭 스크롤 스티키 헤더 체크리스트

> 대상: 게시판 `front/view/src/boardAll.jsx`, 메시지 `front/view/src/Message.jsx`, 타이머 `front/view/src/timer/TimerContent.jsx`와 `TimerLiveViews.jsx`.  
> 배너: `front/components/ads/TopAdBanner.jsx`. 정렬: `front/components/common/SortChips.jsx`.  
> 게시판, 메시지, 타이머의 메인 헤더는 각 화면 스크롤의 맨 위에 둔다. 배너와 함께 올라간다. 학교, 마이페이지 헤더는 그대로 고정이다.

스크롤의 맨 위는 메인 헤더이고, 그 다음이 `TopAdBanner`다. 둘 다 위로 올라가면 사라진다. 그 아래 지정한 줄이 내용 영역 맨 위에 닿으면 그 자리에서 고정되고, 그 아래 내용만 계속 스크롤된다.

```text
  메인 헤더            ← 스크롤되면 위로 사라짐
  TopAdBanner          ← 스크롤되면 위로 사라짐
  고정 줄              ← 맨 위에 닿으면 멈춤
  목록 / 나머지 내용    ← 계속 스크롤
```

| 탭 | 고정 줄 |
| --- | --- |
| 게시판 | 전체 / 학생 정렬 (`SortChips`) |
| 메시지 | 쪽지 / 우편 정렬 (`SortChips`) |
| 타이머 | 타이머 카드 (`styles.timerCard`, 날짜와 시간) |

타이머는 메인 헤더, 친구 스토리, 광고가 같이 올라간다. 날짜와 시간이 들어 있는 `timerCard`만 맨 위에 닿으면 고정된다.

---

## 0. 작업 순서

- [x] 1단계: 게시판. 배너를 목록 스크롤 안으로 넣고, 전체/학생 줄을 섹션 헤더로 고정한다
- [x] 2단계: 메시지. 쪽지·우편을 스크롤 하나로 합치고, 배너 다음의 쪽지/우편 줄을 고정한다
- [x] 3단계: 타이머. 헤더, 친구 스토리, 광고는 같이 올라가고 `timerCard`만 고정한다

이번 범위가 아닌 것: 학교·마이페이지 헤더, 학교 게시판, 우리 학교, 검색, 게시글 상세의 배너. 정렬 칩 모양, 배너 높이, 카드 디자인, 당기기 새로고침·다음 페이지 동작.

---

## 1. 게시판

지금은 `TopAdBanner`와 `SortChips`가 `FlatList` 밖에 있어서 목록만 스크롤된다.

목록은 페이지를 이어서 불러오므로 `SectionList`로 바꾼다. `FlatList`를 `ScrollView` 안에 넣지 않는다.

- [x] `ListHeaderComponent`는 메인 헤더와 `TopAdBanner`다. 둘 다 스크롤되면 사라진다
- [x] 섹션 헤더는 지금 `SortChips`(전체/학생, 최신/인기/근처)다. `stickySectionHeadersEnabled`로 맨 위에 닿으면 고정된다
- [x] 섹션 데이터는 지금 목록이다. 인기 1등 카드, 광고 칸, 스켈레톤, 빈 목록, 더 불러오기, 당기기 새로고침을 유지한다
- [x] 고정 줄 배경은 `colors.white`다. 글 카드가 비쳐 보이지 않는다
- [x] 배너 좌우 여백, 정렬 줄 좌우 여백, 카드 목록 좌우 여백은 지금 값을 유지한다. 고정 줄에 목록 패딩이 한 번 더 붙지 않는다
- [x] 고정된 상태에서 전체/학생과 정렬 드롭다운이 지금처럼 동작한다

---

## 2. 메시지

지금은 `TopAdBanner`와 `SortChips`가 쪽지 `ScrollView`, 우편 `ScrollView` 밖에 있다.

쪽지와 우편을 각각의 안쪽 스크롤에서 빼고, 배너와 정렬을 포함한 스크롤 하나로 그린다.

- [x] 스크롤 첫 요소는 메인 헤더, 다음은 `TopAdBanner`다. 둘 다 올라가면 사라진다
- [x] 그 다음이 지금 `SortChips`(쪽지/우편)다. `stickyHeaderIndices={[2]}`로 맨 위에 닿으면 고정된다
- [x] 그 아래는 선택된 쪽의 목록이다. 쪽지와 우편을 바꿀 때 목록이 바뀌고, 고정 줄은 같은 자리에 남는다
- [x] 스켈레톤, 빈 목록, 광고 칸, 쪽지 긴 누르기, 우편 쓰기 버튼을 유지한다
- [x] 고정 줄 배경은 `colors.white`다
- [x] 배너와 정렬 줄의 좌우 여백은 지금 값을 유지한다

---

## 3. 타이머

지금은 친구 스토리, `TopAdBanner`, 날짜 줄, 시간 컨테이너, 할 일·시간표가 스크롤 하나에 있다.

- [x] 스크롤 첫 요소는 메인 헤더다. 올라가면 사라진다
- [x] 친구 스토리 줄과 `TopAdBanner`는 메인 헤더와 같이 스크롤된다. 좌우 여백은 지금 스크롤 내용과 같다. 배너는 `inset={false}`다
- [x] 날짜와 시간은 `styles.timerCard` 한 장이다. 맨 위에 닿으면 `stickyHeaderIndices`로 이 카드만 고정된다
- [x] 고정된 카드 배경은 `colors.white`다. 아래 할 일·시간표가 비쳐 보이지 않는다
- [x] 할 일·시간표는 고정 줄 아래에서 계속 스크롤된다
- [x] 처음 로딩 스켈레톤도 헤더, 친구 스토리, 배너가 같이 스크롤된다
- [x] 시작, 일시정지, 날짜 이동, 달력, 이미지 저장, 스터디룸, 과목·할 일 동작은 유지한다
