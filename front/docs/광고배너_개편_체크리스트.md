> 이번 수정(빈 상단 배너 자리)까지 반영했다. 공지·광고 내용과 API는 연결하지 않았다.  
> 거터는 `width * 0.04`. 크기 `normalize(100)`, `normalize(20)`. 배경은 `colors.primaryLight2`.

## 1. 그대로 두는 목록 사이 광고

게시글·쪽지·알림·우편 사이에 끼운 광고는 이번엔 손대지 않는다.

- [ ] 게시판 `boardAll.jsx`의 `AdPlaceholder`
- [ ] 학교 게시판 `schoolBoardAll.jsx`의 `AdPlaceholder`
- [ ] 쪽지 `Message.jsx`의 `ChatAdPlaceholder`
- [ ] 알림 `notificationscreen.jsx`의 `NotificationAdPlaceholder`
- [ ] 학교 우편함 `schoolMailbox.jsx`의 `MailboxAdPlaceholder`
- [ ] `App.js`의 `SplashAd`, `LaunchAdModal`
- [ ] `CommuteAdBanner`

학교 게시판·우편함은 헤더 아래 `TopAdBanner`를 새로 두고, 목록 사이 광고는 기존 컴포넌트를 유지한다.

---

## 2. 이번엔 연결하지 않음 (인지)

팁을 공지사항으로 바꾸고, 배너 종류를 나눈다. 백엔드 연결과 노출 조건은 이번 수정에 넣지 않는다.

- [ ] `TopAdBanner`는 나중에 공지사항 또는 광고를 보여 준다
- [ ] 목록 사이 `AdPlaceholder`는 나중에 광고만 보여 준다. 광고가 없으면 그 자리는 렌더하지 않는다
- [ ] 지금 팁 문구를 공지사항으로 바꾸는 작업과 공지사항 API 연결은 하지 않는다
