# 로그인·가입 색상 토큰 정리 체크리스트

> 범위: `front/styles/colors.js` 44–64행의 이전 토큰을, 같은 파일 5–42행 토큰 중 가장 가까운 색으로 바꾼 뒤 이전 이름을 삭제한다.  
> 1순위는 로그인·가입 화면이다. 이전 이름을 지우려면 그 이름을 쓰는 다른 화면도 같은 표로 바꿔야 한다.  
> 새 팔레트에는 투명 검정이 없다. `background2`, `overlay`는 흰 배경 위에 얹힌 것처럼 환산한 가장 가까운 단색으로 바꾼다.

---

## 0. 작업 순서

- [x] 1단계: 아래 매핑표대로 로그인·가입 파일의 `colors.*`를 교체
- [x] 2단계: 이전 토큰을 아직 쓰는 다른 파일을 같은 표로 교체
- [x] 3단계: `colors.js` 44–64행 이전 토큰 블록을 삭제
- [x] 4단계: `colors.background`, `colors.textPrimary` 등 이전 키가 저장소에 남지 않았는지 검색

`colors.border || colors.textLight10`처럼 이전 키를 폴백으로 묶은 자리는 새 키 하나만 남긴다.
