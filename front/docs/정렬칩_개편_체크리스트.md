# 정렬 칩 개편 체크리스트

> 대상: `front/components/common/SortChips.jsx`.  
> 쓰는 화면: 게시판 `boardAll.jsx`, 메시지 `Message.jsx`, 학교 게시판 `schoolBoardAll.jsx`.  
> 3단계(정렬 드롭다운)까지 반영했다.  
> 거터는 `width * 0.04`. 색은 `colors.js`, 글꼴은 `fonts.bold`만 쓴다.

한 줄이다. 왼쪽은 목록을 나누는 칩, 오른쪽은 정렬 드롭다운이다. 드롭다운이 없는 화면은 칩만 둔다.

```text
|← 4% →|  (전체)  학생          최신순 ⌄  |← 4% →|
```

사진 기준이다. 선택된 칩은 회색 면, 선택되지 않은 칩은 흰 면과 회색 테두리. 오른쪽 글은 `최신순`과 아래 방향 화살표.

---

## 0. 작업 순서

- [x] 1단계: `SortChips`를 왼쪽 구분 칩 + 오른쪽 정렬 드롭다운 한 줄로 바꾼다
- [x] 2단계: 게시판, 메시지, 학교 게시판에 구분 칩을 붙인다
- [x] 3단계: 게시판(전체/학생)에만 최신·인기·근처 드롭다운을 붙이고 기존 정렬 값에 연결한다. 학교 게시판에는 드롭다운을 두지 않는다
- [ ] 메시지 쪽지/우편 목록, 게시글 카드, 광고 배너, 학교 우편 상세는 이번 범위가 아니다

---

## 1. 컴포넌트

`value` / `onChange` / `options`는 구분 칩용으로 남긴다. 정렬은 별도다.

- [x] 왼쪽 칩은 `options` 순서대로 그린다. `{ value, label }`
- [x] 선택 칩: 면 `colors.textLight2`, 글 `colors.text`, 테두리 없음
- [x] 미선택 칩: 면 `colors.white`, 테두리 `colors.textLight2`, 글 `colors.textLight5`
- [x] 모서리 `normalize(20)`. 칩 사이 간격 `normalize(8)`
- [x] 지금 선택색 `colors.primary`와 흰 글자는 이 컴포넌트에서 뺀다
- [x] 오른쪽 정렬은 `sortValue`, `onSortChange`가 있을 때만 그린다. 없으면 칩만 왼쪽 정렬
- [x] 닫힌 표시는 현재 항목 라벨과 `chevron-down`. 글 `colors.textLight5`, `fonts.bold`
- [x] 누르면 최신순 / 인기순 / 근처순 목록이 열린다. 고르면 닫히고 `onSortChange`에 `latest` | `popular` | `nearby`를 넘긴다
- [x] 줄 좌우 `paddingHorizontal: width * 0.04`. 아래 구분선 `colors.textLight1`은 유지한다
- [x] 기본 `options`의 최신·인기·근처는 제거한다. 호출하는 쪽이 칩 목록을 넘긴다

## 2. 화면별 칩

| 화면 | 칩 | 드롭다운 |
| --- | --- | --- |
| 게시판 | 전체 / 학생 | 있음 |
| 메시지 | 쪽지 / 우편 | 없음 |
| 학교 게시판 | 게시판 / 우편함 | 없음 |

- [x] 게시판 `전체`: 지금과 같이 `boardType: 'national'` 목록
- [x] 게시판 `학생`: 같은 화면에서 `boardType: 'school'` 목록. 학교 게시판의 게시글 조회와 같다
- [x] 메시지: 슬라이딩 토글(쪽지 / 개인 우편)을 이 칩으로 바꾼다. 값은 지금처럼 `note` / `mail`. 보이는 글자는 쪽지, 우편
- [x] 학교 게시판 `게시판`: 지금 `schoolBoardAll` 목록
- [x] 학교 게시판 `우편함`: 같은 헤더 아래에 `schoolMailbox` 목록을 보여 준다. 우편함 쪽 서브헤더는 두지 않는다
- [x] 우리학교에서 우편함으로 들어오면 학교 게시판의 우편함 칩이 선택된 상태로 연다
- [x] 다른 학교 우편함으로 들어오면 `SortChips` 없이 우편함 페이지만 연다. 다른 학교 게시판은 볼 수 없어서 칩이 필요 없다
- [x] 게시판, 메시지, 학교 게시판 모두 `TopAdBanner` 바로 아래, 목록 위에 둔다. 메시지 배너는 이미 헤더 아래에 있다

## 3. 정렬 드롭다운

- [x] 게시판: 지금 `sortType`(`latest` / `popular` / `nearby`)에 연결한다. 전체·학생 둘 다 이 정렬을 쓴다
- [x] 학교 게시판, 메시지, 다른 학교 우편함에는 `sortValue`를 넘기지 않는다. 학교 게시판 `sortType`은 `latest` 고정을 유지한다
- [x] 근처 정렬의 위치 권한 안내 문구는 게시판에 그대로 둔다
