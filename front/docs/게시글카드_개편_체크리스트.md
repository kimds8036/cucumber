# 게시글 카드 개편 체크리스트

> 대상: `front/components/Boardpostcard.jsx`.  
> 스타일: `front/styles/board.style.js`, `front/styles/schoolBoard.style.js`.  
> 인기 1등 고정: `front/view/src/boardAll.jsx`만.  
> 사진 두 장 기준이다. 일반 카드는 흰 면과 회색 윤곽선, 인기 카드는 연한 초록 면과 왼쪽의 `인기` 뱃지.  
> 색은 `colors.js`, 글꼴은 지금 카드와 같다. 백엔드 인기 순위는 바꾸지 않는다.

---

## 0. 작업 순서

- [x] 1단계: 카드 왼쪽에서 작성자 `익명`, 장착 뱃지, 구분점, 인라인 위치를 빼고 시간만 남긴다. 오른쪽 거리 뱃지는 유지한다
- [x] 2단계: 카드 그림자를 빼고 윤곽선 `colors.textLight1`로 바꾼다
- [x] 3단계: 인기 1등 카드에 `인기` 뱃지, 배경 `colors.primaryLight2`, 윤곽선 없음을 넣는다
- [x] 4단계: 게시판 목록 첫 칸에 인기 1등 글 하나를 고정한다. 같은 글은 아래 목록에서 뺀다

이번 범위가 아닌 것: 본문, 태그, 썸네일, 좋아요·댓글·스크랩 숫자와 아이콘, 거리 뱃지 모양, 카드 모서리·안쪽 여백, 정렬 칩.

---

## 1. 헤더

지금 왼쪽은 `익명` · 장착 뱃지 · `•` · 시간 · (있으면) 위치 글자다. 사진의 일반 카드는 시간만 있다.

- [x] `post.author`, `EquippedBadge`, `postDot`, 인라인 `post.location`을 카드에서 뺀다
- [x] 왼쪽에는 `post.time`만 둔다. 글 스타일은 지금 `postTime` 그대로다
- [x] 오른쪽 `DistanceBadge`는 그대로 둔다. `hideDistanceBadge`, `showDistanceBadge`, `distanceStale`, `distanceLoading` 동작도 유지한다
- [x] 이 헤더는 `BoardPostCard`를 쓰는 게시판, 학교 게시판, 내 글에 같이 적용된다

---

## 2. 윤곽선

그림자는 `board.style.js`와 `schoolBoard.style.js`의 `postItem`에 있는 `shadow.md`다. 안드로이드는 elevation이다.

- [x] `postItem`에서 `shadow.md`를 뺀다. iOS 그림자와 Android `elevation`이 둘 다 없어져야 한다
- [x] `borderWidth: 1`, `borderColor: colors.textLight1`
- [x] 면은 `colors.white`, 모서리 `normalize(18)`, 안쪽 여백과 카드 간격은 유지한다
- [x] `postItem`을 같이 쓰는 내 글의 학교 우편 행과 목록 스켈레톤도 같은 윤곽선을 받는다
- [x] 학교 게시판 `schoolBoard.style.js`의 `postItem`도 같이 바꾼다. 카드가 스타일을 밖에서 받기 때문이다

---

## 3. 인기 카드 모양

사진의 첫 카드다. 일반 카드와 내용 구성은 같고, 헤더 왼쪽과 면·테두리만 다르다.

- [x] `BoardPostCard`에 인기 고정용 prop를 둔다. 그 값이 있을 때만 이 모양을 쓴다
- [x] 배경 `colors.primaryLight2`. 윤곽선 없음, 그림자 없음
- [x] 시간 왼쪽에 `인기` 뱃지. 면 `colors.yellow`, 글 `colors.text`, 테두리 `colors.scrap`, 모서리는 알약
- [x] 뱃지와 시간 사이 간격은 지금 헤더의 구분점 간격 정도
- [x] 거리 뱃지, 본문, 태그, 썸네일, 반응 숫자는 일반 카드와 같다

---

## 4. 목록 맨 위 고정

맨 위 글은 전체/학생 필터의 인기 1등이다. 최신순·인기순·근처순은 그 아래 목록만 바꾼다. 순위 계산은 서버 `sort=popular`를 그대로 쓴다. 새 정렬을 만들지 않는다.

목록의 첫 칸에 그 글 하나를 둔다. 스크롤하면 카드도 같이 올라간다. 화면 위에 붙여 두지는 않는다.

- [x] 인기 1등은 정렬과 상관없이 항상 `sort=popular`, `limit=1`로 따로 가져온다. 인기순 목록의 1페이지 첫 글을 그대로 쓰지 않는다
- [x] 이 요청의 범위는 전체/학생 필터와 같다. 전체는 지금 전체 목록과 같은 범위, 학생은 지금 학생 목록과 같은 `schoolId`다. 목록의 `sortType`은 넣지 않는다
- [x] 위치 좌표는 목록 요청과 같이 넘긴다
- [x] 인기 결과가 없으면 고정 카드를 두지 않는다. 아래 목록은 지금 정렬 그대로다
- [x] 고정한 글과 같은 id는 아래 목록에서 뺀다. 인기순이어도 두 번 나오지 않는다
- [x] 당기기 새로고침, 전체/학생 변경, 포커스 갱신 때 고정 글을 다시 맞춘다. 최신/인기/근처만 바꿀 때는 고정 글을 다시 부르지 않는다
- [x] 가이드 미리보기이거나 학생 인증으로 목록이 비어 있으면 고정 카드를 두지 않는다
- [x] 학교 게시판, 내 글, 우리 학교의 실시간 인기에는 이 고정을 넣지 않는다
