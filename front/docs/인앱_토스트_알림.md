# 인앱 토스트 알림

앱이 켜져 있을 때 상단에 뜨는 `GlobalToast` 기준이다. 백그라운드 푸시 문구는 여기 적지 않는다.

코드: `context/ToastContext.jsx`, `context/NotificationContext.jsx`, `components/common/ToastHost.jsx`, `components/common/GlobalToast.jsx`

채팅방 안의 짧은 안내(`useChatUI`의 `showChatToast`)는 전역 토스트가 아니다. 맨 아래 따로 적었다.

## 공통 동작

- 한 번에 하나. 새 토스트가 오면 이전 것을 교체한다.
- 3초 뒤 사라진다. 위로 스와이프해도 닫힌다.
- 제목이 있으면 제목(굵게) + 본문(보통). 제목이 없으면 본문만 굵게, 최대 2줄.
- 앱이 포그라운드(`active`)일 때만 소켓 토스트를 띄운다.
- 탭하면 `ToastHost`가 화면을 연다. 이동 정보가 없는 로컬 토스트는 탭해도 화면이 바뀌지 않는다.
- 하단 진행 막대(`showProgress`)는 값만 넘어가고, 그리는 코드는 주석 처리되어 있다.

## 소켓으로 오는 알림

서버가 `notification` 이벤트로 보내는 문구와, 앱이 토스트에 실제로 그리는 문구가 다를 수 있다.

### 게시글 댓글 · 답글

| | 내용 |
|---|---|
| 언제 | 내 글에 댓글, 또는 내 댓글에 답글. 포그라운드 |
| 서버 본문 | 댓글 `내 게시글에 새로운 댓글이 달렸어요` / 답글 `내 댓글에 새 답글이 달렸어요` |
| 토스트 제목 | `게시글` |
| 토스트 본문 | 답글(`type=reply`) `내 댓글에 새로운 답글이 달렸어요` / 그 외 `새로운 댓글이 달렸어요` |
| 탭 | 해당 게시글 상세 |

앱은 서버 본문을 쓰지 않고 위 두 문장으로 덮어쓴다. 그래서 알림 목록과 토스트 문장이 다르다.

### 개인 우편

| | 도착 | 답장 | 반송 |
|---|---|---|---|
| 제목 | `우편함` | `우편함` | `우편함` |
| 본문 | 서버 본문. 지금 서버는 `새로운 우편이 도착했습니다` | 본문에 `답장`이 있으면 서버 본문. 지금 서버는 `{이름} 님이 우편 답장을 보냈습니다` | 서버 본문. 지금 서버는 `{이름} 님에게 보낸 우편이 반송되었습니다` |
| 탭 | 우편 상세 | 우편 상세 | 재발송 화면 |

본문이 비면 도착·일반은 `새로운 우편이 도착했어요`, 반송은 `보낸 우편이 반송되었습니다`.

### 익명 쪽지 · DM

두 경로가 있다. 상대가 그 방에 없을 때 `new_message`가 먼저 오고, 이어서 `notification`이 온다. 메시지 탭이 아니고 그 채팅방도 아니면 **토스트가 두 번** 뜰 수 있다.

메시지 탭에 있으면 `new_message` 토스트는 생략한다. 지금 보고 있는 방이면 `new_message`도 생략한다. `notification` 쪽 채팅 토스트는 메시지 탭 여부를 보지 않는다.

| | 익명 쪽지 | DM |
|---|---|---|
| 제목 | `익명` | 보낸 사람 이름. 없으면 `새 메시지` |
| 본문 | 메시지 글. 사진만 있거나 내용이 사진 주소면 `사진`. 알림으로 저장되는 본문도 글이 없으면 `사진` (80자) | 같음 |
| 탭 | 익명 채팅방 | DM 채팅방 |

### 쿡 찌르기

상대 앱이 소켓에 붙어 있으면 `friend_poke`만 보낸다. 이름은 `users.name_enc`를 복호화한 값이다. 복호화된 이름이 없을 때만 `친구`를 쓴다.

| 화면 | 토스트 | 탭 |
|---|---|---|
| 타이머 | 제목 없음. `{이름} 님이 쿡 찔렀어요` / 이름 없으면 `누군가 쿡 찔렀어요` | 이동 정보 없음 |
| 그 외 포그라운드 | 제목 없음. `{이름} 님이 쿡 찔렀어요! 타이머에서 함께 공부를 시작해보세요` / 이름 없으면 `친구가 쿡 찔렀어요! 타이머에서 함께 공부를 시작해보세요` | 타이머 탭 |

같은 사건인데 화면마다 문장 길이가 다르다.

### 공부 끝나면 기다린 사람

`friend_study_finished_summary` 자체는 토스트를 그리지 않는다. 뒤따라 오는 `notification`이 그리거나, 타이머 화면이면 타이머가 직접 그린다.

서버 본문:

- 1명: `공부 완료! {이름} 님이 기다렸어요`
- 여러 명: `공부 완료! {이름} 님 외 {n}명이 기다렸어요`

| 화면 | 토스트 | 탭 |
|---|---|---|
| 타이머 | 제목 없음. `공부 완료!`를 뺀 문장. 예: `{이름} 님이 기다렸어요` | 1명이면 DM, 여러 명이면 알림 목록 |
| 그 외 | 제목 `공부 완료!`, 본문은 `공부 완료!`를 뺀 나머지. 비면 `누군가 기다렸어요` | 같음 |

대기자가 0명이면 토스트를 띄우지 않는다.

### 친구

| 상황 | 제목 | 본문 | 탭 |
|---|---|---|---|
| 친구 요청 | `시스템` | 서버 본문. 지금 서버는 `새 친구 요청이 도착했어요! 친구 목록에서 확인해 보세요` | 친구 화면 |
| 친구 수락 | `시스템` | 서버 본문. 지금 서버는 `{이름} 님이 친구 요청을 수락했어요` | 이동 규칙 없음. 시스템이면 알림 목록 |

파일 주석에는 친구 요청 토스트를 빼는 것처럼 적혀 있지만, 처리 코드는 토스트를 띄운다. 친구 요청 뱃지는 `FriendContext`가 따로 켠다.

### 시스템 (서버 문구 그대로)

`category=system`이고 제목이 `시스템`이 아니면, 서버 제목·본문을 토스트에 그대로 쓴다. 탭은 알림 목록.

| 상황 | 제목 | 본문 |
|---|---|---|
| 학생증 승인 | `학생 인증이 완료되었습니다` | `학생 인증 완료 · 학교·학생 게시판 등 학교 기능을 이용할 수 있어요.` |
| 학생증 거절 | `학생증이 거절되었습니다` | 거절 사유. 사유가 없으면 `알림을 열어 사유를 확인하고, 필요하면 다시 제출해 주세요.` |
| 재학증명서 승인 | `학생 인증이 완료되었습니다` | `Youth Paper를 이용할 수 있어요.` |
| 재학증명서 거절 | `재학증명서가 거절되었습니다` | 거절 사유. 없으면 학생증 거절과 같은 안내 |
| 문의 답변 | `문의 답변이 도착했습니다` | `문의하신 내용에 답변이 등록되었습니다. 앱에서 확인해 주세요.` |

그 외 시스템에서 제목만 있고 본문이 없으면, 제목을 `시스템`으로 두고 원래 제목을 본문에 넣는다. 둘 다 없으면 본문은 `새로운 알림이 도착했어요`.

## 화면에서 직접 띄우는 토스트

소켓과 무관하다. 제목이 없으면 한 줄 굵은 글씨다.

| 상황 | 문구 | 탭 |
|---|---|---|
| 설정에서 다크모드 | `개발 중인 기능입니다.` | 없음 |
| 쿡 찌르기 보냄 | `{이름} 님에게 공부하자는 알림을 보냈어요` | 없음 |
| 공부 끝나면 알려주기 예약 | `{이름} 님의 공부가 끝나면 기다렸다는 알림을 보낼게요` | 없음 |
| 같은 친구 쿨다운 (서버가 거절) | `같은 친구에게는 30초 뒤 다시 쿡 찌르기 할 수 있어요` | 없음 |
| 버튼이 잠긴 동안 다시 누름 | `{남은초}초 후 다시 쿡 찌르기 할 수 있어요` | 없음 |
| DM 방 만들기 실패 | `메시지 전송 준비 중 문제가 발생했어요. 잠시 후 다시 시도해 주세요` | 없음 |

## 채팅방 안 안내 (전역 토스트 아님)

채팅 화면 안에만 약 2초 보인다.

| 상황 | 문구 |
|---|---|
| 복사 | `메시지가 복사되었습니다` |
| 답장 원문 위치가 더 위 | `상단으로 더 올려서 과거 메시지를 확인해 주세요` |
| 원문으로 이동 실패 | `해당 메시지로 이동하지 못했습니다` |

## 검토할 곳

1. 게시글 토스트가 서버 문장을 버리고 더 짧은 문장으로 바뀐다. 알림 목록과 말이 다르다.
2. 쿡 찌르기·공부 완료는 타이머 화면과 그 밖 화면의 문장·제목 유무가 다르다. 타이머에서 받은 쿡 찌르기는 눌러도 타이머로 가는 정보가 없다.
3. 쪽지·DM은 `new_message`와 `notification`이 겹치면 토스트가 연달아 두 번 뜰 수 있다.
4. 우편은 `했습니다` / `했어요`가 경로마다 섞여 있다. 도착·답장·반송은 서버의 `습니다` 문장이 토스트에 그대로 나온다.
5. 친구 요청은 주석과 실제 동작이 다르다. 토스트가 뜬다.
6. 학생증 승인과 재학증명서 승인은 제목이 같은데 본문이 다르다.
