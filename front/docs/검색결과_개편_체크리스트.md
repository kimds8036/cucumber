## 5. 궁금한 점 (답변 부탁)

- [ ] **Q1. 학생 게시판 검색 결과가 서버에서 오지 않는다.**
  `back/src/routes/search.js`는 `national`과 본인 학교 `school` 글만 돌려준다. `student` 글을 포함하도록 백엔드도 고칠까? 고친다면 학생 게시판도 학교 게시판처럼 **학생 인증한 사용자만** 보이게 할까?
  답:`student` 글을 포함하도록 백엔드도 고치고 학생 게시판도 학교 게시판처럼 **학생 인증한 사용자만** 보이게 해줘
- [ ] **Q2. 검색어 하이라이트.**
  지금은 검색어 앞뒤 20자만 잘라서(`makeSnippet`) 검색어를 초록 굵은 글씨로 강조한다. `BoardPostCard`는 본문 3줄을 그대로 보여 주고 강조가 없다.
  - (a) 카드 그대로, 강조 없음
  - (b) 카드에 강조 기능을 추가 (`BoardPostCard`에 선택 prop 추가, 다른 화면은 영향 없음)
  답: (b) 카드에 강조 기능을 추가 (`BoardPostCard`에 선택 prop 추가, 다른 화면은 영향 없음)
- [ ] **Q3. 태그·썸네일·스크랩 수.**
  검색 응답에 `tags`, 이미지, `scrapCount`가 없어서 카드에 태그 칩과 썸네일이 안 나온다. 게시판 카드와 똑같이 보이게 백엔드 응답에 추가할까?
  답: 게시판 카드와 똑같이 보이게 백엔드 응답에 추가
- [ ] **Q4. 전체 탭 구성.**
  지금처럼 섹션마다 제목 + `n건` 뱃지 + 카드 3개 + "결과 더보기"를 유지할까?
  답: 응
- [ ] **Q5. 학교 우편함 카드.**
  지금 우편 결과를 눌러도 `BoardDetail`(게시글 상세)로 간다. `schoolMailbox`처럼 `SchoolMailDetail`로 가게 고칠까? 또 우편 카드에 보낸 학교 라벨(`authorLabel`)도 붙일까? 붙이려면 백엔드 응답에 보낸 사람 정보가 필요하다.
  답: 우편 카드에 보낸 학교 라벨(`authorLabel`)도 붙여주고 `schoolMailbox`처럼 `SchoolMailDetail`로 가게 고쳐줘
- [ ] **Q6. 섹션 순서.**
  전체 탭은 지금 결과 개수가 많은 섹션부터 보여 준다. 탭 순서(전체 게시판 → 학생 → 학교 → 우편함)로 고정할까?
  답: 개수가 많은 섹션부터 보여주는 방식 유지
- [ ] **Q7. 결과가 없는 탭.**
  학교 게시판·학교 우편함은 학생 인증 전에는 항상 비어 있다. 탭은 항상 5개 다 보여 줄까, 결과가 있는 탭만 보여 줄까?
  답: 결과가 있는 탭만 보여주되 학생 미인증 사용자는 학교 게시판/우편함, 학생 게시판 탭에서 검색 결과를 눌러도 게시글 상세로 이동하지 않고 학생 인증 후 이용할 수 있다는 안내 모달을 띄운다. 안내 모달에는 확인/학생증 인증하러 가기 버튼이 있고 인증하러 가기 버튼을 누르면 학교탭으로 이동하여 학생증 인증을 유도한다.
- [ ] **Q8. Q1과 Q7이 충돌한다.**
  Q1대로 서버가 학생·학교 게시판·우편 결과를 **인증한 사용자에게만** 주면, 미인증 사용자는 그 탭에 결과가 없어서 Q7대로 탭 자체가 숨겨진다. 그러면 안내 모달이 뜰 일이 없다.
  - (a) 서버는 미인증 사용자에게도 학생·학교 게시판·우편 결과를 **목록으로는** 준다. 앱에서 누를 때 막고 안내 모달을 띄운다. 상세 화면 API는 지금처럼 인증을 요구하므로 내용이 새지는 않는다
  - (b) 서버는 인증한 사용자에게만 준다. 미인증 사용자는 그 탭이 보이지 않고, 안내 모달은 쓰지 않는다
  - (a)라면 미인증 사용자의 학교 게시판·우편함 결과는 **가입 때 고른 학교(`users.school_id`)** 기준으로 보여 줄까? 학교 정보가 없는 사용자는 그 탭을 비운다
  - 안내 모달은 이미 있는 `components/auth/StudentVerificationCtaModal.jsx`를 재사용할 생각이다. 이 모달의 버튼은 `학생 인증하기` / `나중에`이고, 학생증 검수 중인 사용자에게는 `확인`만 보인다. 이 문구 그대로 써도 될까, 아니면 `확인` / `학생증 인증하러 가기`로 바꿀까? (바꾸면 이 모달을 쓰는 다른 화면도 같이 바뀌므로, 검색 화면에서만 바꾸려면 버튼 문구 prop을 추가한다)
  답: (b) 서버는 인증한 사용자에게만 준다. 미인증 사용자는 그 탭이 보이지 않고, 안내 모달은 쓰지 않는다
