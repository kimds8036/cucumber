# 학교 게시판 개편 체크리스트

> 대상: `front/view/src/schoolBoardAll.jsx` (학교 게시판 목록 + 우편함 섹션), `front/view/src/schoolMailbox.jsx` (우편함 목록, 단독 화면 겸용).  
> 기준 화면: 게시판 탭 `front/view/src/boardAll.jsx`.  
> 카드: `front/components/Boardpostcard.jsx`. 스타일은 `createBoardStyles` (`front/styles/board.style.js`).  
> 상세 헤더: `front/view/src/boardDetail.jsx`.

목표는 학교 게시판을 게시판 탭과 같은 디자인으로 맞추는 것이다. 데이터 요청(`/api/schools/me`, `/api/posts?boardType=school&schoolId=…`, `/api/mails/school`)은 바꾸지 않는다.

우편 상세 화면(`schoolMailDetail.jsx`)은 헤더 제목까지 포함해 별도 체크리스트로 분리한다 (Q15).

- [x] 1단계: 목록 여백과 스크롤 구조를 게시판 탭과 같게 맞춘다

- [x] 3단계: 목록 헤더와 게시글 상세 헤더 제목을 바꾼다
- [x] 4단계: 목록 헤더의 검색 아이콘을 뺀다
- [x] 5단계: 우편함을 1열 게시판 카드로 바꾼다 (Q2, Q7, Q10~Q14, Q16)

- [x] 로딩 중에는 덮개 대신 게시판 탭과 같은 스켈레톤 카드 4장을 목록 항목으로 그린다 (`components/board/BoardPostCardSkeleton.jsx`)

- [x] 배너는 게시판·우편함 모두 `placement="board"` (Q8)

## 질문 (답을 아래에 적어 주세요)

**Q1. 스크롤 방식도 게시판 탭처럼 바꿀까요?**  
게시판 탭은 광고 배너가 스크롤과 함께 올라가고, 칩 줄만 위에 붙어 남습니다(`SectionList` sticky). 학교 게시판은 지금 헤더·배너·칩이 모두 고정이고 목록만 스크롤됩니다.  
- (a) 게시판 탭처럼 배너는 스크롤, 칩은 고정  
- (b) 지금처럼 모두 고정, 여백만 맞춤  
답:(a) 게시판 탭처럼 배너는 스크롤, 칩은 고정

**Q2. 우편함 섹션(2열 카드)도 여백을 맞출까요?**  
답: 우편함도 게시판처럼 1열 카드로 수정해주고 게시판 디자인으로 통일해줘

**Q3. 거리 뱃지를 게시판 탭처럼 위치 권한이 있을 때만 보여 줄까요?**  
지금 학교 게시판은 조건 없이 거리 뱃지 영역을 그립니다.  
답: 거리 뱃지를 게시판 탭처럼 위치 권한이 있을 때만 보여줘

**Q4. 게시판 탭의 정렬 메뉴(최신순/인기순/근처)를 학교 게시판 칩 오른쪽에도 넣을까요?**  
지금 학교 게시판은 최신순 고정이고 정렬 메뉴가 없습니다.  
답: 정렬 메뉴 안 넣을 거야

**Q5. 상세 헤더에서 학교명과 게시판/우편함 사이를 띄어 쓸까요?**  
예: `OO고등학교 게시판` / `OO고등학교게시판`. 학교명을 못 받았을 때는 `학교 게시판` / `학교 우편함`으로 둘까요?  
답: `OO고등학교 게시판`, `OO고등학교 우편함`

**Q6. 다른 학교 우편함(다른 학교 화면 → 우편함)에서 연 우편 상세도 그 학교명 + 우편함으로 보여 줄까요?**  
답:그 학교명 + 우편함으로 보여줘

**Q7. 다른 학교 화면에서 여는 단독 우편함 화면(`schoolMailbox.jsx`, 헤더 `학교 우편함`)은 그대로 둘까요?**  
답: 단독 우편함 화면도 똑같이 통일해주는데 이 다른학교 우편함 화면에는 sortchips 없이 우편함만 띄울 거야

**Q8. 광고 배너 위치값을 바꿀까요?**  
학교 게시판 목록은 `TopAdBanner placement="board"`, 단독 우편함은 `placement="school"`입니다.  
답: 둘 다 BOARD로 해줘

**Q9. `schoolBoard.style.js`의 카드용 스타일을 지워도 될까요?**  
코드에서 `createSchoolBoardStyles`를 쓰는 곳은 `schoolBoardAll.jsx` 하나뿐입니다. 카드용은 지우고 목록 전용 스타일만 남기겠습니다.  
답: 응 지워줘

| 항목 | 우편 카드 (지금) | 게시판 카드 |

**Q10. 우편 카드는 어떤 방식으로 만들까요?**

- (b) `BoardPostCard`에 선택 항목(보낸 사람 라벨, NEW 뱃지)을 추가해서 우편에서만 켠다. 게시판 탭 카드는 그대로다  
답:(b) `BoardPostCard`에 선택 항목(보낸 사람 라벨)을 추가해서 우편에서만 켠다. 게시판 탭 카드는 그대로다, NEW 뱃지는 사라진다
