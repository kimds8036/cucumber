# 학교 우편 상세 개편 체크리스트

> 대상: `front/view/src/schoolMailDetail.jsx` (학교 우편 상세).  
> 기준 화면: 게시글 상세 `front/view/src/boardDetail.jsx` (학교 게시판 글을 열었을 때와 같은 모양).  
> 재사용 후보: 본문 `front/view/src/board/BoardPostContent.jsx`, 댓글 `front/view/src/board/BoardCommentTree.jsx`, 메뉴 `front/view/src/board/BoardFloatingMenu.jsx`, 스타일 `createDetailStyles` (`front/styles/board.style.js`).

목표는 우편 상세를 게시글 상세와 같은 디자인으로 맞추는 것이다. 우편 API(`/api/mails/school/:id`, 댓글·좋아요·삭제·고정·신고)와 학생 인증 게이트는 바꾸지 않는다.

---

## 0. 작업 순서

- [x] 1단계: 헤더 제목을 `학교명 우편함`으로 바꾼다
- [x] 2단계: 편지지 카드 본문을 게시글 상세 본문(`BoardPostContent`)으로 바꾼다
- [x] 3단계: 댓글 목록을 게시글 상세 댓글(`BoardCommentTree`)로 바꾼다
- [x] 4단계: 점 3개 메뉴를 게시글 상세 메뉴(`BoardFloatingMenu`)로 바꾼다
- [x] 5단계: 스크롤 구조·로딩·댓글 입력을 게시글 상세와 맞춘다
- [x] 6단계: 쓰지 않게 된 우편 상세 스타일을 정리한다

---



## 1. 헤더 제목

지금 헤더는 `받은 우편`이다.

- [x] `학교명 우편함` (예: `OO고등학교 우편함`). 학교명은 `route.params.schoolName`으로 이미 들어온다
- [x] 다른 학교 우편함에서 연 우편도 그 학교명으로 보여 준다 (학교 게시판 체크리스트 Q6 답)
- [x] 학교명이 없으면 `학교 우편함`

---



## 2. 본문

지금 우편 본문은 편지지 카드다. 테두리 카드 안에 `From. 재학생`과 시간, 점선 구분선, 본문, 좋아요·댓글 수, 점 3개 메뉴가 있다.

게시글 상세 본문은 카드 없이 흰 배경에 `익명`(굵게) · 뱃지 · 시간 · 거리 뱃지, 본문, 사진, 해시태그, 좋아요 · 댓글 · 스크랩, 점 3개 메뉴 순서다.

우편에 없는 정보: 사진, 해시태그, 위치·거리, 스크랩, 장착 뱃지.

- [x] 편지지 카드(테두리, 점선 구분선, `From.`)를 없애고 게시글 상세 본문 모양으로 바꾼다
- [x] 작성자 자리에 우편의 보낸 사람 라벨(`재학생` / `졸업생 · OO 졸업생` / 학교명)을 넣는다 → **질문 Q1**
- [x] 거리 뱃지는 그리지 않는다 (우편에는 위치가 없다)
- [x] 스크랩 버튼 처리 → **질문 Q2**
- [x] `BoardPostContent`에 우편용 선택 항목을 추가한다 (보낸 사람 라벨, 스크랩 숨김). 게시글 상세 모양은 그대로다

## 3. 댓글

지금 우편 댓글과 게시글 상세 댓글의 차이다.


| 항목        | 우편 (지금)                             | 게시글 상세                      |
| --------- | ----------------------------------- | --------------------------- |
| 댓글 제목     | `댓글 N개`                             | `댓글`                        |
| 좋아요 위치    | 본문 아래 왼쪽                            | 작성자 줄 오른쪽 위                 |
| 답글 방법     | 본문 아래 `댓글 달기` 버튼                    | 점 3개 메뉴의 `답글 달기`            |
| 대댓글 처음 표시 | 3개까지 보이고 `댓글 더보기`                   | 모두 접혀 있고 더보기로 펼침            |
| 대댓글 모양    | 화살표 아이콘 + 들여쓴 말풍선                   | 답글 묶음 배경                    |
| 작성자 표시    | `작성자` / `재학생` / `졸업생` 등, 가운데 점 + 시간 | 작성자 이름 · 뱃지 · 시간 (가운데 점 없음) |
| 고정 댓글     | `고정` 글자                             | 핀 아이콘                       |


- [x] 댓글 목록을 `BoardCommentTree`로 그린다. 우편 댓글 데이터를 게시글 상세 댓글 모양(`type: comment / reply / more / collapse`)으로 바꿔 넘긴다
- [x] 작성자 라벨은 우편 라벨(`작성자` / `재학생` / `졸업생` …)을 그대로 쓴다. `작성자`는 게시글 상세처럼 강조한다
- [x] 장착 뱃지는 우편 댓글 데이터에 없으므로 비운다
- [x] 대댓글 처음 표시 개수 → **질문 Q3**
- [x] 좋아요·고정·삭제·신고 동작은 지금 우편 API 그대로 연결한다

## 4. 점 3개 메뉴

지금 우편 메뉴:

- 글 (내가 쓴 우편): `삭제하기`, `신고 / 차단`
- 글 (남의 우편): `공유하기`(눌러도 동작 없음), `신고 / 차단`
- 댓글: `댓글 고정`/`고정 해제`(우편 작성자만), `삭제하기`(내 댓글만), `신고 / 차단`

게시글 상세 메뉴(`BoardFloatingMenu`)에는 `공유하기`, `쪽지 보내기`, `답글 달기`가 더 있다.

- [x] 모양은 `BoardFloatingMenu`와 같게 한다
- [x] 댓글 메뉴에 `답글 달기`를 넣는다 (Q3 답에 따라 `댓글 달기` 버튼 대신)
- [x] `공유하기`, `쪽지 보내기` 처리 → **질문 Q4**
