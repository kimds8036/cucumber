# 메인 헤더 개편 체크리스트

> 대상: `front/view/frame/mainHeader.jsx`, 스타일 `front/styles/frame.style.js`의 `createHeaderStyles`.  
> 참고 화면: 왼쪽 제목, 오른쪽 검색·알림. 흰 배경, 검색·알림은 원 버튼이 아니다.  
> 통학 표시는 사진에 없어도 지금처럼 검색 왼쪽에 둔다.  
> 3단계(색)까지 반영했다.  
> 거터는 이미 `width * 0.04`. 색은 `colors.js`, 글꼴은 `fonts.bold`(`Baloo2-Bold`)만 쓴다.

---

## 0. 작업 순서

- [x] 1단계: 헤더 구성을 제목 / 통학 표시 / 검색 / 알림으로 맞춘다
- [x] 2단계: 아이콘 버튼의 초록 원·테두리를 빼고 사진처럼 선 아이콘으로 바꾼다
- [x] 3단계: 제목·아이콘·안 읽음 점 색을 `colors.js` 토큰으로 맞춘다
- [ ] 푸터, 서브헤더, 통학 인디케이터 컴포넌트 파일은 이번 범위가 아니다

---

## 1. 배치

사진과 같이 한 줄이다.

```text
|← 4% →|  제목     통학  검색   알림  |← 4% →|
```

- [x] 왼쪽: `headerTitle` 텍스트만. 탭 전환 UI는 없다
- [x] 오른쪽 순서: `CommuteHeaderIndicator`, 검색, 알림. 지금 `buttonContainer` 순서 그대로다
- [x] 통학 표시는 검색·알림처럼 선 아이콘으로 바꾸지 않는다. `createCommuteHeaderStyles` 칩(면 `colors.primaryLight3`, 글 `fonts.bold` · `colors.text`)을 유지한다
- [x] 컨테이너 `paddingHorizontal: width * 0.04`는 유지한다
- [x] 아이콘 버튼 `padding`·`minWidth`를 빼 아이콘 끝이 제목과 같은 4% 선에 오게 했다. 터치는 `hitSlop={normalize(10)}`
- [x] 검색과 알림 사이 간격은 `normalize(12)`. `gap: width * 0.03`은 제거했다

현재 제목 크기 `normalize(fontSizes.heading + 6)`은 26이다. 사진의 큰 제목에 맞는지 적용 때 이 값을 기준으로 보고, 다른 토큰으로 바꿀 때만 체크리스트에 숫자를 적는다.

---

## 2. 글꼴

- [x] 제목 `fontFamily: fonts.bold` (`Baloo2-Bold`) 유지
- [x] `fontWeight: '600'` 같은 시스템 굵기는 제목에 쓰지 않는다. 헤더의 `activeTabText`는 제거했다
- [x] 아이콘은 글꼴이 없다. Ionicons 선 아이콘으로 통일한다
- [x] 검색: `search-outline`
- [x] 알림: `notifications-outline`

---

## 3. 색

| 요소 | 지금 | 바꿀 값 |
|------|------|---------|
| 헤더 배경 | `colors.white` | 유지 |
| 제목 | `colors.text` | 유지 |
| 검색·알림 아이콘 | `colors.primary` | `colors.text`로 변경 |
| 아이콘 버튼 면 | `colors.green` | 2단계에서 제거 |
| 아이콘 버튼 테두리 | `colors.primaryLight5` | 2단계에서 제거 |
| 안 읽음 점 | `colors.alert` | 유지. 숫자 뱃지는 없다 |

- [x] `hasUnread`일 때만 알림 아이콘 오른쪽 위에 점을 둔다
- [x] 점 위치는 종 아이콘 오른쪽 위 모서리(`top: 0`, `right: 0`)다. 색은 `colors.alert`
