# 로그인 · 회원가입 개편 계획

작성: 2026-09-25  
브랜치: `feat/login-signup-overhaul`  
상태: **계획**

참고: `디자인_시스템 v1.md` · 현행 `SignupEntry` / `Login` / `SignKakao|Apple|Phone` / `SignupConsentSheet`

---

## 1. 한 줄

웹용 블루 카드 시안을 **앱(RN) + Youth Paper 그린**으로 옮긴다.  
이메일·비밀번호 확인 폼을 새로 만들지 않고, **지금 있는 카카오 / Apple / 전화번호 + 아이디 로그인**을 같은 톤으로 다시 짠다.  
로그인·가입 **진입 화면에는 헤더를 두지 않는다.**

---

## 2. 시안 → 우리 앱으로 번역

시안은 slate/blue 그라데이션 + 이메일 가입 카드다.  
우리는 **라이트 전용, Baloo2, 민트 그린**이다. 파란 CTA·자물쇠 히어로는 쓰지 않는다.

| 시안 | 우리 |
|------|------|
| `bg-slate-50` ~ `bg-blue-50` | 아주 옅은 **그린·세이지** 그라데이션. `#A6DA95`를 배경에 그대로 깔지 않음 |
| 흰 카드 `rounded-2xl` `shadow-xl` | 흰(또는 `surface`) 카드, `radius.xl`~24, `shadow.md` 정도. 그림자는 과하지 않게 |
| PC/태블릿 중앙 반응형 | 폰이 기준. 카드는 좌우 여백 + `max` 폭으로 가운데 |
| Create Account + 자물쇠 | **Youth Paper 로고** + 짧은 타이틀. 자물쇠는 브랜드와 안 맞음 |
| 이름 / 이메일 / 비번 / 비번확인 | **진입:** 소셜·전화 버튼. **로그인:** 아이디·비밀번호. 전화 가입 단계의 이름·전화는 기존 스텝 유지 |
| 포커스 파란 링 | `primary` / `primaryDark` 보더 + 얕은 그린 글로우 |
| 약관 커스텀 체크 | 이미 `SignupConsentSheet` — **시트 톤만** 맞춤 |
| 파란 그라데이션 CTA | `primary` 필 또는 아주 옅은 그린→진한 그린. 호버 대신 **press opacity / 살짝 scale** |
| 가입 완료 환영 페이드 | 짧은 **환영 화면** 후 기존 라우트(메인·가이드). 플로우를 막지 않음 |

`#A6DA95`는 **CTA·포커스·체크**에 쓴다. 배경은 `green` `#F7FFF3`, `lightgreen` `#E8FFDD`, `surface` `#F7F7F7`을 섞어 눈이 편한 톤으로 간다.

---

## 3. 확정

1. **헤더 없음 (진입)**  
   - `SignupEntry`, `Login` — 스택 헤더도, 화면 안 `SubHeader`/타이틀 바도 없음.  
   - 로고 + 문구가 헤더 역할.  
   - 로그인에 뒤로가기가 필요하면 **카드 안 텍스트 링크**(가입으로 / 닫기)만.

2. **가입 스텝 헤더**  
   - `SignKakao` / `SignApple` / `SignPhone`의 `headerTitle` 바는 **1차에서 없애거나 최소화**.  
   - 진행은 짧은 스텝 문구·점 인디케이터로.  
   - 시스템 뒤로가기는 지금처럼 막되, **그만두기**는 카드/푸터에 둠.  
   - 재제출·학생증·약관 문서(`SubHeader` 쓰는 화면)는 **이번 범위 밖**.

3. **기능은 유지**  
   카카오·Apple·전화 가입, 동의 시트, 아이디/비번 로그인, 소셜 로그인, 아이디·비번 찾기, 중복 계정 안내.

4. **이메일 가입 폼은 안 만듦.** 시안의 4칸 입력은 로그인(아이디·비번)과 전화 스텝에만 패턴을 빌려온다.

---

## 4. 화면별 목표

### 4.1 공통 레이아웃 · 배경

```
[ 옅은 그린 그라데이션 풀스크린 ]
[     흰 카드 (가운데)      ]
[  로고 · 타이틀 · 본문     ]
```

- 배경: 위는 `green` / `lightgreen`, 아래는 `#fff`에 가깝게. `expo-linear-gradient` 또는 큰 원형 블롭 2개.  
- 카드: 흰 면, 큰 라운드, `shadow.md`. 좌우 패딩은 지금보다 살짝 여유.  
- 진입 버튼 폭은 **카드 안 폭**에 맞춘다 (이미 줄인 알약 폭 유지·조정).

### 4.2 SignupEntry (계정 만들기)

**헤더 바 없음.**

| 영역 | 내용 |
|------|------|
| 타이틀 | 로고 + **계정 만들기** (영문 Create Account 병기 가능, 작게) |
| 서브 | 「몇 번만 누르면 시작할 수 있어요」 정도. 짧게 |
| 액션 | 카카오 / Apple / 전화번호로 시작하기 — 브랜드색은 유지(노랑·검정·그린 라인) |
| 푸터 | 이미 계정이 있나요? **로그인** |

약관은 버튼 직후 **기존 바텀 시트**. 시안처럼 카드 안에 체크를 넣지 않는다(스텝이 늘고 중복됨).

### 4.3 Login

**헤더 바 없음.**

| 영역 | 내용 |
|------|------|
| 타이틀 | 로고 + **로그인** |
| 서브 | 「다시 만나서 반가워요」 등 한 줄 |
| 입력 | 아이디 · 비밀번호. 왼쪽 아이콘(사람 / 자물쇠), 비번 **눈 토글** |
| 포커스 | 밑줄/박스 보더가 `primaryDark`로, 얕은 그린 링 |
| 에러 | 필드 아래 빨간(`alertDark`) 한 줄. 제출 전에도 형식만 가볍게 |
| CTA | **로그인** — 그린 필 버튼 |
| 보조 | 아이디 찾기 · 비밀번호 찾기 |
| 간편 | 카카오 · Apple 원형(또는 작은 필) 유지 |
| 푸터 | 아직 회원이 아닌가요? **회원가입** |

지금 GrowingUnderline는 유지해도 되고, 시안처럼 **라운드 박스 + 좌 아이콘**으로 바꿔도 된다. 1차는 박스+아이콘을 추천(포커스·에러가 잘 보임).

### 4.4 약관 시트

- 체크 색 `primary`, 필수 라벨만 진하게.  
- 시트 손잡이·여백은 유지, 배경을 카드와 같은 흰/연그린으로 맞춤.

### 4.5 가입 스텝 (전화·소셜 이후)

- 화면 헤더 바 제거(또는 로고만).  
- 입력(이름·전화 등)은 로그인과 **같은 필드 컴포넌트**.  
- 다음/완료 CTA는 그린 필.  
- 유효성 실패는 필드 아래 즉시.

### 4.6 완료

- 카드 안에서 폼 대신 **체크 + 「환영합니다」** 짧게(0.8~1.2초) 페이드.  
- 그다음 기존 `login()` 이후 라우트. 새 온보딩을 여기서 시작하지 않음.

## 5. 컬러 가이드 (그린 계열, 고정 hex 아님)

| 역할 | 후보 | 비고 |
|------|------|------|
| 배경 위쪽 | `#F7FFF3` ~ `#E8FFDD` | 연하고 차분하게 |
| 배경 아래 | `#FFFFFF` | 카드와 맞춤 |
| 카드 | `#FFFFFF` | 대비 |
| 타이틀 | `textPrimary` `#272A26` | |
| 서브 | `textSecondary` | |
| CTA · 포커스 | `primary` `#A6DA95` / `primaryDark` `#6f9163` | 글자는 진한 그린 또는 흰(대비율 보고 선택) |
| 에러 | `alert` / `alertDark` | 그린과 섞지 않음 |
| 카카오/Apple | 공식색 유지 | 브랜드 가이드 |

`#A6DA95`만으로 큰 버튼을 칠하면 글자 대비가 약할 수 있다. CTA 텍스트는 **`primaryDark` 또는 `#fff` + 버튼면을 한 단계 진하게** 하는 쪽을 먼저 본다.

## 6. 구현 순서

1. **공통 스킨** — 그라데이션 배경, 중앙 카드, 필드·CTA 컴포넌트 (`signup` 전용 작은 세트).  
2. **SignupEntry** — 헤더 없음, 타이틀/서브/버튼 스택을 카드 안으로.  
3. **Login** — 같은 카드, 아이콘 필드, 눈 토글, 인라인 에러, 그린 CTA.  
4. **Consent 시트** 체크·여백만 톤 맞춤.  
5. **가입 스텝** 헤더 정리 + 필드 재사용.  
6. **환영 페이드** (마지막, 짧고 스킵 가능하게).

파일 후보:

| 구분 | 경로 |
|------|------|
| 진입 | `view/src/signup/SignupEntry.jsx`, `styles/signupEntry.style.js` |
| 로그인 | `view/src/signup/Login.jsx`, `styles/login.style.js` |
| 공통 UI | `view/src/signup/` 아래 `AuthCard` · `AuthTextField` (신규) |
| 동의 | `SignupConsentSheet.jsx` |
| 스텝 | `SignKakao.jsx`, `SignApple.jsx`, `SignPhone.jsx`, `styles/login.style.js` 헤더 블록 |

## 7. 이번에 안 함

- 이메일 회원가입, 비밀번호 확인 칸  
- 메인 탭·게시판 헤더 개편 (다른 브랜치)  
- 학생증 재제출·NEIS+ 등 `SubHeader` 인증 화면  
- 다크 모드, 파란 팔레트  
- 웹/PC 전용 레이아웃

---

## 8. 시안 7항 체크

1. 레이아웃·배경 — 연그린 그라데이션 + 중앙 흰 카드  
2. 헤더·타이틀 — **바 헤더 삭제**, 카드 안 로고+타이틀+서브  
3. 입력 — 로그인·전화 스텝에 좌 아이콘, 포커스 그린, 비번 눈 토글  
4. 유효성 — 필드 아래 빨간 문구, 즉시 피드백  
5. 약관 — 기존 시트, 그린 체크  
6. CTA — 그린 필, press 피드백  
7. 완료 — 짧은 환영 페이드 후 기존 진입  

이 순서로 가면 시안 느낌을 가져오되, 우리 색과 실제 가입 경로와 어긋나지 않는다.
