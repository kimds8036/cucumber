# Youth Paper — 디자인 시스템 · 팝업 / 모달 / 하단 시트

> 화면에 **안내·확인·선택·차단** 목적으로 뜨는 창을 코드 기준으로 정리한 문서.  
> 단위: 기준폭 375 · iOS **pt** / Android **dp**(글자 **sp**)  
> **[기존]** = 코드에 있음 · **[시작값]** = 통일 제안(미확정)

관련: `디자인_시스템_컴포넌트.md` · `디자인_시스템_정리.md` · `디자인_시스템 v1.md`

---

## 0. 한눈에 고르기

| 목적 | 쓸 것 | 형태 |
|------|--------|------|
| 짧은 확인·오류·선택 (1~3 버튼) | `appAlert` → `AlertHost` | **중앙 팝업** |
| 가입 중 닫히면 안 되는 안내 | `SignupBlockingAlertModal` | 중앙 팝업 (백드롭·뒤로 차단) |
| 신고·사유 선택 후 확인 | `ReportModal` | **하단 시트** + 내부 중앙 팝업 |
| 삭제·차단 등 메뉴 | 메일/메시지/친구 **메뉴 시트** | **하단 시트** (핸들) |
| iOS형 액션 목록 | `IOSActionSheet` | **하단 액션 시트** (카드+취소 분리) |
| 동의·약관 선택 | `SignupConsentSheet` | **하단 시트** (슬라이드) |
| 제출 중 터치 차단 | `SubmittingLockModal` | **잠금 오버레이** |
| 짧은 피드백·푸시 미리보기 | `showToast` / `GlobalToast` | **상단 토스트** (팝업 아님) |
| 광고·온보딩·카메라 가이드 | 전용 모달/오버레이 | 풀스크린 또는 전용 UI |

**같은 역할이면 `AppPopupModal` / AlertHost 셸을 재사용한다.**  
게임·스터디룸 전용 UI는 이 문서 범위 밖(의도적 예외).

## 1. 종류 맵

```
안내 창
├── A. 중앙 팝업 (Center dialog)
│   ├── A1. 전역 Alert          → appAlert + AlertHost + AppPopupModal
│   ├── A2. 차단형 안내         → SignupBlockingAlertModal
│   └── A3. 도메인 확인 모달    → AppPopupModal 래퍼 (인증·시간표·신고 후속 등)
│
├── B. 하단 시트 (Bottom sheet)
│   ├── B1. 앱 메뉴 시트        → 핸들 + 상단 radius 24 (메일·메시지·친구)
│   ├── B2. 타이머/폼 시트      → timerModals bottomSheetCard
│   ├── B3. 가입 동의 시트      → SignupConsentSheet
│   ├── B4. 신고 시트           → ReportModal
│   └── B5. iOS 액션 시트       → IOSActionSheet
│
├── C. 잠금·가이드 오버레이
│   ├── C1. 제출 잠금           → SubmittingLockModal
│   ├── C2. 인증 진행           → SignupIdentityVerifyingOverlay 등
│   └── C3. 가이드/카메라       → GuideOverlay · StudentIdCameraGuideOverlay
│
├── D. 전용 풀/대형 모달
│   ├── 약관·정책               → Login policy Modal · SignupLegalDocumentModal
│   ├── 런치 광고               → LaunchAdModal
│   └── 기타                    → SignupIosSafeModal 래퍼 사용 화면
│
└── E. 토스트 (참고)            → ToastHost / GlobalToast  ※ 모달과 역할 분리
```

## 2. A. 중앙 팝업

### 2.1 공통 셸 — `AppPopupModal`

**경로:** `components/common/AppPopupModal.jsx`

| 항목 | 값 **[기존]** |
|------|----------------|
| 위치 | 화면 중앙 |
| 딤 | `rgba(0,0,0,0.3)` (기본) |
| 카드 폭 | **86%** · max **420** |
| 배경 | `colors.background` |
| radius | **18** |
| 패딩 | 가로 **18** · 세로 **25** |
| 애니메이션 | fade · dismiss 후 언마운트 **320ms** |
| 배경 탭 닫기 | `dismissOnBackdrop` (기본 false 권장 for alert) |
| 뒤로가기 | `dismissOnBackPress` (기본 true) |

**쓸 때:** 확인·안내·짧은 폼이 가운데에 떠야 할 때.  
**쓰지 말 때:** 긴 목록 선택·파괴적 메뉴 나열 → 하단 시트.

---

### 2.2 전역 Alert — `appAlert` + `AlertHost`

**경로:** `utils/appAlert.js` · `components/common/AlertHost.jsx`

| 항목 | 기준 |
|------|------|
| 호출 | `appAlert.alert(title, message, buttons, options)` |
| 큐 | Host가 순차 표시 |
| 제목 | 18 · Bold · `textPrimary` · 가운데 |
| 본문 | 14 · `textSecondary` · lineHeight 22 |
| 노트 | `options.note` · 12 · `textLight40` |
| 버튼 높이 | **42** · radius **10** · gap 8 |
| 배치 | 2개 이하 가로 / 3개 이상 세로 |
| 배경 탭 | **닫히지 않음** |
| 본문 sanitize | `sanitizeUserFacingText` |

**버튼 `style`**

| style | 면 | 글 |
|-------|-----|-----|
| (기본) | `primary` | 흰 |
| `cancel` | `textLight5` | `textSecondary` |
| `destructive` | `alert` | 흰 |

**사용 기준**

- 오류·저장 완료·권한 안내·“정말 삭제?” 등 **전역 확인**
- 네이티브 `Alert.alert` UI를 화면마다 직접 그리지 않음
- Host 부팅 전 → 짧은 대기 후 native fallback 가능

## 6. E. 토스트 (팝업과 구분)

| 항목 | 기준 |
|------|------|
| API | `showToast` (`ToastContext`) |
| UI | `GlobalToast` · Host `ToastHost` |
| 위치 | **상단** · 자동 사라짐 · 탭 시 이동 가능 |
| 용도 | “저장됐어요”, 푸시 미리보기 등 **가벼운** 안내 |

확인·오류로 사용자 결정이 필요하면 **토스트 대신 A(중앙 Alert)**.

## 7. 상호작용 · 접근 규칙

| 규칙 | 내용 |
|------|------|
| 한 번에 하나 | Alert는 큐 · 시트/모달은 화면에서 단일 visible 권장 |
| 배경 탭 | Alert·차단형 = 끄기 · 메뉴 시트·액션 시트 = 켜기 |
| 뒤로가기(Android) | Alert 기본 닫기 · Blocking/Lock = 무시 |
| 페이드 | `AppPopupModal` 320ms · Consent 시트는 별도 타이밍 |
| iOS Modal | 가능하면 Safe 언마운트 패턴 (`AppPopupModal` / `SignupIosSafeModal`) |

## 8. 플랫폼

### iOS (pt)

- 중앙 팝업 · 앱 메뉴 시트 · Consent 시트 = 앱 토큰 색
- `IOSActionSheet`만 시스템 그레이/빨강에 가깝게 **별도 팔레트**
- Modal dismiss 잔상 → Safe 언마운트 필수에 가깝게 취급

### Android (dp / sp)

- 동일 논리 수치 · 글자는 sp
- 하드웨어 뒤로가기 = `dismissOnBackPress` / Lock no-op 준수
- elevation은 시트·토스트에 이미 사용

## 9. 신규 화면 체크리스트

1. 확인 1~3버튼 → **`appAlert`**  
2. 가입 중 강제 안내 → **`SignupBlockingAlertModal`**  
3. 대상+액션(삭제/차단) → **B1 메뉴 시트** (핸들·radius 24)  
4. 신고 → **`ReportModal`**  
5. iOS형 액션만 → **`IOSActionSheet`** (또는 B1로 통일 **[시작값]**)  
6. 제출 중 → **`SubmittingLockModal`**  
7. 가벼운 피드백 → **토스트**  
8. 중앙 커스텀 내용 → **`AppPopupModal` 래퍼** (셸 복제 금지)
