# Youth Paper — 디자인 시스템 정리

> 현재 코드(`styles/colors.js`, `styles/tokens.js`, `styles/frame.style.js`, `view/frame/*`) 기준 요약본.  
> 상세 규칙·시작값 표기는 `디자인_시스템 v1.md` 참고.  
> **기준 폭:** 375 · 스케일 `normalize(n) = round((width/375)*n)`  
> **단위:** iOS pt / Android 레이아웃 dp · 글자 sp

---

## 1. Grid

| 항목 | 값 | 코드 |
|------|-----|------|
| 기준 프레임 | 폭 **375** (논리) | `getNormalize` |
| 메인 여백 (Margin) | **20** (`space.xl`) — 메인 헤더 가로 | `createHeaderStyles` |
| 화면 거터 | 폭 × **7%** (`screenGutterRatio`) | SubHeader, SignupPrimaryFooter |
| 리스트 거터 | 폭 × **4%** (`listGutterRatio`) | 게시판 리스트 등 |
| 간격 스케일 | 4 / 8 / 12 / 16 / 20 / 24 | `tokens.space` |
| 모서리 | 8 / 12 / 16 / 24 / pill(999) | `tokens.radius` |

**정렬**

- 서브헤더 제목: 가운데  
- 본문·가입 입력: 왼쪽  
- 주 CTA: 가로 full  

컬럼 고정 그리드(예: 4열)는 코드에 없음. 여백·거터 비율로 레이아웃을 맞춤.

```
|← 7% →|          content          |← 7% →|   SubHeader / 가입 CTA
|← 4% →|          list             |← 4% →|   피드 리스트
|← 20 →|         main header       |← 20 →|   MainHeader
```

## 2. Navigation Bar

### 하단 탭 — `MainFooter`

| 항목 | 값 |
|------|-----|
| 배경 | `#fff` (`background`) |
| 높이 | **65** (논리) |
| 탭 min 높이 | **50** |
| 상단 구분선 | `textLight5`, 0.5 |
| 탭 수 | **5** |

| 탭 | 라벨 | 아이콘 계열 |
|----|------|-------------|
| board | 홈(게시판) | Octicons |
| message | 메시지 | Ionicons |
| school | 우리 학교 | FontAwesome |
| timer | 타이머 | MaterialIcons |
| mypage | 마이페이지 | Ionicons |

**상태**

| 상태 | 아이콘·라벨 |
|------|-------------|
| 기본 | `textSecondary` |
| 선택 | `primary` (`#A6DA95`) + 상단 **삼각 인디케이터** |
| 눌림 | `activeOpacity` **0.7** |

### 상단 — `MainHeader` / `SubHeader`

| 종류 | 역할 |
|------|------|
| MainHeader | 탭 타이틀 + 검색·알림 원형 아이콘 버튼 (`green` 면, primary 보더) |
| SubHeader | 뒤로 + 가운데 제목 (Bold `xxl`) · 거터 7% |
| SearchSubHeader | 검색 전용 (SubHeader와 동일 거터·뒤로 크기) |

## 3. Typography

**서체:** Baloo2  
- Regular → `Baloo2-Regular`  
- Bold → `Baloo2-Bold`  
- 예외: 미니게임 등 `Jua` (메인 셸과 분리)

| Level | 역할 | 토큰 | 크기 | 굵기 | iOS | Android |
|-------|------|------|------|------|-----|---------|
| 1 | 큰 제목 | `heading` | 20 | Bold | 20pt | 20sp |
| 2 | 화면 타이틀 / CTA | `title` / `xxl` | 18 / 16 | Bold | 18·16pt | 18·16sp |
| 3 | 본문·칩 | `xl` | 14 | Regular | 14pt | 14sp |
| 4 | 보조·메타 | `lg` | 12 | Regular | 12pt | 12sp |
| 5 | 초소 메타·탭 라벨 | `md` | 10 | Regular/Bold | 10pt | 10sp |

메인 헤더 탭 라벨: `heading + 6` (코드 관례).

**색과 함께**

- 본문: `textPrimary` `#272A26`  
- 보조: `textSecondary`  
- CTA 위: `textWhite`

## 4. Color

학생 커뮤니티용 **라이트·민트** 톤. 온도/에너지형 다크 UI가 아님.

### Main / Sub

| 역할 | Hex | 토큰 |
|------|-----|------|
| **Main** | `#A6DA95` | `primary` |
| Main 강조 글 | `#6f9163` | `primaryDark` |
| 연한 그린 면 | `#F7FFF3` / `#C8EDB2` / `#E8FFDD` | `green` / `greenDark` / `lightgreen` |
| **Sub (주의·스크랩)** | `#F5A623` | `scrap` |
| Sub 강조 | `#A46E17` | `scrapDark` |
| 오류 | `#FF9F9F` / `#AB6A6A` | `alert` / `alertDark` |
| 정보 | `#AAD7FF` | `subcolor` |

`primaryLight5` ~ `primaryLight70` — 면·보더·비활성 CTA용 투명도.

### 면 · 배경

| 역할 | Hex | 토큰 |
|------|-----|------|
| 화면 배경 | `#FFFFFF` | `background` |
| 카드·섹션 | `#F7F7F7` | `surface` |
| 가이드 면 | `#FAF8F4` | `guideBackground` |
| 비활성 면 | `#ECECEC` | `disabled` |

**모드:** 라이트 전용 (다크 토큰 없음).

## 5. Grey System

본문 색 `#272A26`을 기준으로 한 **투명도 그레이** + 고정 hex.

| Level | 용도 | 값 | 토큰 |
|-------|------|-----|------|
| 1 | 본문·제목 | `#272A26` | `textPrimary` |
| 2 | 보조 글 | `rgba(39,42,38,0.5)` | `textSecondary` |
| 3 | 비활성 글 | `rgba(39,42,38,0.3)` | `background2` |
| 4 | 테두리·구분 | `#E0E0E0` / `#E6E6E6` | `border` / `timetableBorder` |
| 5 | 약한 선·스켈레톤 | 5%~70% | `textLight5` ~ `textLight70` |
| — | 흰 / 회색 면 | `#FFF` / `#F7F7F7` / `#D3D3D3` | `background` / `surface` / `backgroundGray` |

```
#272A26  →  50%  →  30%  →  #E0E0E0  →  #F7F7F7  →  #FFFFFF
  본문      보조     비활성    테두리      면         배경
```

## 6. Component

### Button

| 종류 | 모양 | 크기 | 색 |
|------|------|------|-----|
| Primary CTA | pill | 높이 **52**, Bold `xxl` | `primary` + 흰 글 |
| Popup | radius **10** | 높이 **42** | `primary` |
| Header icon | 원형 | min **40** | `green` 면 + primary 보더 |
| Destructive | — | — | `alert` / `alertDark` |
| Disabled | — | — | `disabled` 또는 `primaryLight50` |

눌림: `interaction` **0.7** 통일.

구현: `SignupPrimaryFooter`, Login pill, `AlertHost` 버튼.

### Card

| 종류 | 용도 | 형태 |
|------|------|------|
| Feed | 게시글 | 흰 면, radius ~**18**, `shadow.md` |
| Surface | 설정·마이 블록 | `surface` 또는 보더만 |
| Profile | 마이 요약 | `Profilecard` 전용 |

### Input

| 종류 | 용도 | 형태 |
|------|------|------|
| Underline | 로그인·가입·아이디 | 밑줄형 (박스 없음) |
| Search | 검색 | `SearchSubHeader` |
| Boxed | 일부 폼만 | radius `md` + `border` |

### Chip / Toggle류

| | 비활성 | 활성 |
|--|--------|------|
| 필터 칩 | 흰 + `textLight10` 보더 | `primary` + 흰 글 |
| (토글 스위치) | 공통 토글 컴포넌트 **없음** — 화면별 Switch/칩으로 처리 |

### Modal / Feedback

| 컴포넌트 | 요약 |
|----------|------|
| `AppPopupModal` | 폭 ~86%, radius **18**, 딤 0.3 |
| `AlertHost` / `ToastHost` | 전역 알림·토스트 |
| `Skeleton` | `textLight10` pulse |
| `SubmittingLockModal` | 제출 중 잠금 |

### Icon

- 스타일: 벡터 아이콘 혼용 (Ionicons / Feather / Material / Octicons / FA)  
- 활성: `primary` · 비활성: `textSecondary`  
- 프로필 아이콘 면: `getProfileInnerColor` (연녹·노랑·연홍·연파·흰)
