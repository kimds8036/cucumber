# 타이머 시간 카드 개편 체크리스트

> 대상: 타이머 탭의 시간 카드. 지금은 `front/view/src/timer/TimerLiveViews.jsx`의 `segment === 'card'` 부분(206~299줄)에 들어 있다.  
> 스타일: `front/styles/timer.js`의 `createTimerStyles` (`timerCard`, `dateBar*`, `studyRoomEntry*`, `saveBtn`, `timerBlock`, `timerTime`, `timerBtn*`).  
> 참고 디자인: 왼쪽에 시간과 시작 버튼, 오른쪽에 메뉴 3개(연속 공부, 위클리 달성률, 스터디룸)를 세로로 둔 카드.

목표는 시간 카드를 별도 컴포넌트로 분리하고 참고 디자인처럼 바꾸는 것이다. 타이머 시작·일시정지, 사진 저장, 스터디룸 입장 동작은 지금과 같게 유지한다.

---

## 0. 작업 순서

- [x] 1단계: 시간 카드를 새 컴포넌트 파일로 분리한다 (모양은 그대로)
- [x] 2단계: 날짜 이동 줄(이전 날짜, 날짜, 다음 날짜)을 없앤다
- [x] 3단계: 카드를 왼쪽 시간 영역과 오른쪽 메뉴 영역으로 나눈다
- [x] 4단계: 시간 영역 오른쪽 위에 사진 저장·설정 버튼을 둔다
- [x] 5단계: 메뉴에 연속 공부, 위클리 달성률, 스터디룸 버튼을 세로로 둔다
- [x] 6단계: 로딩 스켈레톤과 사용 안 하는 스타일을 정리한다

## 1. 컴포넌트 분리

- [x] 새 파일 `front/view/src/timer/TimerCard.jsx`를 만든다 → **질문 Q1**
- [x] 지금 카드가 쓰는 값(표시 시간, 실행 중 여부, 오늘 보기 여부, 시작·일시정지, 사진 저장, 스터디룸 입장)을 props로 받는다
- [x] 1초마다 바뀌는 시간은 지금처럼 `TimerLiveViews.jsx`가 `LiveElapsedMsContext`로 계산해 `displayTotalMs`로 넘긴다 (매초 다시 그리는 범위는 지금과 같다)
- [x] 사용 가이드의 카드 강조 영역(`GuideFocusTarget`, `T.TIMER_TIMER_CARD`)을 새 카드 바깥에 그대로 둔다
- [x] `TimerLiveViews.jsx`의 `segment === 'card'`는 새 컴포넌트를 부르도록 바꾼다

## 2. 날짜 이동 줄 제거

지금 카드 맨 위에는 `<` 날짜 `>` 버튼 줄이 있다. 날짜를 누르면 달력이 열리고, 화살표로 지난 날짜 기록을 볼 수 있다.

- [x] 카드에서 `<`, 날짜, `>` 버튼을 없앤다 (`TimerCard.jsx`의 `SHOW_DATE_NAV = false`로 숨김)
- [x] 지난 날짜 기록 보기 기능 처리 → **질문 Q2** (버튼만 숨기고 달력·날짜 이동 코드는 남김)
- [ ] 지금 날짜 줄 오른쪽에 있는 `스터디룸 입장` 버튼과 사진 저장 버튼은 새 위치(메뉴, 시간 영역 오른쪽 위)로 옮긴다
