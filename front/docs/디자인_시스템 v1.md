# Youth Paper — DESIGN.md (디자인 시스템 v1)

> **소스 오브 트루스(코드):** `front/styles/colors.js`, `front/styles/tokens.js`, `front/styles/frame.style.js`, `front/view/frame/*`, `front/components/common/*`  
> 이 문서와 코드가 다르면 **코드를 우선**하고, 합의 후 토큰·문서를 같이 갱신한다.  
> **단위:** 표의 숫자는 기준폭 **375**에서의 논리 크기. 렌더는 `normalize(n) = round((width/375)*n)`.  
> - **iOS:** 레이아웃·도형 = **pt**, 글자 = **pt** (RN `fontSize`가 그대로 pt)  
> - **Android:** 레이아웃·도형 = **dp**, 글자 = **sp** (RN `fontSize`가 sp로 매핑; 메타 라인은 `includeFontPadding: false` 관례)

### 이 문서에서 쓰는 표기

| 표기 | 의미 |
|------|------|
| **[코드]** | 저장소 파일을 열어 확인한 사실 |
| **[화면]** | 앱 UI 구조·카피·플로우에서 읽히는 목적/분위기 (본 작업에서는 실기기 스크린샷 전수 점검 없음 → 컴포넌트·스타일·온보딩 문구로 보강) |
| **[시작값]** | 이번에 문서화·통일용으로 제안한 수치. 확정값이 아님 |
| **[기존]** | 이미 코드/문서에 있던 기준 |

## 0. 조사 요약 — 화면 vs 코드

### 0.1 [화면]에서 읽히는 앱 분위기·목적

| 관찰 | 내용 |
|------|------|
| 브랜드 | 밝은 민트 그린 + 흰 배경, 캐주얼·친근한 학생 커뮤니티 |
| 대상 | 중·고등 재학생 (가입·학생 인증 게이트) |
| 메인 목적 | 익명 게시판·메시지/우편 · 우리 학교(급식·잔디) · 공부 타이머 · 마이(시간표·친구) |
| 반복 UI | 하단 5탭, 서브헤더(뒤로+제목), 초록 CTA, 칩 필터, 카드형 게시글, 밑줄형 로그인/가입 입력 |
| 예외 톤 | 스터디룸·미니게임 등은 풀블리드·별도 폰트(Jua 등) — 메인 셸과 의도적으로 다름 |

### 0.2 [코드]에서 확인한 구현 사실

| 확인 | 위치 |
|------|------|
| 색·폰트 토큰 | `styles/colors.js` — `primary #A6DA95`, Baloo2, `fontSizes` |
| radius·shadow·간격 시작 스케일 | `styles/tokens.js` — `radius`, `shadow`, **`space`**, **`interaction`** |
| 셸 | `MainHeader` / `MainFooter` / `SubHeader` / `SearchSubHeader` |
| 가입 CTA | `SignupPrimaryFooter` — 높이 52, pill, 거터 7% |
| 팝업 | `AppPopupModal` — 폭 86%, radius 18, 딤 0.3 |
| 스케일 | `getNormalize` in `frame.style.js` |
| 다크 모드 | **토큰·ThemeContext 없음 → 라이트 전용 [기존]** |
| 아이콘 | Ionicons / Feather / MaterialIcons 등 혼용 [기존] |

### 0.3 역할이 달라 억지로 통일하지 않는 것

- 스터디룸·훈민정음 등 **게임/애니 전용 UI**
- 시간표 과목색·프로필 눈 색 **도메인 팔레트**
- 위젯(네이티브) 레이아웃 — 인앱과 “느낌”만 맞추고 수치 강제 공유하지 않음

## 3. 레이아웃

### 3.1 화면 여백 · 간격 **[기존] + [시작값] `tokens.space`**

| 토큰/관례 | 논리 | iOS | Android | 용도 |
|-----------|------|-----|---------|------|
| `space.xs` | 4 **[시작값]** | 4pt | 4dp | 아이콘-글 초밀착 |
| `space.sm` | 8 **[기존 관례·토큰화]** | 8pt | 8dp | 푸터 버튼 위아래, 기본 갭 |
| `space.md` | 12 **[시작값]** | 12pt | 12dp | 필드 간 |
| `space.lg` | 16 **[기존 관례]** | 16pt | 16dp | 섹션 패딩 |
| `space.xl` | 20 **[기존 메인헤더]** | 20pt | 20dp | 메인 헤더 가로 |
| `space.xxl` | 24 **[시작값]** | 24pt | 24dp | 섹션 분리 |
| `screenGutterRatio` | **0.07** **[기존]** | 폭×7% | 폭×7% | SubHeader, SignupPrimaryFooter |
| `listGutterRatio` | **0.04** **[기존]** | 폭×4% | 폭×4% | 게시판 리스트 |
| 로그인 본문 | 28 **[기존]** | 28pt | 28dp | Login body |

정렬: 서브헤더 제목 **가운데**, 본문·가입 입력 **왼쪽**, CTA **가로 full**.

### 3.2 카드 안쪽 · 모서리 · 버튼 **[기존]**

#### Radius (`tokens.radius`) — iOS pt / Android dp

| 키 | 값 | 용도 |
|----|-----|------|
| `sm` | 8 | 스켈레톤·작은 면 |
| `md` | 12 | 입력·서브푸터 완료 버튼 |
| `lg` | 16 | 큰 카드·배너 |
| `xl` | 24 | 넉넉한 라운드 |
| `full` | 999 | 칩·필·원형 |

관례 **[기존]:** 로그인/가입 CTA ≈ **pill(높이/2)**, 목록 카드·팝업 ≈ **18**, 정렬 칩 ≈ **20**.

## 4. 공통 컴포넌트

같은 역할 → 모양·동작 통일. 다른 역할 → 억지 통일 금지.

### 4.1 버튼

| 컴포넌트/패턴 | 쓰임 | 모양·크기 | 사용 기준 |
|---------------|------|-----------|-----------|
| **Primary CTA** (`SignupPrimaryFooter`, Login pill) | 가입·로그인·시작하기 | primary 면, 흰 글, Bold `xxl`, 높이 52, pill | 화면 하단 주 액션 1개 |
| **Popup primary** (`AlertHost` / `AppPopupModal` children) | 확인 | 높이 42, radius 10, primary | 모달 내 |
| **Header icon** (`MainHeader`) | 검색·알림 | 원형, `green` 면, primary 보더 | 메인 탭 상단만 |
| **Text / link** | 보조 이동 | `primary`/`primaryDark` 글 | 카드·푸터 링크 |
| **Destructive** | 삭제·거절 | `alert` 면 또는 `alertDark` 글 | 파괴적 확인 |
| Disabled | 주 액션 불가 | `primaryLight50` 또는 `disabled` 면 | `disabled`/`loading` |

`activeOpacity`: CTA **0.85**, 리스트 **0.7** (`tokens.interaction`) **[기존 관측→토큰]**.

### 4.2 카드

| 패턴 | 쓰임 | 모양 | 기준 |
|------|------|------|------|

| **Surface section** | 설정·마이 블록 | `surface` 또는 보더만 | 비클릭 묶음 |
| **Profile card** | 마이 요약 | 전용 레이아웃 | 마이페이지만 |
| 금지 | 히어로에 카드 스택 | — | 랜딩형 남용 금지 |

### 4.3 입력 칸

| 패턴 | 쓰임 | 모양 | 기준 |

## 6. 적용 예시

### 6.1 가입 완료 → 프로필 아이디 (`SignProfileUsername`) **[코드 적용됨]**

1. 화면 거터 = `width * 0.07` (SubHeader와 동일)  
2. 제목 Bold `heading`, 보조 Regular `lg` + `textSecondary`  
3. 입력 = Underline + GrowingUnderline + SignStep2형 텍스트 피드백  
4. 하단 = `SignupPrimaryFooter` label「시작하기」, disabled/loading 상태 공유  

### 6.2 검색 3화면 **[코드 적용됨]**

`Search` / `SearchResult` / 결과→재검색 → 모두 `SearchSubHeader`.  
뒤로 아이콘 크기·거터는 `SubHeader`와 동일. clear 슬롯 높이 고정으로 입력 시 점프 방지.

### 6.3 전역 알림 **[코드]**

`Alert.alert` → `appAlert` → `AlertHost` → `AppPopupModal`.  
본문 `textSecondary` 14 / 제목 Bold 18 / 버튼 높이 42.

### 6.4 새 화면 체크리스트

1. 색·폰트·radius·shadow·space·interaction은 토큰에서  
2. 하위 화면은 `SubHeader` + `background`  
3. 주 CTA 1개 = Primary pill 또는 `SignupPrimaryFooter` 패턴  
4. 입력 신규 = Underline 우선  
5. 라이트·민트 톤 유지 (퍼플 그라데이션·다크 신규 금지)  
6. raw hex 남발 금지

## 7. 플랫폼별 요약

### iOS

- 단위: **pt** (레이아웃·글자)  
- 그림자: `shadowColor` / opacity / radius  
- 시트: `IOSActionSheet` 등 하단 시트 패턴 허용  
- SafeArea: `SafeAreaView` edges로 top/bottom 처리  

### Android

- 단위: **dp** (레이아웃), **sp** (글자)  
- 그림자: `elevation`  
- 텍스트: 메타·한 줄 입력에 `includeFontPadding: false` 관례  
- 뒤로가기: 가입 잠금·모달 `dismissOnBackPress` 정책 화면별 준수  

스케일 공식은 양 플랫폼 동일(`width/375`).
