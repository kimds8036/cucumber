# YouthPaper 앱 디자인 시스템

> 프론트 코드(`styles/`, `components/`, `view/frame/`) 기준으로 정리한 **현재 앱의 시각·컴포넌트 형식**이다.  
> 색·폰트를 바꿀 때는 `front/styles/colors.js` · `front/styles/tokens.js`를 우선한다.

---

## 1. 한 줄로 보는 톤

| 항목 | 느낌 |
|------|------|
| 브랜드 | 밝은 **민트 그린** (`#A6DA95`) 중심의 학생·학교 커뮤니티 |
| 배경 | **화이트** 베이스, 카드/면은 아주 옅은 회색 |
| 타이포 | **Baloo2** — 둥글고 친근한 디스플레이형 산세리프 |
| 형태 | 둥근 모서리(칩·필·카드), 과하지 않은 그림자 |
| 대비 | 본문 `#272A26`, 보조는 동일 색의 투명도 변형 |
| 모드 | **라이트 전용** (다크 모드 토큰 없음) |

전체적으로 **캐주얼·라이트·그린 액센트**. 보라·네온·헤비 글래스모피즘은 쓰지 않는다.

### 2.5 도메인 팔레트

**프로필 눈/아이콘 색** — `PROFILE_COLORS` (1~6: 그린·블루·핑크·오렌지·민트·퍼플).

**로고 계열 연한 면** — `yellow` `#FFFCD7`, `red` `#FFF3F3`, `blue` `#E5F0FF`, `white`.

## 3. 타이포그래피

| 토큰 | 폰트 |
|------|------|
| `fonts.regular` | `Baloo2-Regular` |
| `fonts.bold` | `Baloo2-Bold` |

로드: `App.js` `useFonts`. 게임(훈민) 등 예외 화면만 별도 폰트(Jua 등) 사용.

### 폰트 사이즈 (`fontSizes`) — **기준 375폭** 값

| 키 | px | 대략 용도 |
|----|-----|-----------|
| `xs` | 6 | 극소 |
| `sm` | 8 | 캡션 |
| `md` | 10 | 탭 라벨·아주 작은 메타 |
| `lg` | 12 | 본문 메타·보조 |
| `xl` | 14 | 본문·칩 |
| `xxl` | 16 | 서브헤더 제목·버튼 |
| `title` | 18 | 화면 타이틀 |
| `heading` | 20 | 큰 제목 (+ 헤더 탭은 +6 스케일) |
| `guideStepNumber` | 30 | 가이드 스텝 숫자 |

실제 렌더는 `normalize(size)` = `Math.round((width/375) * size)` 로 스케일한다. 화면별 `getNormalize` / `createXxxStyles(width)` 패턴을 따른다.

Android는 메타 라인에서 `includeFontPadding: false`를 자주 켠다.

## 4. 형태 · 간격 · 그림자 (`styles/tokens.js`)

### Radius

| 키 | 값 | 용도 |
|----|-----|------|
| `sm` | 8 | 작은 면·스켈레톤 |
| `md` | 12 | 입력·버튼·카드 기본 |
| `lg` | 16 | 큰 카드·배너 |
| `xl` | 24 | 넉넉한 라운드 |
| `full` | 999 | 칩·필·원형 뱃지 |

관례: **로그인 CTA ≈ pill** (`borderRadius` ≈ 높이/2), **목록 카드 ≈ 18**, **팝업 카드 ≈ 18**, **정렬 칩 ≈ 20**, **푸터 완료 버튼 ≈ 12**.

### Shadow

| 키 | iOS | Android |
|----|-----|---------|
| `sm` | opacity 0.08, r 2 | elevation 2 |
| `md` | opacity 0.12, r 4 | elevation 4 |
| `lg` | opacity 0.16, r 8 | elevation 8 |

게시글 카드 등은 `...shadow.md`를 펼쳐 쓴다. 그림자는 **얕게** — 다층 glow·강한 드롭섀도 지양.

### 가로 여백 관례

- 메인 헤더: `normalize(20)` 수준  
- 서브헤더: 폭의 `~7%`  
- 게시판 리스트: 폭의 `~4%`  
- 로그인 본문: `normalize(28)`

## 6. 공통 UI 패턴

### 6.1 버튼

| 유형 | 시각 |
|------|------|
| Primary CTA | `primary` 배경, 흰/`background` 텍스트, Bold, pill 또는 12~16 라운드 |
| Disabled | `primaryLight50` 배경 |
| 텍스트/링크 | `primary` 또는 `primaryDark` |
| 헤더 아이콘 | 원형, `green` 배경, 얇은 primary 보더 |

### 6.2 칩 · 필터

비활성: 흰 배경 + `textLight10` 보더 + `textSecondary`  
활성: `primary` 채움 + 흰 텍스트  
거리 스테일: 주황 반투명 칩 (`distanceStale*`)

광고/팁 배지: `PillBadge` — `borderRadius: 999`

### 6.3 카드 · 리스트

- 흰 배경 + 라운드(~18) + `shadow.md` (게시판 포스트)
- 또는 `surface` / 보더만 쓰는 플랫 섹션
- **카드 남용 지양**: 상호작용·목록 단위에만 카드 느낌

### 6.4 입력

로그인 등: **밑줄형** 입력(박스 보더 최소화), Baloo2 Regular, `textPrimary`  
포커스 시 화려한 글로우보다 단순 상태 변화

### 6.5 모달 · 시트

| 컴포넌트 | 용도 |
|----------|------|
| `AppPopupModal` | 중앙 확인 팝업. 딤 ~0.3, 카드 흰·radius 18·폭 ~86% |
| `IOSActionSheet` | 하단 액션시트, radius 14 |
| `ReportModal` 등 | 신고·확인 도메인 모달 |
| `SubmittingLockModal` | 제출 중 잠금 |

애니메이션: fade (~320ms). 백드롭 탭 닫기는 화면마다 선택.

### 6.6 토스트 · 알림

| 컴포넌트 | 용도 |
|----------|------|
| `GlobalToast` / `ToastHost` | 상단 슬라이드 인, 채팅·일반 메시지 |
| `AlertHost` | 앱 전역 알림 호스트 |

### 6.7 로딩 · 스켈레톤

| 컴포넌트 | 용도 |
|----------|------|
| `Loading` | 전역/화면 로딩 |
| `Skeleton` | `textLight10` 면 + opacity 0.5↔0.9 펄스 |
| `*Skeleton` (채팅·급식 시간 등) | 화면별 스켈레톤 조합 |

### 6.8 배너 · 게이트

인증/재인증/차단: `StudentVerificationGate`, `Reverification*Banner`, `AccountBlockedScreen`, `ForceUpdateGate`, `OfflineGate`  
톤: primary CTA + alert/연한 면으로 상태 구분. 타이포는 Baloo2 유지.

### 6.9 프로필 · 배지

- `ProfileCard` — 마이페이지 요약 카드  
- `ProfileIcon` / `EquippedBadge` — 아바타·장착 배지  
- `DistanceBadge` — 거리 표시  
- `CommuteHeaderChip` / `CommuteHeaderIndicator` — 등교 상태 칩

## 9. 모션 · 인터랙션 감각

- 탭 `activeOpacity` 0.7 전후  
- 토스트: 위에서 spring/back 이징으로 등장  
- 스켈레톤: 느린 opacity 루프  
- 모달: fade, 과한 스케일 팝 지양  
- 스터디룸 걷기: 짧은 프레임 사이클 (`WALK_FRAME_MS`)

## 10. 새 UI 체크리스트

1. 색은 `colors.*` / 도메인 팔레트만 — raw hex 남발 금지  
2. 폰트는 `fonts.regular` / `fonts.bold` + `fontSizes` + `normalize`  
3. 라운드·그림자는 `tokens.radius` / `tokens.shadow`  
4. 하위 화면은 `SubHeader` + 흰 배경이 기본  
5. Primary 액션은 그린 필/버튼, 파괴적 액션은 `alert` 계열  
6. 카드는 목록·터치 단위에만, 히어로에 카드 스택 지양  
7. 라이트 모드·민트 그린 톤 유지 (퍼플 그라데이션·다크 UI로 새 화면을 만들지 않음)
