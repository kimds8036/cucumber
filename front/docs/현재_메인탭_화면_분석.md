## 1. 모든 탭 공통 셸

개편해도 **같은 역할의 진입점**은 남겨야 한다. 모양은 바꿔도 된다.

### 상단 (좌 → 우)

| 자리 | 무엇 | 기능 |
|------|------|------|
| 좌 | 탭 타이틀 (보드만 예외) | 표시만 |
| 좌(보드) | **전체** ↔ **학생** | 피드 전환. 활성 쪽이 진하고 왼쪽에 온다 |
| 우 | 등교 칩 (조건부) | 등교 시간대에만. 탭 → 등교 브레이크아웃 |
| 우 | 검색 (돋보기) | 스택 `Search` |
| 우 | 알림 (벨) | 스택 `Notification`. 미읽음이면 빨간 점 (쪽지/DM 방은 점 집계에서 제외) |

### 하단 5탭 (좌 → 우)

| 키 | 라벨 | 하는 일 |
|----|------|---------|
| `board` | 게시판 | 전국/학생 피드 |
| `message` | 메시지 | 쪽지 + 개인우편 |
| `school` | 우리 학교 | 학교 허브 (인증 필요) |
| `timer` | 타이머 | 공부 타이머·투두·친구 |
| `mypage` | 마이페이지 | 프로필·시간표·설정 |

활성 탭: 아이콘/글자 강조 + **위쪽 삼각형 인디케이터**. 푸터에는 미읽음 숫자 없음.  
같은 탭을 다시 눌러도 스크롤 탑 같은 동작은 없다.

### 앱 전역 (탭 위)

재인증 배너, 거절 모달, 인앱 리뷰, 학생인증 준비물 브리지.  
개편 후에도 **인증 상태 배너/모달**이 어느 탭에서든 떠야 한다.

## 2. 학생인증 게이트 (이식 핵심)

미인증이어도 **전체 게시판 · 쪽지 · 타이머 · 마이페이지**는 쓴다.  
막히는 곳은 아래 세 갈래뿐이다.

| 막히는 곳 | 미인증일 때 | 인증 후 |
|-----------|-------------|--------|
| 게시판 → **학생** 피드 / 학생 글쓰기 | 목록 비움 + 인증 CTA. 닫으면 **전체**로 돌아감 | 학생 피드·작성 |
| 메시지 → **개인 우편** / 우편 보내기 | 탭 전환 자체를 막고 CTA | 우편 목록·발송 |
| **우리 학교** 탭 전체 | 빈 화면 + CTA. 「나중에」면 게시판 탭으로 | 학교 허브 |

학교 하위(학교 게시판, 학교 우편함, 급식 달력)도 학생 전용으로 유지.

## 3. 게시판 (Group 3810)

**배치 방향:** 세로 피드. 필터는 상단 가로 칩. 글쓰기는 우하단 플로팅.

### 위 → 아래

1. **공통 헤더** — 전체/학생 스왑 + 검색 + 벨  
2. **정렬 칩** (가로) — 최신 / 인기 / 근처  
3. **팁 배너** (광고 자리, 지금은 팁 문구만. 탭 동작 없음)  
4. **글 카드 목록** (세로 무한 스크롤)  
5. **+ FAB** (우하단)  
6. **공통 푸터**

### 글 카드 한 장 (위 → 아래, 좌우)

- 위: 익명·상대시간 (좌) / 거리 칩 (우, 위치 권한 있을 때)  
- 본문 미리보기 (몇 줄 자르기)  
- 이미지 있으면 우측 썸네일  
- 태그  
- 아래: 좋아요 / 댓글 (0이면 숨김)

**목록 카드는 통째로 탭 → 글 상세.** 좋아요·스크랩·메뉴는 목록에 연결되지 않고 **상세 화면**에서 한다.

### 버튼 · 제스처

| 조작 | 기능 |
|------|------|
| 전체 / 학생 | 피드 전환. 학생+미인증 → CTA |
| 최신 / 인기 / 근처 | 정렬. 근처는 좌표 필요, 위치 거부 시 안내 |
| 카드 | `BoardDetail` |
| + FAB | `BoardWrite` (national 또는 student). 학생+미인증이면 CTA만 |
| 당겨 새로고침 | 1페이지 갱신 + 팁 교체 + 위치 갱신 |
| 하단 도달 | 다음 페이지 |

### 화면에 안 보여도 있는 것

빈 목록 문구, 스켈레톤, 피드 전환 팁 말풍선, 인피드 광고 슬롯(아직 비움).  
차단 유저 글은 목록에서 빠진다.

### 개편 시 반드시 살릴 기능

- 전체/학생 두 보드, 정렬 3종, 거리, 페이지네이션, pull-to-refresh, FAB  
- 상세에서 좋아요·댓글·스크랩·작성자 쪽지·신고/차단·내 글 삭제  
- 태그, 썸네일, 장착 배지  
- 팁(또는 광고) 상단 슬롯

## 4. 메시지 (Group 3809)

**배치 방향:** 상단 세그먼트 + 세로 대화 목록. 우편일 때만 우하단 FAB.

### 위 → 아래

1. **공통 헤더** — 「메시지」 + 검색 + 벨  
2. **필 토글** (가로, 한 줄) — 쪽지 | 개인 우편  
3. **방 목록** (세로)  
4. **우편 FAB** (비행기) — 개인 우편 탭에만  
5. **공통 푸터**

### 목록 한 행 (좌 → 우)

- 좌: 새싹 아바타  
- 중: 이름 + 마지막 말 미리보기  
- 우: 시각 + (있으면) 미읽음 숫자 / 반송 표시

이름 규칙: 익명 쪽지·받은 우편은 「익명」, DM·보낸 우편은 상대 이름.

### 버튼 · 제스처

| 조작 | 기능 |
|------|------|
| 쪽지 | 익명 쪽지방 + DM을 최신순으로 한 목록 |
| 개인 우편 | 미인증이면 전환 안 하고 CTA |
| 쪽지 행 | `Chat` (익명방) |
| DM 행 | `DMChat` |
| 우편 행 | 스레드 읽음 처리 후 `MailDetail` |
| 행 길게 누르기 | 삭제 / 신고·차단 시트 |
| 우편 FAB | `SendMail` (내부에서 다시 학생인증 확인) |

당겨 새로고침은 없다. 포커스·소켓으로 갱신.

### 개편 시 반드시 살릴 기능

- 쪽지(익명+DM 병합)와 개인우편은 **다른 데이터**  
- 미읽음 숫자, 반송, 롱프레스 삭제/차단  
- 실시간 목록 갱신  
- 우편 작성 FAB + 학생인증

## 5. 우리 학교 (Group 3806)

**배치 방향:** 세로 스크롤 허브. 카드가 위에서 아래로 쌓이고, 바로가기만 **2열**.

인증 전: 본문 없이 CTA만. 「나중에」→ 게시판 탭.

### 위 → 아래 (인증 후)

1. **공통 헤더** — 「우리 학교」 + 검색 + 벨  
2. **학교 카드** (세로 가운데 정렬)  
   - 학교 이름  
   - 위치(핀 + 주소)  
   - 통계 3칸 가로: 학생 수 / 게시글 수 / 우편 수 — **탭 없음**  
3. **급식 카드**  
   - 헤더: 「급식」(좌) / 「자세히 →」(우)  
   - 본문: 끼니 슬롯 **3칸 가로** (조/중/석 + 요일 뱃지 + 메뉴 줄)  
4. **우리 학교 공부 잔디밭**  
   - 제목 + (i) 안내  
   - 요일×날짜 히트맵 + 아래 범례  
5. **바로가기 2칸 가로** — 학교 게시판 / 학교 우편함 (각 「→ 보러 가기」)  
6. **실시간 인기** — 이미지에는 안 보이지만 바로가기 **아래**에 있음. 최대 5개  
7. **공통 푸터**

### 버튼

| 조작 | 기능 |
|------|------|
| 자세히 → | `MealCalendar` (급식 달력) |
| 급식 칸 | 해당 끼니 메뉴 모달 |
| (i) | 잔디 설명 툴팁 (짧게 표시) |
| 학교 게시판 | `SchoolBoardAll` → 여기서 또 FAB로 학교 글쓰기 |
| 학교 우편함 | `SchoolMailbox` |
| 인기 행 | `BoardDetail` |

당겨 새로고침 없음. 학교/급식 캐시가 있다.  
급식·잔디는 홈 위젯과도 맞춰 둔다.

### 개편 시 반드시 살릴 기능

- 학교 프로필(이름·주소·세 통계)  
- 급식 미리보기 + 달력  
- 공부 잔디  
- 학교 게시판 / 학교 우편함 진입  
- 학교 인기글  
- **탭 진입 자체 인증 게이트**

## 6. 타이머 (Group 3807)

**배치 방향:** 위는 가로 친구 줄, 가운데 큰 타이머 카드, 아래는 **투두 | 공부기록 2열**.  
학생인증 없음.

### 위 → 아래

1. **공통 헤더** — 「타이머」 + 검색 + 벨  
2. **친구 스토리 바** (가로 스크롤)  
   - 맨 앞 「친구 추가」(+)  
   - 친구 원형들 (공부 중이면 점, 추천이면 추가 아이콘)  
3. **타이머 카드**  
   - 위: ◀ 날짜 ▶ (좌) / 다운로드 (우). 코드상 실행 중일 때만 「스터디룸 입장」도 이 줄  
   - 가운데: 큰 경과 시간  
   - 아래: 시작 / 일시정지 (오늘 날짜만)  
4. **하단 2열**  
   - 좌 **투두리스트** + 「과목 추가」  
     - 과목 행: 이름, 누적 시간, 재생/일시정지, 접기  
     - 펼치면 할 일 체크 + 「+ 할 일 추가」  
   - 우 **공부 기록** — 시간대 세로 칸, 10분 슬롯 색칠  
5. **공통 푸터**

### 버튼

| 조작 | 기능 |
|------|------|
| 친구 추가 | 아이디로 친구 요청 |
| 친구 원 | 쿡 찌르기 시트. 추천이면 친구 추가 확인 |
| 쿡 찌르기 | 상대 타이머에 쿡 (쿨다운 있음) |
| 기다림 알림 | 상대 공부 끝나면 알림 |
| 메시지 보내기 | DM 방 만들고 `DMChat` |
| 날짜 ◀▶ / 날짜 탭 | 다른 날 보기 / 달력. 미래는 오늘까지 |
| 스터디룸 입장 | `TimerAniLab` — **타이머가 돌아가 있을 때만** |
| 다운로드 | 플래너 이미지 갤러리 저장 |
| 시작 / 일시정지 | 오늘만 |
| 과목 재생 | 그 과목으로 타이머 |
| 과목 롱프레스 | 과목 삭제 |
| 할 일 체크 / 롱프레스 | 완료 / 삭제 |
| 과목 추가 · 할 일 추가 | 모달 |

과거 날짜: 시작·추가·편집은 숨기거나 막는다.

### 개편 시 반드시 살릴 기능

- 타이머일(06:00 기준) 저장, 과목/할 일/세션  
- 친구 바 + 쿡 + 기다림 + DM  
- 스터디룸은 타이머 ON 게이트  
- 공부 기록 그리드, 갤러리 저장  
- 위젯과 같은 누적 시간

## 7. 마이페이지 (Group 3808)

**배치 방향:** 세로 스크롤. 위 프로필 카드(안에 시간표), 아래 메뉴 리스트.

### 위 → 아래

1. **공통 헤더** — 「마이페이지」 + 검색 + 벨  
2. **프로필 카드**  
   - 아바타 + 이름 + 장착 배지 + @아이디  
   - 학교 · 학년 반 (미인증이면 「인증 전」)  
   - 미인증 CTA: 학생 인증하기 / 검수 중 / 거절됨·사유 보기  
   - 바로가기 3칸 가로: **친구 N · 게시글 N · 스크랩 N** (친구 요청 있으면 점)  
   - **시간표 그리드** (월~금 × 교시)  
   - 시간표 하단 아이콘 가로: 새로고침(교시 설정) / 편집 / 다운로드  
3. **메뉴 리스트** (한 줄 = 아이콘 + 제목 + 부가설명 + `>`)  
4. **공통 푸터**

이미지에는 클린 센터·설정·계정 관리만 보이지만, 스크롤 아래에 나머지가 있다.

### 버튼

| 조작 | 기능 |
|------|------|
| 학생 인증하기 | 인증 플로우 (`reason: mypage`) |
| 거절됨 · 사유 보기 | 거절 모달 → 재제출 |
| 검수 중 | 눌러도 이동 없음 |
| 친구 | `Friends` |
| 게시글 | `MyPosts` 작성 탭 |
| 스크랩 | `MyPosts` 스크랩 탭 |
| 시간표 없을 때 「시간표 추가하기」 | 인증: 나이스 선택(`TimetabelChoice`). 미인증: 수동 `EditTimetable` |
| 교시 설정 | `PeriodTimeSettings` |
| 시간표 편집 | `EditTimetable` |
| 시간표 저장 | 갤러리 |
| 클린 센터 | 신고·제한 현황 `HiddenPostsAppeals` |
| 회초리 | 개발팀 제보 `DeveloperWhack` |
| 친구 초대하기 | 초대 링크 공유 |
| 배지 관리 | `BadgeManage` |
| 앱 설정 | 알림·거리·다크모드·앱잠금 (`NotificationSettings` prefs) |
| 계정 관리 | 아이디·학년반·비밀번호 등 (같은 화면 profile) |
| 고객 지원 | 공지·문의·가이드·약관 `Info` |
| 로그아웃 | 확인 후 세션 종료 |
| 계정 탈퇴 | 두 번 확인 후 탈퇴 (글/댓글은 익명으로 남음 안내) |

당겨 새로고침 없음. 탭 포커스 때 숫자만 다시 가져온다.

### 개편 시 반드시 살릴 기능

- 프로필 + 인증 CTA 3상태

## 8. 글쓰기 (image.png)

메인 탭이 아니라 스택 화면. 게시판 FAB · 학교 게시판 FAB에서 들어온다.  
`boardContext`: `national` | `student` | `school`.

**배치 방향:** 위는 고정 툴바, 아래는 본문 입력. 하단 탭바 없음. 가이드 문구는 화면 맨 아래 고정.

### 위 → 아래

1. **SubHeader** — 뒤로(좌) / 「글쓰기」(중) / **등록** 필 버튼(우)  
2. **툴바 한 줄** (좌 → 우)  
   - 게시판 칩 (전체게시판 ▼)  
   - 태그 아이콘  
   - 이미지 아이콘  
   - 위치 핀 (기본 켜짐 = 채운 핀)  
3. 태그를 열면 그 아래: 추천 태그 · `#` 입력 · 선택한 태그 칩  
4. 사진을 고르면 그 아래: 가로 썸네일 줄 (+ 추가 / 개별 삭제)  
5. **본문** — 플레이스홀더 「오늘의 이야기를 들려주세요」. **제목 필드 없음**  
6. **하단 고정 안내** — 비방/욕설은 커뮤니티 가이드에 따라 삭제될 수 있음

### 버튼 · 기능

| 조작 | 기능 |
|------|------|
| 뒤로 | 작성 취소 후 이전 화면 |
| 등록 | 본문(또는 사진)이 있어야 활성. `POST /api/posts` 후 학교면 한 단계 pop, 아니면 탭 루트 |
| 게시판 칩 | 드롭다운: 전체게시판 / 학생게시판 / 학교게시판. 진입 컨텍스트로 초기값 |
| 태그 | 패널 토글. 최대 5개. 검색 추천(`/api/posts/tags/search`). 스페이스·엔터로 추가, 칩 ✕로 제거 |
| 이미지 | 앨범에서 여러 장, 최대 5장 |
| 위치 핀 | 켜면 글에 좌표 첨부(근처·거리용). 끄면 좌표 없음 |
| 등록 실패 `STUDENT_VERIFICATION_REQUIRED` | 학생/학교 보드인데 미인증이면 안내 |

### 개편 시 반드시 살릴 기능

- 보드 3종 선택 + 진입 컨텍스트  
- 본문 · 태그(최대 5, 추천) · 이미지(최대 5) · 위치 on/off  
- 학생/학교 보드 인증 실패 처리  
- 커뮤니티 가이드 경고  
- 작성 후 돌아갈 곳(학교 vs 메인 피드)

## 9. 게시글 상세 (image1.png)

목록 카드·학교 인기글·검색 결과에서 들어온다.  
파일: `boardDetail.jsx` + `BoardPostContent` + `BoardCommentTree` + `BoardFloatingMenu`.

**배치 방향:** 위는 고정 서브헤더, 가운데 세로 스크롤(글 → 팁 → 댓글), 아래는 댓글 입력 고정.

### 위 → 아래

1. **SubHeader** — 뒤로 / 「게시판」  
2. **글 본문**  
   - 위: 익명(또는 작성자) · 상대시간 (좌) / 거리 칩 (우, 위치 권한 있을 때)  
   - 본문 전체  
   - 이미지(있으면 세로로, 탭하면 뷰어)  
   - 태그 칩 (탭 → 해당 태그 검색)  
   - 아래: 좋아요 / 댓글 수 / 스크랩 (좌) · **⋮ 메뉴** (우)  
3. **팁 배너** (`TopAdBanner`) — 광고 자리. 지금은 「Tip + 문구」만. 탭 동작 없음  
4. **댓글 목록** (트리)  
   - 루트 댓글: 익명 N 또는 「작성자」 · 시간 · (고정이면 핀)  
   - 본문. 답글이면 `@부모` 표시, 한 단 들여쓰기  
   - 아래: 좋아요 · 「댓글 달기」 (좌) · ⋮ (우)  
5. **하단 입력** — 「댓글을 입력하세요」 + 보내기(위 화살표). 답글 대상이 있으면 그 위에 대상 표시·취소

### 글 ⋮ 메뉴

| 누가 | 항목 |
|------|------|
| 내 글 | 공유하기 · 삭제하기 |
| 남의 글 | 쪽지 보내기 · 공유하기 · 신고 / 차단 |

자기 자신에게 쪽지는 막는다.

### 댓글 ⋮ 메뉴

| 누가 | 항목 |
|------|------|
| 내 댓글 | 삭제하기. 글 작성자면 여기에 댓글 고정/해제 |
| 남의 댓글 | 쪽지 보내기 · 신고 / 차단. 글 작성자면 고정/해제 추가 |
| 글 작성자 + 루트 댓글만 | 고정 가능 (답글에는 고정 없음) |

### 버튼 · 제스처

| 조작 | 기능 |
|------|------|
| 좋아요(글/댓글) | 토글 |
| 스크랩 | 토글. 마이페이지 스크랩 목록에 반영 |
| 태그 | `SearchResult` (그 태그) |
| 이미지 | 전체 화면 뷰어 |
| 댓글 달기 | 하단 입력을 그 댓글의 답글로. 초안은 유지 |
| 댓글 더보기 / 접기 | 답글 펼침 |
| 보내기 | 댓글 또는 답글 등록 |
| 쪽지 보내기 | 익명 쪽지방 열고 `Chat` |

### 화면에 안 보여도 있는 것

로딩 스켈레톤, 이미지 비율 잡히기 전 대기, 신고 모달, 삭제 확인, 댓글 입력 시 키보드에 맞춰 입력창 올라옴.  
댓글 이미지 첨부는 코드에 자리가 있으나 **지금은 꺼 둠** (`showImageAttach={false}`).

### 개편 시 반드시 살릴 기능

- 글: 본문·이미지·태그·거리·좋아요·스크랩·공유·삭제·쪽지·신고/차단  
- 댓글 트리: 익명 번호 / 작성자 라벨, 좋아요, 답글, 고정, 삭제, 쪽지, 신고/차단  
- 하단 입력 + 답글 대상  
- 글과 댓글 사이 팁/광고 슬롯  
- 태그 → 검색

## 11. 개편 이식 체크리스트

기능을 옮길 때 이 목록으로 빠짐을 확인한다.

1. **5탭 정보 구조** — 게시판 / 메시지 / 학교 / 타이머 / 마이. 합치더라도 위 기능이 어디로 가는지 정한다.  
2. **검색 · 알림(빨간 점) · 등교 칩**  
3. **학생인증 3곳** — 학생 피드·개인우편·우리학교 (+ 그 하위)  
4. **게시판** — 전체/학생, 정렬 3, 거리, FAB, 상세 액션, 팁 슬롯  
4-1. **글쓰기** — 보드 3종, 본문, 태그 5, 이미지 5, 위치, 가이드 문구, 인증 실패  
4-2. **글 상세** — 좋아요/스크랩/메뉴, 댓글 트리·답글·고정, 쪽지/신고, 입력창, 팁 슬롯  
5. **메시지** — 쪽지(익명+DM) vs 우편, 미읽음, 롱프레스, 우편 작성  
6. **학교** — 카드, 급식, 잔디, 두 바로가기, 인기글, 위젯 동기화  
7. **타이머** — 친구/쿡, 일자, 시작·정지, 과목/할 일, 기록, 스터디룸 게이트, 캡처  
8. **마이** — 프로필·인증 CTA, 3퀵링크, 시간표, 메뉴 9개  
9. **빈 상태 · 스켈레톤 · 가이드 하이라이트** — 첫 실행 가이드가 잡는 타깃 이름은 가능하면 유지  
10. **광고 슬롯** — 지금은 비어 있으나 게시판·메시지 자리에 훅이 있다
