# 신고/운영 시스템 현재상태 진단 + 진행 체크리스트

## 1) 현재 상태 진단 (코드 기준)

### 이미 구현됨
- 게시글 신고 API: `POST /api/posts/:id/report`
- 댓글 신고 API: `POST /api/comments/:commentId/report`
- 중복 신고 차단: 동일 유저가 동일 대상 재신고 시 차단
- 신고 데이터 적재: `reports` 테이블에 저장
- 프론트 공통 신고 UI 컴포넌트: `frontend/components/common/ReportModal.jsx` 추가됨

### 미구현/보완 필요
- 신고 3회 임계치 도달 시 자동 숨김(`is_hidden`) 처리
- 목록/상세 조회에서 숨김 글 미노출 처리
- 작성자용 "숨김 처리된 내 글" 조회 API
- 이의신청(소명) 저장/조회 API
- 관리자 최종 판정(확정 삭제/복구) API
- 허위 신고자 패널티 반영 로직
- 일일 신고 횟수 제한(예: 5회)

### 운영 정책 문구(정제본)
- 신고 완료: "신고가 접수되었습니다. 더 안전한 커뮤니티를 위해 함께해 주셔서 감사합니다. 허위 신고가 반복되면 이용이 제한될 수 있습니다."
- 중복 신고: "이미 신고한 게시물입니다."
- 작성자 숨김 안내: "작성하신 게시글이 신고 누적으로 임시 숨김 처리되었습니다. 이의가 있으시면 고객센터에서 소명해 주세요."
- 고객센터 상단: "신고 누적으로 숨김 처리된 내 게시글만 표시됩니다. 억울한 처리라고 생각되면 상세 사유를 작성해 주세요."
